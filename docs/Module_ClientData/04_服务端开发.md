## 核心逻辑

### 查询客户端数据

```java
public ClientDataInfo queryClientData(long playerId, int dataType, String dataKey) {
    // 查询数据
    PlayerClientData data = clientDataDao.selectByPlayerAndKey(playerId, dataType, dataKey);

    if (data == null) {
        return ClientDataInfo.notFound(dataType, dataKey);
    }

    return ClientDataInfo.found(dataType, dataKey, data.getDataValue(), data.getVersion());
}
```

### 保存客户端数据

```java
public void saveClientData(long playerId, int dataType, String dataKey, String dataValue, long version) {
    // 检查数据大小
    if (dataValue != null && dataValue.length() > MAX_DATA_SIZE) {
        throw new BusinessException(ErrorCode.CLIENT_DATA_TOO_LARGE);
    }

    // 查询现有数据
    PlayerClientData existingData = clientDataDao.selectByPlayerAndKey(playerId, dataType, dataKey);

    if (existingData == null) {
        // 新增数据
        PlayerClientData newData = new PlayerClientData();
        newData.setPlayerId(playerId);
        newData.setDataType(dataType);
        newData.setDataKey(dataKey);
        newData.setDataValue(dataValue);
        newData.setVersion(version);
        newData.setUpdateTime(new Date());
        clientDataDao.insert(newData);
    } else {
        // 版本检查
        if (version <= existingData.getVersion()) {
            throw new BusinessException(ErrorCode.CLIENT_DATA_VERSION_ERROR);
        }

        // 更新数据
        existingData.setDataValue(dataValue);
        existingData.setVersion(version);
        existingData.setUpdateTime(new Date());
        clientDataDao.updateById(existingData);
    }
}
```

### Web加密数据

```java
public WebEncryptedData getWebEncryptedData(long playerId, String encryptKey) {
    // 生成加密数据
    String rawData = generateEncryptRawData(playerId);
    String encryptData = AESUtil.encrypt(rawData, encryptKey);

    // 设置过期时间
    long expireTime = System.currentTimeMillis() + ENCRYPT_DATA_EXPIRE;

    // 缓存加密数据
    String cacheKey = "web_encrypt:" + playerId + ":" + encryptKey;
    redisTemplate.opsForValue().set(cacheKey, encryptData, ENCRYPT_DATA_EXPIRE, TimeUnit.MILLISECONDS);

    return new WebEncryptedData(encryptKey, encryptData, expireTime);
}
```

## 协议处理

```java
@Handler(module = 11, sub = 1)
public void handleQueryClientData(long playerId, GC2GS_011_001_ReqQueryClientData req) {
    ClientDataInfo data = clientDataService.queryClientData(
        playerId, req.getDataType(), req.getDataKey());
    sendRetQueryClientData(playerId, data);

public void handleSaveClientData(long playerId, GC2GS_011_002_ReqSaveClientData req) {
    clientDataService.saveClientData(
        playerId, req.getDataType(), req.getDataKey(),
        req.getDataValue(), req.getVersion());
    sendRetSaveClientData(playerId, req.getDataType(), req.getDataKey(), true, req.getVersion());

    sendRetWebEncryptedData(playerId, data);
}
```

## 数据清理

### 定期清理过期数据

```java
@Scheduled(cron = "0 0 3 * * ?") // 每天凌晨3点
public void cleanExpiredData() {
    // 清理超过180天未更新的数据
    Date expireDate = DateUtils.addDays(new Date(), -180);
    int deleted = clientDataDao.deleteByUpdateTime(expireDate);
    log.info("Cleaned {} expired client data records", deleted);
}
```

## 安全考虑

### 数据校验

```java
public void validateClientData(int dataType, String dataKey, String dataValue) {
    // 数据类型校验
    if (!isValidDataType(dataType)) {
        throw new BusinessException(ErrorCode.INVALID_DATA_TYPE);
    }

    // 数据键长度校验
    if (dataKey == null || dataKey.length() > 128) {
        throw new BusinessException(ErrorCode.INVALID_DATA_KEY);
    }

    // 数据值大小校验
    if (dataValue != null && dataValue.length() > MAX_DATA_SIZE) {
        throw new BusinessException(ErrorCode.CLIENT_DATA_TOO_LARGE);
    }

    // JSON格式校验
    try {
        if (dataValue != null && !dataValue.isEmpty()) {
            JsonParser.parseString(dataValue);
        }
    } catch (Exception e) {
        throw new BusinessException(ErrorCode.INVALID_DATA_FORMAT);
    }
}
```

## 注意事项

1. 客户端数据大小需要限制
2. 版本号用于防止数据覆盖
3. 敏感数据不应存储在客户端数据中
4. 需要定期清理过期数据
5. Web加密数据需要设置过期时间
