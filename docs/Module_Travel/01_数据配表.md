# 游历系统 - 数据配表

## 概述

游历系统 (TravelOp, p008) 是游戏中的核心玩法之一，玩家可以派遣角色进行游历，在游历过程中触发各种事件并获得奖励。

## 配表文件

### 1. 游历位置配置 (TravelPos)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| pos_id | int | 位置ID |
| pos_name | string | 位置名称 |
| unlock_condition | int | 解锁条件 |
| event_list | array | 可触发事件列表 |

### 2. 游历事件配置 (TravelEvent)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| event_id | int | 事件ID |
| event_type | int | 事件类型 |
| event_desc | string | 事件描述 |
| reward_list | array | 奖励列表 |
| weight | int | 权重 |

### 3. 游历妃子配置 (TravelConsort)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| consort_id | long | 妃子ID |
| consort_name | string | 妃子名称 |
| like_init | int | 初始好感度 |
| event_list | array | 关联事件列表 |

### 4. 游历事件类型配置

#### 4.1 奖励事件 (RewardEvent)
- 触发条件：游历到达特定位置
- 奖励内容：资源、道具、经验等

#### 4.2 赌博事件 (GambleEvent)
- 玩家选择参与赌博
- 结果：赢取或失去资源

#### 4.3 邀请事件 (InvitationEvent)
- 触发社交互动
- 可能获得新的伙伴

#### 4.4 妃子相关事件
- **妃子酒吧事件 (ConsortBarEvent)**: 与妃子在酒吧的互动
- **妃子好感事件 (ConsortLikeEvent)**: 提升妃子好感度
- **妃子亲密度事件 (ConsortIntimacyEvent)**: 提升亲密度

#### 4.5 其他事件
- **赠礼事件 (GiftedEvent)**: 获得赠礼
- **变换事件 (ChangeEvent)**: 事件变化
- **加力事件 (AddPowerEvent)**: 获得力量加成

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Travel/`
- 服务端配置：`game_server/Config/travel/`

## 配表加载

```csharp
// 获取游历位置配置
var posRef = GRefdataCoreMgr.instance.travelPosRefCore.getRef(posId);

// 获取游历事件配置
var eventRef = GRefdataCoreMgr.instance.travelEventRefCore.getRef(eventId);

// 获取游历妃子配置
var consortRef = GRefdataCoreMgr.instance.travelConsortRefCore.getRef(consortId);
```

## 注意事项

1. 事件权重配置影响触发概率
2. 不同位置可触发的事件类型不同
3. 妃子事件需要对应的妃子已解锁
