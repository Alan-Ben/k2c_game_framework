# 客户端数据 - 协议文档

## 协议编号

模块编号：p011 (ClientDataOp)

## 客户端请求协议 (GC2GS)

### GC2GS_011_001_ReqQueryClientData

**说明**：请求查询客户端数据

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dataType | int | 数据类型 |
| dataKey | string | 数据键 |

**返回**：GS2GC_011_001_RetQueryClientData

---

### GC2GS_011_002_ReqSaveClientData

**说明**：请求保存客户端数据

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dataType | int | 数据类型 |
| dataKey | string | 数据键 |
| dataValue | string | 数据值 |
| version | long | 版本号 |

**返回**：GS2GC_011_002_RetSaveClientData

---

### GC2GS_011_003_ReqWebEncryptedData

**说明**：请求Web加密数据

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| encryptKey | string | 加密键 |

**返回**：GS2GC_011_003_RetWebEncryptedData

---

## 服务端响应协议 (GS2GC)

### GS2GC_011_001_RetQueryClientData

**说明**：返回查询的客户端数据

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dataType | int | 数据类型 |
| dataKey | string | 数据键 |
| dataValue | string | 数据值 |
| version | long | 版本号 |
| exist | bool | 是否存在 |

---

### GS2GC_011_002_RetSaveClientData

**说明**：返回保存结果

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dataType | int | 数据类型 |
| dataKey | string | 数据键 |
| success | bool | 是否成功 |
| version | long | 版本号 |

---

### GS2GC_011_003_RetWebEncryptedData

**说明**：返回Web加密数据

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| encryptKey | string | 加密键 |
| encryptData | string | 加密数据 |
| expireTime | long | 过期时间 |

---

## 数据结构

### ClientDataInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dataType | int | 数据类型 |
| dataKey | string | 数据键 |
| dataValue | string | 数据值（JSON格式） |
| version | long | 版本号 |
| updateTime | long | 更新时间 |
