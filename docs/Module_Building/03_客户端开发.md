# 建筑模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerBuildingComponent
**路径**: `GameComponent/Building/PlayerBuildingComponent.cs`

**功能**: 建筑管理器，管理玩家所有建筑数据

**继承关系**:
```
PlayerBuildingComponent : _ANPBasicPlayerComponent
```

**协议模块**: p010_BuildingOp

**依赖组件**:
- `ENPPlayerCompType.HERO`

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| buildingList | IReadOnlyList<BuildingInfo> | 所有建筑列表 |
| businessBuildingList | List<BusinessBuildingInfo> | 商业建筑列表 |
| farmingBuildingList | List<FarmingBuildingInfo> | 农场建筑列表 |
| nextOrderedBuilding | BuildingInfo | 下一个要建造的建筑 |
| farmingMultipleInfo | FarmingMultipleInfo | 农场建筑暴击倍数信息 |
| haveBuildingUnderConstruction | bool | 是否有建筑正在建造 |

**主要事件**:

| 事件名 | 说明 |
|--------|------|
| onBuildingBuilt | 建筑建造完成 |
| onFarmingBuildingChg | 农场建筑变化 |
| onBusinessBuildingChg | 商业建筑变化 |
| onNextOrderedBuildingChg | 下一个建筑变化 |

## 五、访问方式

```csharp
// 获取建筑组件
PlayerBuildingComponent buildingComp = NPPlayer.instance.buildingComp;

// 获取所有建筑
var buildings = buildingComp.buildingList;

// 获取指定建筑
BuildingInfo building = buildings.FirstOrDefault(b => b.buildingId == buildingId);

// 获取农场建筑列表
var farmingBuildings = buildingComp.farmingBuildingList;

// 获取商业建筑列表
var businessBuildings = buildingComp.businessBuildingList;
```
