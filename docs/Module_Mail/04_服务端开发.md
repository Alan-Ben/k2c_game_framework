## 核心逻辑

### 发送邮件

```java
public void sendMail(long playerId, MailData mailData) {
    // 1. 检查邮件数量限制
    int count = mailDao.countByPlayerId(playerId);
    if (count >= MAIL_MAX_COUNT) {
        // 删除最早的已读邮件
        cleanOldestMail(playerId);
    }

    // 2. 创建邮件
    PlayerMail mail = new PlayerMail();
    mail.setId(generateMailId());
    mail.setPlayerId(playerId);
    mail.setMailType(mailData.getMailType());
    mail.setTitle(mailData.getTitle());
    mail.setContent(mailData.getContent());
    mail.setSender(mailData.getSender());
    mail.setRewardList(mailData.getRewardList());
    mail.setState(EMailState.UNREAD.getValue());
    mail.setSendTime(new Date());
    mail.setExpireTime(calculateExpireTime(mailData.getMailType()));

    // 3. 保存邮件
    mailDao.insert(mail);

    // 4. 推送通知
    pushMailAdded(playerId, mail);
}
```

### 批量发送系统邮件

```java
public void sendSystemMail(SystemMail systemMail) {
    // 1. 获取目标玩家列表
    List<Long> targetPlayers = getTargetPlayers(systemMail.getTargetCondition());

    // 2. 批量插入邮件
    List<PlayerMail> mailList = new ArrayList<>();
    for (Long playerId : targetPlayers) {
        PlayerMail mail = createMailFromSystem(systemMail, playerId);
        mailList.add(mail);
    }
    mailDao.batchInsert(mailList);

    // 3. 推送通知给在线玩家
    for (Long playerId : targetPlayers) {
        if (playerManager.isOnline(playerId)) {
            PlayerMail mail = findMailByPlayerAndSystem(playerId, systemMail.getMailId());
            pushMailAdded(playerId, mail);
        }
    }
}
```

### 领取附件

```java
public void takeMailItems(long playerId, long mailId) {
    // 1. 查询邮件
    PlayerMail mail = mailDao.selectById(mailId);
    if (mail == null || mail.getPlayerId() != playerId) {
        throw new BusinessException(ErrorCode.MAIL_NOT_FOUND);
    }

    // 2. 检查状态
    if (mail.getState() == EMailState.REWARD_TAKEN.getValue()) {
        throw new BusinessException(ErrorCode.MAIL_REWARD_TAKEN);
    }

    // 3. 发放奖励
    if (mail.getRewardList() != null && !mail.getRewardList().isEmpty()) {
        rewardService.giveRewards(playerId, mail.getRewardList());
    }

    // 4. 更新状态
    mail.setState(EMailState.REWARD_TAKEN.getValue());
    mailDao.updateById(mail);

    // 5. 推送通知
    pushMailRewardTaken(playerId, mailId);
}
```

### 一键领取所有附件

```java
public void takeAllMailItems(long playerId) {
    // 1. 查询有附件的邮件
    List<PlayerMail> mailList = mailDao.selectWithReward(playerId);

    // 2. 汇总所有奖励
    List<RewardInfo> allRewards = new ArrayList<>();
    for (PlayerMail mail : mailList) {
        if (mail.getState() != EMailState.REWARD_TAKEN.getValue()) {
            allRewards.addAll(mail.getRewardList());
            mail.setState(EMailState.REWARD_TAKEN.getValue());
        }
    }

    // 3. 批量发放奖励
    rewardService.giveRewards(playerId, allRewards);

    // 4. 批量更新状态
    mailDao.batchUpdateState(mailList);
}
```

### 删除邮件

```java
public void deleteMail(long playerId, long mailId) {
    // 1. 查询邮件
    PlayerMail mail = mailDao.selectById(mailId);
    if (mail == null || mail.getPlayerId() != playerId) {
        throw new BusinessException(ErrorCode.MAIL_NOT_FOUND);
    }

    // 2. 检查是否锁定
    if (mail.getIsLocked()) {
        throw new BusinessException(ErrorCode.MAIL_LOCKED);
    }

    // 3. 检查是否有未领取附件
    if (mail.getState() != EMailState.REWARD_TAKEN.getValue()
        && mail.getRewardList() != null && !mail.getRewardList().isEmpty()) {
        throw new BusinessException(ErrorCode.MAIL_HAS_REWARD);
    }

    // 4. 删除邮件
    mailDao.deleteById(mailId);

    // 5. 推送通知
    pushMailRemoved(playerId, mailId);
}
```

## 定时任务

### 清理过期邮件

```java
@Scheduled(cron = "0 0 2 * * ?") // 每天凌晨2点执行
public void cleanExpiredMails() {
    Date now = new Date();
    int deleted = mailDao.deleteExpired(now);
    log.info("Cleaned {} expired mails", deleted);
}
```

### 发送定时系统邮件

```java
@Scheduled(fixedRate = 60000) // 每分钟检查
public void sendScheduledMails() {
    List<SystemMail> pendingMails = systemMailDao.selectPending();
    for (SystemMail mail : pendingMails) {
        if (mail.getSendTime().before(new Date())) {
            sendSystemMail(mail);
            mail.setStatus(EMailStatus.SENT.getValue());
            systemMailDao.updateById(mail);
        }
    }
}
```

## 注意事项

1. 邮件ID需要全局唯一，建议使用雪花算法
2. 批量发送邮件时注意数据库性能
3. 奖励发放需要事务保证
4. 过期清理任务避开高峰期
