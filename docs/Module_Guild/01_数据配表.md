# 公会模块数据配表文档

## 配表说明

公会模块相关的配置数据主要存储在以下配表中:

---

## 一、公会基础配表

### GuildRefObj - 公会配置
**文件**: `guild_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 公会配置ID |
| name | string | 公会名称模板 |
| max_member | int | 最大成员数量 |
| create_cost | object | 创建消耗 |

---

### GuildLevelRefObj - 公会等级配置
**文件**: `guild_level_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| level | long | 公会等级 |
| max_member | int | 最大成员数量 |
| upgrade_exp | long | 升级所需经验 |
| upgrade_cost | object | 升级消耗 |
| unlock_feature | object | 解锁功能 |

---

## 二、公会职位配表

### GuildPositionRefObj - 公会职位配置
**文件**: `guild_position_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int | 职位ID |
| name | string | 职位名称 |
| authority | object | 权限列表 |
| max_count | int | 最大人数 |

**职位枚举**:
| 职位ID | 名称 | 说明 |
|--------|------|------|
| 1 | 盟主 | 公会创建者 |
| 2 | 副盟主 | 管理权限 |
| 3 | 长老 | 高级成员 |
| 4 | 成员 | 普通成员 |

---

## 三、公会建设配表

### GuildConstructRefObj - 公会建设配置
**文件**: `guild_construct_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 建设ID |
| name | string | 建设名称 |
| type | int | 建设类型 |
| cost | object | 建设消耗 |
| reward | object | 建设奖励 |
| guild_exp | long | 公会经验 |

---

## 四、公会技能配表

### GuildSkillRefObj - 公会技能配置
**文件**: `guild_skill_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 技能ID |
| name | string | 技能名称 |
| max_level | long | 最大等级 |
| unlock_guild_level | long | 解锁公会等级 |
| effect | object | 技能效果 |
| upgrade_cost | object | 升级消耗 |

---

## 五、公会宝箱配表

### GuildBoxRefObj - 公会宝箱配置
**文件**: `guild_box_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 宝箱ID |
| name | string | 宝箱名称 |
| quality | int | 品质 |
| condition | object | 开启条件 |
| reward | object | 奖励内容 |

---

## 六、配表加载方式

```csharp
// 获取公会等级配置
GuildLevelRefObj levelRef = GRefdataCoreMgr.instance.guildLevelRefCore.getRef(level);

// 获取公会职位配置
GuildPositionRefObj positionRef = GRefdataCoreMgr.instance.guildPositionRefCore.getRef(positionId);

// 获取公会建设配置
GuildConstructRefObj constructRef = GRefdataCoreMgr.instance.guildConstructRefCore.getRef(constructId);
```
