# 阶段目标数据配表文档

## 配表说明

阶段目标模块相关的配置数据主要存储在以下配表中:

---

## 一、大阶段配置表

### RefStageGoalBigStep - 大阶段配置
**文件**: `stage_goal_big_step.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| big_step | long | 大阶段ID |
| name | string | 阶段名称 |
| reward | object | 阶段奖励 |
| first_reach_reward | object | 首达奖励 |
| sub_task_list | List | 子任务列表 |

---

## 二、子任务配置表

### RefStageGoalTask - 子任务配置
**文件**: `stage_goal_task.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 任务ID |
| big_step_id | long | 所属大阶段ID |
| name | string | 任务名称 |
| condition | object | 完成条件 |
| reward | object | 任务奖励 |

---

## 三、首达奖励配置

### 首达奖励结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| items | List&lt;RewardItem&gt; | 奖励物品列表 |
| show_type | int | 展示类型 |

---

## 四、阶段目标数据结构

### StageGoal_BigStepFirstReachInfo - 大阶段首达信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| bigStepId | long | 大阶段ID |
| reachTimeMs | long | 达成时间 |
| playerList | List&lt;StageGoal_FirstReachPlayer&gt; | 首达玩家列表 |

### StageGoal_TopPlayerInfo - TOP1玩家信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| cid | long | 玩家CID |
| step | long | 阶段数 |

---

## 五、配表加载方式

```csharp
// 获取大阶段配置
RefStageGoalBigStep bigStepRef = GRefdataCoreMgr.instance.stageGoalBigStepRefCore.getRef(bigStepId);

// 获取子任务配置
RefStageGoalTask taskRef = GRefdataCoreMgr.instance.stageGoalTaskRefCore.getRef(taskId);
```

```java
// 服务端获取配置
RefStageGoalBigStep ref = RefStageGoalBigStep.getMgr().get(bigStepId);
```
