## 三、客户端请求协议 (GC2GS)

### 3.1 GC2GS_035_001_ReqMuseumInfo

**功能说明**: 请求博物馆信息

**触发场景**:
- 进入博物馆界面时
- 博物馆解锁时
- 刷新博物馆数据时

**请求参数**:

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| museumId | int | 是 | 博物馆ID（0表示所有） | 0 |

**返回协议**: GS2GC_035_050_OnMuseumInfo

**协议结构**:

```protobuf
message GC2GS_035_001_ReqMuseumInfo {
    int32 museum_id = 1;
}
```

**错误处理**:

| 错误码 | 触发条件 | 处理建议 |
|--------|----------|----------|
| 35020 | 博物馆未解锁 | 引导解锁条件 |
| 35021 | 博物馆不存在 | 检查配置 |

### 3.3 GC2GS_035_003_ReqMuseumItemUpgrade

**功能说明**: 请求升级藏品

**触发场景**:
- 点击升级按钮时
- 批量升级时

**请求参数**:

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| itemId | int | 是 | 藏品ID | 10001 |
| upgradeCount | int | 否 | 升级次数（默认1） | 5 |
| autoUse | bool | 否 | 是否自动使用材料 | true |
| useProtect | bool | 否 | 是否使用保护石 | false |

**返回协议**: GS2GC_035_052_OnMuseumItemChg

**协议结构**:

```protobuf
message GC2GS_035_003_ReqMuseumItemUpgrade {
    int32 item_id = 1;
    int32 upgrade_count = 2;
    bool auto_use = 3;
    bool use_protect = 4;
}
```

**业务流程**:

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant DB as 数据库
    participant Bag as 背包模块

    Client->>Server: ReqMuseumItemUpgrade(itemId, count)
    Server->>DB: 查询藏品信息
    DB-->>Server: 返回藏品数据

    alt 藏品不存在
        Server-->>Client: ErrCode:35001
    else 已满级
        Server-->>Client: ErrCode:35002
    else 材料不足
        Server-->>Client: ErrCode:35003
    else 升级成功
        loop 升级次数
            Server->>Bag: 检查材料
            alt 材料充足
                Server->>Bag: 扣除材料
                Server->>Server: 判定成功率
                alt 升级成功
                    Server->>DB: 等级+1
                else 升级失败 且 使用保护
                    Server->>Server: 保持等级
                else 升级失败 未使用保护
                    Server->>DB: 等级-1（可配置）
                end
            else 材料不足
                Server-->>Client: ErrCode:35003
                Note over Server: 中断升级循环
            end
        end
        Server->>DB: 更新属性
        Server-->>Client: OnMuseumItemChg
    end
```

### 3.4 GC2GS_035_004_ReqMuseumItemActive

|--------|------|------|------|--------|
| itemId | int | 是 | 藏品ID | 10001 |
| activeStage | int | 否 | 激活阶段（默认下一阶段） | 2 |

**返回协议**: GS2GC_035_052_OnMuseumItemChg + GS2GC_035_055_OnMuseumAttrChg + GS2GC_035_056_OnMuseumSetEffect

**协议结构**:

```protobuf
message GC2GS_035_004_ReqMuseumItemActive {
    int32 item_id = 1;
    int32 active_stage = 2;
}
```

**业务流程**:

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant AttrMgr as 属性管理器
    participant SetMgr as 套装管理器

    Client->>Server: ReqMuseumItemActive(itemId)
    Server->>Server: 检查激活条件

    alt 条件不满足
        Server-->>Client: ErrCode:35005
    else 已激活该阶段
        Server-->>Client: ErrCode:35004
    else 激活成功
        Server->>Server: 扣除激活材料
        Server->>Server: 更新激活状态
        Server->>AttrMgr: 应用属性加成
        AttrMgr-->>Server: 返回属性变更
        Server->>SetMgr: 检查套装效果
        SetMgr-->>Server: 返回套装变更
        Server-->>Client: OnMuseumItemChg
        Server-->>Client: OnMuseumAttrChg
        opt 套装效果变更
            Server-->>Client: OnMuseumSetEffect
        end
    end
```


**业务流程**:

```mermaid
flowchart TD
    A[请求设置展位] --> B{检查展位状态}
    B -->|展位被锁定| C[返回错误35008]
    B -->|展位空闲| D{检查藏品状态}
    B -->|展位已占用| E[先移出原藏品]

    E --> D
    D -->|藏品不存在| F[返回错误35001]
    D -->|藏品未解锁| G[返回错误35007]
    D -->|藏品在其他展位| H[从原展位移出]
    D -->|藏品可用| I[放入新展位]

    H --> I
    I --> J[计算展示收益]
    J --> K[推送展位变更]
```

**业务流程**:

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant Bag as 背包模块

    Client->>Server: ReqMuseumItemCompose(fragmentId, count)
    Server->>Server: 获取碎片配置
```
