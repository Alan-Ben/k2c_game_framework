## 核心逻辑

### 每日签到

```java
public void dailyCheck(long playerId) {
    PlayerDailyCheck check = dailyCheckDao.selectById(playerId);

    // 检查今日是否已签到
    if (check.getTodayChecked()) {
        throw new BusinessException(ErrorCode.ALREADY_CHECKED);
    }

    // 发放奖励
    DailyCheckConfig config = dailyCheckConfigDao.getByDay(check.getTotalCheckDays() + 1);
    itemService.giveItems(playerId, config.getRewardList());

    // VIP双倍
    PlayerBase player = playerDao.selectById(playerId);
    if (player.getVipLevel() >= config.getVipDoubleNeed()) {
        itemService.giveItems(playerId, config.getRewardList());
    }

    // 更新签到数据
    check.setTodayChecked(true);
    check.setTotalCheckDays(check.getTotalCheckDays() + 1);
    check.setLastCheckTime(new Date());
    dailyCheckDao.updateById(check);

    // 更新七日登录天数
    updateSevenDayLogin(playerId);
}
```

### 领取七日奖励

```java
public void takeSevenDayReward(long playerId, int day) {
    PlayerSevenDayLogin login = sevenDayLoginDao.selectById(playerId);

    if (login.getLoginDay() < day) {
        throw new BusinessException(ErrorCode.DAY_NOT_REACHED);
    }

    if (login.getRewardTakenList().contains(day)) {
        throw new BusinessException(ErrorCode.REWARD_ALREADY_TAKEN);
    }

    // 发放奖励
    SevenDayLoginConfig config = sevenDayConfigDao.getByDay(day);
    itemService.giveItems(playerId, config.getRewardList());

    // 记录领取
    login.getRewardTakenList().add(day);
    sevenDayLoginDao.updateById(login);
}
```

## 定时任务

### 每日重置

```java
@Scheduled(cron = "0 0 0 * * ?")
public void dailyReset() {
    // 重置今日签到状态
    dailyCheckDao.resetTodayChecked();
}
```

## 注意事项

1. 签到天数需要每日重置
2. 七日登录从首次登录开始计算
3. 目标进度需要单独追踪
