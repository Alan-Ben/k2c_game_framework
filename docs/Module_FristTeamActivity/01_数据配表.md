# FristTeamActivityOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p003
**模块名称**: FristTeamActivityOp (首期组队活动操作)
**主要功能**: 提供游戏活动逻辑测试接口，用于活动系统的调试和验证

## 配置文件

本模块为测试/调试模块，主要依赖 CommonActivity 通用活动配置。

### 关联配置表

| 配置表名称 | 用途 | 位置 |
|-----------|------|------|
| ActivityConfig | 活动基础配置 | 游戏配置系统 |
| ActivityInstanceConfig | 活动实例配置 | 游戏配置系统 |

## 数据结构

### 活动实例标识

```java
// 活动实例ID
long instanceId;
```

## 配置字段说明

### 测试参数配置

| 字段名 | 类型 | 说明 |
|--------|------|------|
| instanceId | long | 活动实例唯一标识 |
| param1 | int | 测试参数1 |

## 配置加载流程

1. 服务器启动时加载活动配置
2. 根据配置创建活动实例
3. 客户端通过 instanceId 访问特定活动实例

## 注意事项

- 本模块主要用于开发测试阶段
- 生产环境可能禁用部分测试功能
- 与 CommonActivityMgr 紧密关联
