# 宴会系统 - 数据配表

## 概述

宴会系统 (DinnerOp, p019) 是游戏中的社交玩法，玩家可以举办宴会邀请其他玩家参加，获得奖励。

## 配表文件

### 1. 宴会配置 (Dinner)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dinner_id | int | 宴会ID |
| dinner_name | string | 宴会名称 |
| dinner_type | int | 宴会类型 |
| max_joiner | int | 最大参与人数 |
| duration | int | 持续时间(秒) |
| cost_list | array | 举办消耗 |
| reward_list | array | 基础奖励 |

### 2. 宴会许可配置 (DinnerPermit)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| permit_id | int | 许可ID |
| permit_name | string | 许可名称 |
| extra_reward | array | 额外奖励 |
| special_guest | int | 特殊客人 |

### 3. 宴会食物配置 (DinnerFood)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| food_id | int | 食物ID |
| food_name | string | 食物名称 |
| food_quality | int | 食物品质 |
| guest_like | array | 喜欢的客人类型 |

## 宴会状态枚举

```csharp
public enum EDinnerState
{
    PREPARING = 0,  // 准备中
    ONGOING = 1,    // 进行中
    ENDED = 2       // 已结束
}
```

## 宴会类型枚举

```csharp
public enum EDinnerType
{
    NORMAL = 1,     // 普通宴会
    LUXURY = 2,     // 豪华宴会
    ROYAL = 3       // 皇家宴会
}
```
