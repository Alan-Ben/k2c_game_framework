# 聊天模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### NPPlayerChatComponent
**路径**: `GameComponent/NPChat/NPPlayerChatComponent.cs`

**功能**: 聊天管理器，管理玩家聊天数据

**继承关系**:
```
NPPlayerChatComponent : _ANPBasicPlayerComponent
```

**协议模块**: p022_ChatOp

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| channelList | List<ChatChannelInfo> | 频道列表 |
| privateChatList | List<PrivateChatInfo> | 私聊列表 |
| unreadCount | int | 未读消息数 |

---

### 1.2 聊天信息类

#### ChatChannelInfo
**功能**: 聊天频道数据

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| channelId | int | 频道ID |
| channelType | int | 频道类型 |
| messageList | List<ChatMessage> | 消息列表 |
| lastMsgTime | long | 最后消息时间 |

#### ChatMessage
**功能**: 聊天消息

| 属性名 | 类型 | 说明 |
|--------|------|------|
| senderId | long | 发送者ID |
| senderName | string | 发送者名称 |
| content | string | 消息内容 |
| sendTime | long | 发送时间 |
| msgType | int | 消息类型 |

---

## 二、协议接口

### 2.1 请求协议

| 协议名 | 说明 |
|--------|------|
| GC2GS_022_001_ReqSendChat | 发送聊天消息 |
| GC2GS_022_002_ReqChatHistory | 请求聊天历史 |
| GC2GS_022_003_ReqPrivateChatList | 请求私聊列表 |
| GC2GS_022_004_ReqSetBlackList | 设置黑名单 |

### 2.2 响应协议

| 协议名 | 说明 |
|--------|------|
| GS2GC_022_001_RetSendChat | 发送结果 |
| GS2GC_022_002_RetChatHistory | 聊天历史 |
| GS2GC_022_050_OnChatMessage | 新消息推送 |

---

## 三、频道类型

| 类型 | 说明 |
|------|------|
| 世界频道 | 全服广播 |
| 公会频道 | 公会内部聊天 |
| 私聊频道 | 一对一聊天 |
| 系统频道 | 系统消息 |

## 四、UI窗口

| 类名 | 说明 |

## 五、访问方式

```csharp
// 获取聊天组件
NPPlayerChatComponent chatComp = NPPlayer.instance.chatComp;

// 获取未读消息数
int unread = chatComp.unreadCount;

// 获取频道列表
var channels = chatComp.channelList;
```
