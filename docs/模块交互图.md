# K2C 游戏框架模块交互图

## 一、核心模块交互

### 1.1 玩家登录交互流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Gateway as 网关
    participant Login as 登录服务
    participant GameServer as 游戏服务
    participant Player as Player模块
    participant Hero as Hero模块
    participant Bag as Bag模块
    participant Quest as Quest模块

    Client->>Gateway: 连接请求
    Gateway->>Login: 登录验证
    Login-->>Gateway: 验证通过
    Gateway->>GameServer: 创建会话
    GameServer->>Player: 加载玩家数据
    Player->>Hero: 加载英雄列表
    Player->>Bag: 加载背包数据
    Player->>Quest: 加载任务数据
    GameServer-->>Client: 推送初始数据
```

### 1.2 英雄升级交互流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Hero as Hero模块
    participant Player as Player模块
    participant Bag as Bag模块
    participant Quest as Quest模块

    Client->>Hero: 请求升级英雄
    Hero->>Player: 检查资源是否足够
    Player-->>Hero: 返回资源状态
    Hero->>Player: 扣减升级资源
    Hero->>Hero: 执行升级逻辑
    Hero->>Quest: 触发任务事件
    Quest-->>Client: 推送任务进度
    Hero-->>Client: 推送升级结果
    Hero->>Player: 重新计算实力
    Player-->>Client: 推送实力变化
```

### 1.3 装备穿戴交互流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Hero as Hero模块
    participant Bag as Bag模块
    participant Player as Player模块

    Client->>Hero: 请求穿戴装备
    Hero->>Bag: 检查装备是否存在
    Bag-->>Hero: 返回装备信息
    Hero->>Hero: 检查装备位置
    alt 已有装备
        Hero->>Bag: 卸下原装备
    end
    Hero->>Bag: 标记装备已穿戴
    Hero->>Hero: 更新英雄装备槽
    Hero->>Player: 重新计算实力
    Hero-->>Client: 推送穿戴结果
    Bag-->>Client: 推送背包变化
```

## 二、战斗模块交互

### 2.1 竞技场挑战交互流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Arena as Arena模块
    participant Player as Player模块
    participant Hero as Hero模块
    participant Rank as 排行榜

    Client->>Arena: 请求挑战玩家
    Arena->>Player: 获取挑战者信息
    Arena->>Hero: 获取挑战者英雄
    Arena->>Player: 获取被挑战者信息
    Arena->>Hero: 获取被挑战者英雄
    Arena->>Arena: 执行战斗计算
    alt 挑战胜利
        Arena->>Rank: 更新排名
        Arena->>Player: 发放胜利奖励
    else 挑战失败
        Arena->>Player: 发放参与奖励
    end
    Arena-->>Client: 推送战斗结果
    Rank-->>Client: 推送排名变化
```

```mermaid
sequenceDiagram
```


### 3.3 聊天消息交互流程

```mermaid
sequenceDiagram

    participant Chat as Chat模块
    participant Player as Player模块
    participant Client2 as 接收方客户端

    Client1->>Chat: 发送消息
    Chat->>Player: 获取发送者信息
    Chat->>Chat: 检查消息内容
    alt 世界频道

    else 私聊
        Chat->>Client2: 发送给指定玩家
    end
    Chat-->>Client1: 推送发送成功
```

## 四、任务系统交互

### 4.1 任务触发交互流程

```mermaid
sequenceDiagram
    participant EventSource as 事件源模块
    participant Quest as Quest模块
    participant Player as Player模块
    participant Bag as Bag模块
    participant Client as 客户端

    EventSource->>Quest: 触发游戏事件
    Quest->>Quest: 匹配任务目标
    Quest->>Quest: 更新任务进度
    alt 任务完成
        Quest->>Client: 推送任务完成通知
    else 进度更新
        Quest->>Client: 推送进度变化
    end

    Note over Client: 玩家领取奖励
    Client->>Quest: 请求领取奖励
    Quest->>Bag: 发放任务奖励
    Quest->>Quest: 接取后续任务
    Quest-->>Client: 推送领取成功
```

### 4.2 活跃度计算交互流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Quest as Quest模块
    participant Bag as Bag模块

    Client->>Quest: 完成日常任务
    Quest->>Quest: 计算活跃度
    Quest->>Client: 推送活跃度变化
    alt 达到活跃度档位
        Quest->>Client: 解锁档位奖励
    end

    Client->>Quest: 请求领取活跃度奖励
    Quest->>Bag: 发放奖励
    Quest-->>Client: 推送领取成功
```
