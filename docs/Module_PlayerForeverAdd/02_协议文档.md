# 永久属性加成协议文档

## 协议模块编号: p002 (InitOp) / p021 (PlayerInfo)

---

## 一、客户端请求协议 (GC2GS)

### 1.1 初始化相关

#### GC2GS_002_069_ReqForeverAddInit - 请求永久加成初始化
**功能说明**: 请求获取玩家所有永久加成数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| (无参数) | - | - |

---

## 二、服务端响应协议 (GS2GC)

### 2.1 初始化响应

#### GS2GC_002_069_RetForeverAddInit - 返回永久加成初始化数据
**功能说明**: 返回玩家所有永久加成数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| addList | List&lt;NPCommon_ForeverAddInfo&gt; | 永久加成列表 |

---

### 2.2 推送通知协议

#### GS2GC_021_075_OnForeverAddChg - 永久加成变化推送
**功能说明**: 推送永久加成数据变化

| 字段名 | 类型 | 说明 |
|--------|------|------|
| add | NPCommon_ForeverAddInfo | 变化的加成信息 |

---

## 三、数据结构

### NPCommon_ForeverAddInfo - 永久加成信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 加成ID |
| count | int | 加成次数 |

---

## 四、协议调用流程

### 4.1 永久加成初始化流程
```
客户端                          服务端
   |                               |
   |--- ReqForeverAddInit -------->|
   |                               | (查询玩家永久加成数据)
   |<-- RetForeverAddInit ---------|
   |                               |
```

### 4.2 永久加成变化流程
```
服务端                           客户端
   |                               |
   | (玩家获得永久加成)             |
   |--- OnForeverAddChg ---------->|
   |                               | (更新本地数据)
   |                               |
```

---

## 五、物品类型

### ENPItemType.FOREVER_ADD

永久加成作为一种特殊的物品类型处理：

- 可以通过奖励系统发放
- 可以作为消耗品使用
- 支持数量限制检查
