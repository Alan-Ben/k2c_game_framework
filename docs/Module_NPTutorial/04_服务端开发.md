# 引导系统服务端开发文档

## 一、模块架构

### 1.1 模块概述

引导系统（Tutorial System）负责管理玩家的引导数据，包括：
- 强制引导进度管理
- 可选引导完成状态记录
- 引导触发条件判断

### 1.2 数据存储

引导数据存储在玩家数据中，不单独使用组件管理。

---

## 二、核心数据结构

### 2.1 引导数据 (TutorialData)

**路径**: `ServerProtocol/src/Common/TutorialData.java`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| lastFinishForceTutorial | long | 最后完成的强制引导ID |
| finishTutorialId | ArrayList&lt;Long&gt; | 已完成的引导ID列表 |

---

## 三、引导数据处理

### 3.1 引导完成记录

```java
// 完成强制引导
public void finishForceTutorial(long tutorialId)
{
    if (tutorialId > tutorialData.getLastFinishForceTutorial())
    {
        tutorialData.setLastFinishForceTutorial(tutorialId);
    }
}

// 完成可选引导
public void finishOptionalTutorial(long tutorialId)
{
    if (!tutorialData.getFinishTutorialId().contains(tutorialId))
    {
        tutorialData.addFinishTutorialId(tutorialId);
    }
}
```

### 3.2 引导状态查询

```java
// 判断引导是否已完成
public boolean isTutorialFinished(long tutorialId)
{
    return tutorialData.getFinishTutorialId().contains(tutorialId);
}

// 判断强制引导进度
public boolean needTriggerForceTutorial(long tutorialId)
{
    return tutorialId > tutorialData.getLastFinishForceTutorial();
}
```

## 四、引导触发机制

### 4.1 触发条件

引导触发条件在配置表中定义，常见条件包括：

| 条件类型 | 说明 |
|----------|------|
| 等级达到 | 玩家等级达到指定值 |
| 功能解锁 | 特定功能解锁后触发 |
| 前置引导完成 | 完成前置引导后触发 |

### 4.2 引导关联

引导系统与其他系统的关联：

| 系统 | 关联方式 |
|------|----------|
| 功能解锁系统 | 功能解锁时触发对应引导 |
| 战斗系统 | 战斗中触发战斗引导 |
| 建筑系统 | 建筑操作相关引导 |
