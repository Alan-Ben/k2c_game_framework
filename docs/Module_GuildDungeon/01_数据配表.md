# GuildDungeonOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p037
**模块名称**: GuildDungeonOp (公会副本操作)
**主要功能**: 提供公会副本战斗、伤害排行、奖励领取等功能

## 配置文件

### 关联配置表

| 配置表名称 | 用途 |
|-----------|------|
| GuildDungeonConfig | 公会副本基础配置 |
| GuildDungeonMonsterConfig | 副本怪物配置 |
| GuildDungeonRewardConfig | 副本奖励配置 |
| GuildDungeonLevelConfig | 副本等级配置 |

## 数据结构

### 公会副本设置信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| dungeonLevel | int | 副本等级 |
| autoStart | boolean | 是否自动开启 |
| tagMonsterList | List | 标记怪物列表 |

### 副本实例信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| instanceId | long | 实例ID |
| monsterId | int | 当前怪物ID |
| monsterHp | long | 怪物当前血量 |
| monsterMaxHp | long | 怪物最大血量 |
| startTime | long | 开启时间 |

### 英雄战斗信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| heroId | long | 英雄ID |
| fightCount | int | 战斗次数 |
| totalDamage | long | 总伤害 |

### 伤害排行信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| cid | long | 玩家CID |
| damage | long | 伤害值 |
| rank | int | 排名 |
