# 招募系统 - 数据配表

## 概述

招募系统 (Recruit) 是游戏中的抽卡玩法，玩家可以通过招募获得英雄、伴侣等角色。

## 配表文件

### 1. 招募池配置 (RecruitPool)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| pool_id | int | 招募池ID |
| pool_name | string | 招募池名称 |
| pool_type | int | 招募池类型 |
| item_list | array | 物品列表 |
| guarantee_config | json | 保底配置 |

### 2. 招募项配置 (RecruitItem)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| item_id | int | 物品ID |
| item_type | int | 物品类型(英雄/伴侣/道具) |
| weight | int | 权重 |
| rarity | int | 稀有度 |

### 3. 招募商店配置 (RecruitShop)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| shop_id | int | 商店ID |
| shop_name | string | 商店名称 |
| item_list | array | 商品列表 |
| refresh_time | int | 刷新时间 |

### 4. 保底配置 (RecruitGuarantee)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| guarantee_id | int | 保底ID |
| guarantee_count | int | 保底次数 |
| guarantee_rarity | int | 保底稀有度 |

## 招募类型枚举

```csharp
public enum ERecruitType
{
    NORMAL = 1,     // 普通招募
    HERO = 2,       // 英雄招募
    CONSORT = 3,    // 伴侣招募
    SPECIAL = 4     // 特殊招募
}
```

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Recruit/`
- 服务端配置：`game_server/Config/recruit/`
