# 章节模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerChapterComponent
**路径**: `GameComponent/Chapter/PlayerChapterComponent.cs`

**功能**: 章节管理器，管理玩家关卡进度数据

**继承关系**:
```
PlayerChapterComponent : _ANPBasicPlayerComponent
```

**协议模块**: p016_ChapterOp

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| curChapterId | long | 当前章节ID |
| curNodeId | long | 当前节点ID |
| chapterList | List<ChapterInfo> | 章节列表 |
| forwardLogicMgr | ChapterForwardLogicMgr | 推进逻辑管理器 |

---

### 1.2 章节信息类

#### ChapterInfo
**功能**: 单个章节数据

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| chapterId | long | 章节ID |
| nodeList | List<NodeInfo> | 节点列表 |
| status | int | 章节状态 |
| progress | float | 进度 |

---

### 1.3 状态机管理

#### ChapterForwardLogicMgr
**路径**: `GameComponent/Chapter/ChapterForwardLogicMgr.cs`

**功能**: 章节推进状态机管理

**状态类型**:
- NoneState - 无状态
- IdleState - 空闲
- OnceForwardState - 单次推进
- AutoBattleState - 自动战斗
- DialogState - 对话
- FightBossState - 战斗Boss
- ChapterCompleteState - 章节完成

---

## 二、协议接口

### 2.1 请求协议

| 协议名 | 说明 |
|--------|------|
| GC2GS_016_001_ReqStartChapter | 开始章节 |
| GC2GS_016_002_ReqFinishNode | 完成节点 |
| GC2GS_016_003_ReqChapterReward | 领取章节奖励 |

### 2.2 响应协议

| 协议名 | 说明 |
|--------|------|
| GS2GC_016_001_RetStartChapter | 开始章节结果 |
| GS2GC_016_002_RetFinishNode | 完成节点结果 |
| GS2GC_016_050_OnChapterProgress | 章节进度推送 |
| GS2GC_016_051_OnChapterComplete | 章节完成推送 |
