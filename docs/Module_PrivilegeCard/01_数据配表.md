# 权益卡数据配表文档

## 配表说明

权益卡模块相关的配置数据主要存储在以下配表中:

---

## 一、权益卡配置表

### RefPrivilegeCard - 权益卡配置
**文件**: `privilege_card.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 权益卡ID |
| cardType | EPrivilegeCardType | 权益卡类型 |
| duration_days | int | 有效天数 |
| daily_reward | object | 每日奖励 |
| bonus_prop_modifier | PlayerBonusPropertyModifier | 属性加成修改器 |
| player_pro | NPPlayerPropertyModifier | 玩家属性加成 |

---

## 二、权益卡类型枚举

### EPrivilegeCardType - 权益卡类型

| 枚举值 | 说明 |
|--------|------|
| NONE | 无 |
| MONTH | 月卡 |
| YEAR | 年卡 |

---

## 三、奖励配置

### 每日奖励结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| items | List&lt;RewardItem&gt; | 奖励物品列表 |
| count | int | 奖励数量 |

---

## 四、属性加成配置

### PlayerBonusPropertyModifier - 属性加成修改器

| 字段名 | 类型 | 说明 |
|--------|------|------|
| bonusType | EBonusPropertyType | 加成属性类型 |
| value | long | 加成值 |
| ratio | float | 加成比例 |

---

## 五、配表加载方式

```csharp
// 获取权益卡配置
GSOPrivilegeCardRefSet refSet = GRefdataCoreMgr.instance.privilegeCardRefSet;
PrivilegeCardRefObj cardRef = refSet.getRef(cardType);
```

```java
// 服务端获取配置
RefPrivilegeCard ref = RefPrivilegeCard.getMgr().get(cardId);
```

---

## 六、配置示例

```json
{
  "id": 1,
  "cardType": "MONTH",
  "duration_days": 30,
  "daily_reward": {
    "items": [
      {"itemId": 1001, "count": 100}
    ]
  },
  "bonus_prop_modifier": {
    "bonusType": "SPEED",
    "value": 100,
    "ratio": 0.1
  }
}
```
