## 核心类

### SevenDayGoalsComponent

七日目标玩家数据组件，存储玩家七日目标进度和奖励领取状态。

### RechargeRebateInfo

充值返利活动信息，支持:
- RechargeRebateInfo_Daily: 每日返利
- RechargeRebateInfo_Days: 多日累计返利

## 业务逻辑

### 收益目标处理

1. 检查活动有效性
2. 计算目标进度
3. 验证奖励领取条件
4. 发放奖励

### 七日目标处理

1. 根据开服时间计算天数
2. 更新任务进度
3. 验证领取条件
4. 发放奖励并更新状态

### 充值返利处理

1. 记录充值金额
2. 按配置计算返利
3. 发放返利奖励
