# 通用操作 - 数据配表

## 概述

通用操作模块 (CommOp, p007) 处理游戏中的通用功能，包括招募、抽卡、问卷调查、阶段目标、红点系统等。

## 配表文件

### 1. 招募配置 (Recruit)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| recruit_id | int | 招募ID |
| recruit_type | int | 招募类型 |
| cost_list | array | 消耗列表 |
| reward_pool | array | 奖励池 |
| guarantee_id | int | 保底ID |

### 2. 抽卡配置 (Gacha)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| gacha_id | int | 抽卡ID |
| gacha_type | int | 抽卡类型 |
| pool_id | int | 奖池ID |
| cost | array | 消耗 |
| guarantee_count | int | 保底次数 |
| cumulative_reward | array | 累计奖励 |

### 3. 阶段目标配置 (StageGoal)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| goal_id | int | 目标ID |
| stage | int | 阶段 |
| task_list | array | 任务列表 |
| reward | array | 奖励 |

### 4. 问卷配置 (Questionnaire)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| questionnaire_id | int | 问卷ID |
| title | string | 标题 |
| question_list | array | 问题列表 |
| reward | array | 奖励 |

### 5. 红点配置 (RedDot)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| red_id | int | 红点ID |
| parent_id | int | 父红点ID |
| module_type | int | 模块类型 |
| condition | json | 触发条件 |

## 数据类型枚举

### 招募类型

```csharp
public enum ERecruitType
{
    NORMAL = 1,     // 普通招募
    HERO = 2,       // 英雄招募
    CONSORT = 3,    // 伴侣招募
    SPECIAL = 4     // 特殊招募
}
```

### 抽卡类型

```csharp
public enum EGachaType
{
    NORMAL = 1,     // 普通抽卡
    LIMIT = 2,      // 限定抽卡
    FRIEND = 3      // 友情抽卡
}
```

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Recruit/`
- 服务端配置：`game_server/Config/recruit/`

## 注意事项

1. 招募和抽卡需要配置保底机制
2. 红点系统需要支持层级关系
3. 阶段目标需要配置完成条件
