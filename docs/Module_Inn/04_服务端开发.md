### 结算

```java
public void settle(long playerId, int stationId) {
    // 1. 获取座位信息
    PlayerInnStation station = stationDao.selectByPlayerAndId(playerId, stationId);
    if (station.getGuestId() == null || station.getGuestId() <= 0) {
        throw new BusinessException(ErrorCode.NO_GUEST);
    }

    // 2. 检查时间
    InnGuestConfig guestConfig = guestConfigDao.getById(station.getGuestId());
    long elapsed = System.currentTimeMillis() - station.getGuestStartTime().getTime();
    if (elapsed < guestConfig.getMinStayTime() * 1000) {
        throw new BusinessException(ErrorCode.GUEST_NOT_READY);
    }

    // 3. 发放奖励
    itemService.giveItems(playerId, guestConfig.getRewardList());

    // 4. 清空座位
    station.setGuestId(null);
    station.setGuestStartTime(null);
    stationDao.updateById(station);

    // 5. 更新人气
    updatePopularity(playerId, guestConfig.getPopularityAdd());
}
```

## 注意事项

1. 客人有最短停留时间
2. 菜品品质影响奖励
3. 勋章等级提供加成
