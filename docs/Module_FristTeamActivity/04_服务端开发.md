## 消息处理器

### MsgDealer_GC2GS_003_001_ReqGameLogicTest

**文件位置**: `NPUserMsgDispather/p003_FristTeamActivityOp/MsgDealer_GC2GS_003_001_ReqGameLogicTest.java`

**处理流程**:

```java
@Override
protected void _dealMessage(_ANPUSUserBasicMsgItem _commiter,
                            GC2GS_003_001_ReqGameLogicTest _msg)
{
    // 1. 获取用户数据
    NPUSUserData userData = _commiter.getUserData();

    // 2. 查找活动实例
    _AActivityBase activity = userData.getUSServer()
        .getCommActivityMgr()
        .lookupActivity(_msg.getInstanceId());

    // 3. 获取活动逻辑处理器
    ActivityGameLogicDealer dealer = activity.getGameLogicDealer();

    // 4. 执行逻辑处理
    dealer.dealMsg(_commiter, userData.getCid(), 0, _msg, null, callback);
}
```

### 关键依赖类

| 类名 | 说明 |
|------|------|
| _AActivityBase | 活动基类 |
| ActivityGameLogicDealer | 活动游戏逻辑处理器 |
| CommonActivityMgr | 通用活动管理器 |

## 业务逻辑

### 活动实例查找

通过 `CommonActivityMgr.lookupActivity(instanceId)` 查找活动实例。

### 逻辑分发

活动逻辑处理器负责将消息分发给对应的活动逻辑处理函数。
