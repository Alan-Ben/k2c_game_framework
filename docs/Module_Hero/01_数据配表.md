# 英雄模块数据配表文档

## 配表说明

英雄模块相关的配置数据主要存储在以下配表中:

---

## 一、英雄基础配表

### HeroRefObj - 英雄静态配置
**文件**: `hero_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 英雄配置ID |
| name | string | 英雄名称 |
| suit_id | long | 所属套系ID |
| halo_id | long | 光环ID |
| spec_attr_type | int | 相性类型 |
| init_level | long | 初始等级 |
| init_step | long | 初始阶段 |
| init_star | long | 初始觉醒星级 |
| quality | int | 品质 |

---

### HeroLevelRefObj - 英雄等级配置
**文件**: `hero_level_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| level | long | 等级 |
| exp | long | 升级所需经验 |
| attr_add | object | 属性加成 |

---

### HeroStepRefObj - 英雄阶段配置
**文件**: `hero_step_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| step | long | 阶段 |
| level_limit | long | 等级上限 |
| cost | object | 突破消耗 |
| attr_add | object | 属性加成 |

---

### HeroStarRefObj - 英雄觉醒配置
**文件**: `hero_star_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| star | long | 觉醒星级 |
| cost | object | 觉醒消耗 |
| attr_add | object | 属性加成 |
| skill_unlock | long | 解锁技能ID |

---

## 七、配表加载方式

```csharp
// 获取英雄静态配置
HeroRefObj heroRef = GRefdataCoreMgr.instance.heroRefCore.getRef(heroId);

// 获取英雄等级配置
HeroLevelRefObj levelRef = GRefdataCoreMgr.instance.heroLevelRefCore.getRef(level);

// 获取英雄皮肤配置
HeroSkinRefObj skinRef = GRefdataCoreMgr.instance.heroSkinRefCore.getRef(skinId);
```
