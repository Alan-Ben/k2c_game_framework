# 初始化系统 - 数据配表

## 概述

初始化系统 (InitOp, p002) 负责玩家登录时的所有数据初始化同步，是客户端与服务端数据同步的核心模块。

## 配表文件

### 1. 初始化顺序配置 (InitOrder)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| order_id | int | 顺序ID |
| module_id | int | 模块ID |
| module_name | string | 模块名称 |
| depend_list | array | 依赖模块列表 |
| is_async | bool | 是否异步加载 |

### 2. 模块配置 (InitModule)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| module_id | int | 模块ID |
| protocol_id | int | 协议ID |
| cache_time | int | 缓存时间(秒) |
| is_required | bool | 是否必须 |

## 初始化流程

1. **玩家登录** → 发送 GC2GS_002_001_ReqPlayerInfo
2. **核心数据** → 同步玩家基础信息
3. **模块数据** → 按配置顺序依次请求
4. **依赖检查** → 确保依赖模块已加载
5. **初始化完成** → 进入游戏主界面

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Init/`
- 服务端配置：`game_server/Config/init/`

## 注意事项

1. 模块初始化顺序必须严格遵守依赖关系
2. 可选模块加载失败不应阻止进入游戏
3. 大数据量模块建议分批加载
4. 缓存配置影响重复登录时的加载速度
