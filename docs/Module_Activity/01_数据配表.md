# 活动模块数据配表文档

## 配表说明

活动模块相关的配置数据主要存储在以下配表中:

---

## 一、活动基础配表

### ActivityRefObj - 活动配置
**文件**: `activity_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 活动配置ID |
| name | string | 活动名称 |
| type | int | 活动类型 |
| start_time | long | 开始时间戳 |
| end_time | long | 结束时间戳 |
| condition | object | 参与条件 |
| reward | object | 基础奖励 |

**活动类型枚举**:
| 类型ID | 说明 |
|--------|------|
| 1 | 限时活动 |
| 2 | 累计充值活动 |
| 3 | 消费返利活动 |
| 4 | 七日目标活动 |
| 5 | 收益目标活动 |
| 6 | 排行榜活动 |

---

## 二、活动任务配表

### ActivityTaskRefObj - 活动任务配置
**文件**: `activity_task_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 任务ID |
| activity_id | long | 所属活动ID |
| name | string | 任务名称 |
| target | object | 任务目标 |
| reward | object | 任务奖励 |
| step | int | 任务步骤 |

---

## 三、活动商店配表

### ActivityShopRefObj - 活动商店配置
**文件**: `activity_shop_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 商店ID |
| activity_id | long | 所属活动ID |
| item_list | array | 商品列表 |
| refresh_type | int | 刷新类型 |
| refresh_cost | object | 刷新消耗 |

---

## 四、活动基金配表

### ActivityFundRefObj - 活动基金配置
**文件**: `activity_fund_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 基金ID |
| name | string | 基金名称 |
| price | long | 购买价格 |
| total_reward | long | 总奖励价值 |
| reward_list | array | 奖励列表 |

---

## 五、充值返利配表

### RechargeRebateRefObj - 充值返利配置
**文件**: `recharge_rebate_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 配置ID |
| activity_id | long | 所属活动ID |
| min_recharge | long | 最低充值金额 |
| max_recharge | long | 最高充值金额 |
| rebate_ratio | float | 返利比例 |

---

## 六、配表加载方式

```csharp
// 获取活动配置
ActivityRefObj activityRef = GRefdataCoreMgr.instance.activityRefCore.getRef(activityId);

// 获取活动任务配置
ActivityTaskRefObj taskRef = GRefdataCoreMgr.instance.activityTaskRefCore.getRef(taskId);

// 获取活动商店配置
ActivityShopRefObj shopRef = GRefdataCoreMgr.instance.activityShopRefCore.getRef(shopId);
```
