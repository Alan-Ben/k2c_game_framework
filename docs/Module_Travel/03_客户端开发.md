## 数据类

### TravelConsortInfo

游历妃子信息管理类：

```csharp
public class TravelConsortInfo
{
    private long _m_lConsortId;     // 妃子ID
    private int _m_iLike;            // 好感度
    private ConsortRefShowInfo _m_rConsortRefShowInfo;  // 妃子显示信息
    private TravelConsortRefObj _m_rTravelConsortRefObj; // 游历妃子配表数据

    // 更新妃子信息
    public void updateInfo(Travel_Consort _serverTravelConsort)
    {
        _m_lConsortId = _serverTravelConsort.getConsortId();
        _m_iLike = _serverTravelConsort.getLike();
    }
}
```

## 事件处理

### 事件类型枚举

```csharp
public enum ETravelEventType
{
    Reward = 1,         // 奖励事件
    Gamble = 2,         // 赌博事件
    Invitation = 3,     // 邀请事件
    ConsortBar = 4,     // 妃子酒吧事件
    ConsortLike = 5,    // 妃子好感事件
    ConsortIntimacy = 6, // 妃子亲密度事件
    Gifted = 7,         // 赠礼事件
    Change = 8,         // 变换事件
    AddPower = 9        // 加力事件
}
```

### 事件处理流程

1. **接收事件通知**：服务端推送 GS2GC_008_050_OnEventAdd
2. **显示事件界面**：根据事件类型显示对应UI
3. **玩家操作**：玩家选择处理方式
4. **发送请求**：发送对应的处理请求协议
5. **处理结果**：接收服务端返回，更新UI

## UI 窗口

### 游历主界面

主要功能：
- 显示当前游历状态
- 显示游历位置列表
- 显示可触发的事件
- 一键游历按钮

### 事件处理界面

根据不同事件类型显示：
- 奖励预览
- 选择按钮
- 确认/取消操作

### 妃子互动界面

显示妃子信息和互动选项：
- 妃子头像、名称
- 好感度进度
- 互动按钮

## 协议对接

### 发送请求

```csharp
// 开始游历
public void reqStartTravel()
{
    NPGSClientListener.sendMsg(GSWriter_008_TravelOp.make_008_001_ReqStartTravel());
}

// 一键游历
public void reqAkeyTravel()
{
    NPGSClientListener.sendMsg(GSWriter_008_TravelOp.make_008_002_ReqAkeyTravel());
}

// 处理事件
public void reqDealEvent(int eventId, ETravelEventType eventType)
{
    switch(eventType)
    {
        case ETravelEventType.Reward:
            NPGSClientListener.sendMsg(GSWriter_008_TravelOp.make_008_003_ReqDealRewardTravel(eventId));
            break;
        // ... 其他事件类型
    }
}
```

### 接收响应

```csharp
// 接收事件添加通知
public void onEventAdd(GS2GC_008_050_OnEventAdd _msg)
{
    var eventInfo = _msg.getEventInfo();
    // 处理事件显示逻辑
    showEventUI(eventInfo);
}

// 接收妃子变化通知
public void onConsortChg(GS2GC_008_052_OnConsortChg _msg)
{
    var consortInfo = _msg.getConsortInfo();
    // 更新妃子信息显示
    updateConsortUI(consortInfo);
}
```

## 红点系统

游历系统红点触发条件：
- 有新事件待处理
- 游历完成可领取奖励
- 妃子好感度达到新阶段

## 注意事项

1. 事件处理需要根据事件类型选择对应的请求协议
2. 妃子事件需要先解锁对应妃子
3. 一键游历会自动处理所有可处理的事件
4. 注意处理网络异常情况，避免重复请求
