# MarsExploreOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p041
**模块名称**: MarsExploreOp (火星探索操作)
**主要功能**: 提供火星探索、矿点采集、公会分享等功能

## 配置文件

### 关联配置表

| 配置表名称 | 用途 |
|-----------|------|
| MarsExploreConfig | 火星探索配置 |
| MarsMineConfig | 火星矿点配置 |
| MarsExploreTeamConfig | 探索队伍配置 |
| MarsRepairConfig | 修复配置 |

## 数据结构

### 探索队伍信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| teamId | long | 队伍ID |
| teamState | int | 队伍状态 |
| currentMineId | long | 当前矿点ID |
| repairEndTime | long | 修复结束时间 |

### 矿点信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| mineId | long | 矿点ID |
| mineType | int | 矿点类型 |
| resourceId | int | 资源ID |
| resourceCount | long | 资源数量 |
| ownerCid | long | 占有者CID |

### PVP记录

| 字段名 | 类型 | 说明 |
|--------|------|------|
| logId | long | 记录ID |
| attackerCid | long | 攻击者CID |
| defenderCid | long | 防御者CID |
| result | int | 结果 |
| time | long | 时间 |

## 公会分享功能

- 公会矿点分享
- 公会成员协助采集
- 公会矿点列表
