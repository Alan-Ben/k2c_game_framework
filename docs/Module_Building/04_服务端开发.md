# 建筑模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

建筑模块（Building Module）负责管理玩家所有建筑的数据和业务逻辑，包括：
- 建筑建造与升级
- 农田产出收集
- 经营建筑雇员管理
- 经营建筑产品生产
- 英雄驻扎建筑

### 1.2 模块编号

协议模块编号: `p010`

## 四、核心逻辑流程

### 4.1 建筑建造流程

```
客户端                          服务端
   |                               |
   |--- ReqBuildingBuild --------->|
   |                               | 1. 验证建筑配置是否存在
   |                               | 2. 验证解锁条件
   |                               | 3. 验证资源是否足够
   |                               | 4. 扣除建造资源
   |                               | 5. 创建建筑数据
   |<-- RetBuildingBuild ----------|
   |<-- OnBuildingAdd ------------| (推送建筑新增)
   |                               |
```

### 4.2 农场产出收集流程

```
客户端                          服务端
   |                               |
   |--- ReqFarmClickOutput ------->|
   |                               | 1. 验证农场是否存在
   |                               | 2. 计算产出数量
   |                               | 3. 发放产出奖励
   |                               | 4. 更新点击时间
   |<-- RetFarmClickOutput --------|
   |                               |
```

### 4.3 经营建筑雇佣员工流程

```
客户端                          服务端
   |                               |
   |--- ReqBusinessHireEmployee -->|
   |                               | 1. 验证建筑是否存在
   |                               | 2. 验证雇员上限
   |                               | 3. 验证雇佣资源
   |                               | 4. 扣除雇佣资源
   |                               | 5. 增加雇员
   |<-- RetBusinessHireEmployee ---|
   |                               |
```

## 六、服务配置

### 6.1 协议注册

建筑模块协议在服务端启动时注册：

```csharp
// 协议主序号
public const byte BUILDING_MODULE_ORDER = 10;

// 协议处理器注册
protocolHandler.Register<GC2GS_010_001_ReqBuildingBuild>(OnBuildingBuild);
protocolHandler.Register<GC2GS_010_002_ReqFarmUpgradeLvl>(OnFarmUpgradeLvl);
protocolHandler.Register<GC2GS_010_003_ReqFarmClickOutput>(OnFarmClickOutput);
// ... 其他协议注册
```

### 6.2 服务依赖

建筑模块依赖以下服务：
- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
- 英雄服务 (HeroService) - 用于驻扎功能
