# 成就系统 - 数据配表

## 概述

成就系统 (Achieve) 是游戏中的里程碑玩法，玩家完成特定目标可获得成就和奖励。

## 配表文件

### 1. 成就配置 (Achieve)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| achieve_id | int | 成就ID |
| achieve_name | string | 成就名称 |
| achieve_type | int | 成就类型 |
| achieve_desc | string | 成就描述 |
| target_value | long | 目标值 |
| step_list | array | 阶段列表 |

### 2. 成就阶段配置 (AchieveStep)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| step_id | int | 阶段ID |
| achieve_id | int | 成就ID |
| step | int | 阶段数 |
| target_value | long | 目标值 |
| reward_list | array | 奖励列表 |

### 3. 成就类型配置 (AchieveType)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| type_id | int | 类型ID |
| type_name | string | 类型名称 |
| red_tip_id | int | 红点ID |

### 4. 成就点配置 (AchievePoint)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| point_id | int | 点数ID |
| type | int | 类型 |
| point_per_achieve | int | 每成就点数 |

### 5. 成就点阶段配置 (AchievePointStep)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| step_id | int | 阶段ID |
| type | int | 类型 |
| need_point | long | 所需点数 |
| reward_list | array | 奖励列表 |

## 成就类型枚举

```csharp
public enum EAchieveType
{
    GROWTH = 1,     // 成长类
    BATTLE = 2,     // 战斗类
    SOCIAL = 3,     // 社交类
    COLLECT = 4,    // 收集类
    SPECIAL = 5     // 特殊类
}
```

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Achieve/`
- 服务端配置：`game_server/Config/achieve/`
