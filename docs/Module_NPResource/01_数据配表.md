# NPResource 玩家资源模块 - 数据配表文档

## 模块概述

**模块名称**: NPResource (玩家资源)
**模块类型**: 客户端独立组件
**主要功能**: 管理玩家各类资源数量和显示

## 配置文件

### 配置表

| 配置表名称 | 用途 |
|-----------|------|
| ResourceConfig | 资源配置 |
| ResourceIconConfig | 资源图标配置 |

## 数据结构

### 资源信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| resourceId | int | 资源ID |
| resourceName | String | 资源名称 |
| currentAmount | long | 当前数量 |
| maxAmount | long | 最大数量 |

## 资源类型

| 类型ID | 类型名 | 说明 |
|--------|--------|------|
| 1 | GOLD | 金币 |
| 2 | GEM | 宝石 |
| 3 | FOOD | 食物 |
| 4 | WOOD | 木材 |
| 5 | STONE | 石头 |
| 6 | IRON | 铁矿 |
| 7 | ENERGY | 能源 |

## 组件说明

资源数据通常存储在 NPPlayerInfo 组件中，本模块提供资源读取和显示辅助功能。
