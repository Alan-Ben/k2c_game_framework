# 引导系统协议文档

## 协议模块编号: p002 (InitOp)

引导系统的协议主要包含在初始化操作模块中。

---

## 一、引导数据同步

### GS2GC_002_xxx_RetTutorialInit - 引导初始化响应
**功能说明**: 返回玩家引导数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| tutorialData | TutorialData | 引导数据 |

---

## 二、引导数据结构

### TutorialData - 引导数据对象

| 字段名 | 类型 | 说明 |
|--------|------|------|
| lastFinishForceTutorial | long | 最后完成的强制引导ID |
| finishTutorialId | List&lt;long&gt; | 已完成的引导ID列表 |

---

## 三、协议调用流程

### 3.1 引导完成流程
```
客户端                          服务端
   |                               |
   |--- 完成引导步骤 --------------->|
   |                               | (更新引导状态)
   |<-- 推送引导数据变化 -----------|
   |                               |
```

### 3.2 强制引导流程
```
客户端                          服务端
   |                               |
   |--- 触发强制引导 --------------->|
   |                               | (验证触发条件)
   |<-- 返回引导数据 ---------------|
   |                               |
   |--- 完成引导 ------------------>|
   |                               | (记录完成状态)
   |<-- 推送下一引导 ---------------|
   |                               |
```

---

## 四、引导状态管理

引导状态主要通过 `TutorialData` 结构管理：

- **强制引导**: 通过 `lastFinishForceTutorial` 记录最后完成的强制引导ID
- **可选引导**: 通过 `finishTutorialId` 列表记录所有已完成的引导ID
