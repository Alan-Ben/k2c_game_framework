# 火星系统 - 数据配表

## 概述

火星系统 (MarsOp, p038-p041) 是游戏中的探索玩法，玩家可以探索火星、建造基地、派遣人员。

## 配表文件

### 1. 火星航程配置 (MarsGoRoute)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| route_id | int | 航程ID |
| route_name | string | 航程名称 |
| stage_count | int | 阶段数量 |
| duration | int | 持续时间 |

### 2. 火星建筑配置 (MarsBuilding)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| building_id | int | 建筑ID |
| building_name | string | 建筑名称 |
| building_type | int | 建筑类型 |
| max_level | int | 最大等级 |
| upgrade_cost | array | 升级消耗 |

### 3. 火星人员配置 (MarsPeople)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| people_id | int | 人员ID |
| people_name | string | 人员名称 |
| people_type | int | 人员类型 |
| ability | json | 能力值 |

### 4. 火星探索配置 (MarsExplore)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| explore_id | int | 探索ID |
| explore_name | string | 探索名称 |
| area_id | int | 区域ID |
| reward_list | array | 奖励列表 |

### 5. 火星科技配置 (MarsTech)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| tech_id | int | 科技ID |
| tech_name | string | 科技名称 |
| tech_type | int | 科技类型 |
| effect | json | 效果 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Mars/`
- 服务端配置：`game_server/Config/mars/`
