## 数据结构

### InnInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| innLevel | int | 旅店等级 |
| popularity | int | 人气值 |
| medalLevel | int | 勋章等级 |
| stationList | array | 座位列表 |
| dishList | array | 菜品列表 |
| guestList | array | 客人列表 |

### InnStationInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| stationId | int | 座位ID |
| level | int | 等级 |
| guestId | int | 当前客人ID |
| state | int | 状态 |

### InnDishInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dishId | int | 菜品ID |
| level | int | 等级 |
| unlock | bool | 是否解锁 |
