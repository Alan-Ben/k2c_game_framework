## 五、协议交互时序图

### 5.1 开始游历流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Config as 配表

    C->>S: GC2GS_008_001_ReqStartTravel
    S->>S: 检查游历次数/冷却时间
    S->>Config: 获取位置配置
    Config-->>S: 返回位置列表
    S->>S: 随机选择位置
    S->>Config: 获取事件配置
    Config-->>S: 返回事件列表
    S->>S: 随机选择事件
    S->>DB: 保存事件数据
    DB-->>S: 保存成功
    S->>C: GS2GC_008_001_RetStartTravel(eventInfo)
    S->>C: GS2GC_008_050_OnEventAdd(eventInfo)
```

### 5.2 一键游历流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Config as 配表

    C->>S: GC2GS_008_002_ReqAkeyTravel
    S->>Config: 获取位置和事件配置

    loop 遍历处理次数
        S->>S: 随机位置
        S->>S: 随机事件
        alt 一次性事件
            S->>S: 直接发放奖励
        else 需要玩家选择的事件
            S->>DB: 保存到待处理列表
            S->>C: GS2GC_008_050_OnEventAdd(eventInfo)
        end
    end

    S->>DB: 更新玩家记录
    S->>C: GS2GC_008_002_RetAkeyTravel(resultList, dealEventList)
```

### 5.3 处理妃子事件流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库

    C->>S: GC2GS_008_008_ReqDealConsortLikeTravel(instanceId)
    S->>DB: 查找事件数据
    DB-->>S: 返回事件数据
    S->>S: 验证事件有效性
    S->>DB: 查找妃子数据
    DB-->>S: 返回妃子数据
    S->>S: 计算好感度变化
    S->>DB: 更新妃子好感度
    S->>DB: 删除事件数据
    S->>C: GS2GC_008_008_RetDealConsortLikeTravel(eventResult)
    S->>C: GS2GC_008_051_OnEventDel(instanceId)
    S->>C: GS2GC_008_052_OnConsortChg(consort)

    alt 好感度达到结婚条件
        S->>S: 触发结婚事件
        S->>C: 推送获得妃子
    end
```

### 5.4 博彩事件流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库

    C->>S: GC2GS_008_011_ReqDealGamblingTravel(instanceId, betAmount, isAbandon)

    alt 放弃赌博
        S->>S: 标记事件完成
        S->>C: 返回放弃结果
    else 参与赌博
        S->>S: 验证下注金额
        S->>S: 扣除下注金额
        S->>S: 随机赌博结果
        alt 胜利
            S->>S: 发放奖励(下注×倍率)
        else 失败
            S->>S: 不返还下注金额
        else 大奖
            S->>S: 发放高额奖励
        end
        S->>DB: 更新玩家货币
        S->>C: GS2GC_008_011_RetDealGamblingTravel(eventResult, gambleResult)
    end

    S->>C: GS2GC_008_051_OnEventDel(instanceId)
```

## 六、错误码定义

### 6.1 游历模块错误码 (TravelErr)

**源码路径**: `game_server/Common/src/NPCommon/ErrMain/TravelErr.java`

| 错误码 | 常量名 | 说明 | 触发场景 |
|--------|--------|------|---------|
| 170001 | TRAVEL_EVENT_CREATE_FAIL | 游历事件创建失败 | 创建事件时 |
| 170002 | TRAVEL_EVENT_NOT_FOUND | 游历事件未找到 | 查找事件时 |
| 170003 | TRAVEL_EVENT_NOT_DEAL | 游历事件未处理 | 事件状态异常 |
| 170004 | TRAVEL_EVENT_CONSORT_NOT_IN | 游历事件不属于指定妃子列表 | 妃子事件验证 |
| 170005 | TRAVEL_COST_NOT_ENOUGH | 游历事件消耗不足 | 处理事件时 |
| 170006 | TRAVEL_COST_FAIL | 游历事件消耗失败 | 扣除资源时 |
| 170007 | TRAVEL_GAMBLE_BET_INVALID | 博彩押注额度不合法 | 博彩下注时 |

**源码定义**:
```java
public class TravelErr implements _IErrHolder {
    public static final Result TRAVEL_EVENT_CREATE_FAIL = Result.constInit(170001, "游历事件创建失败");
    public static final Result TRAVEL_EVENT_NOT_FOUND = Result.constInit(170002, "游历事件未找到");
    public static final Result TRAVEL_EVENT_NOT_DEAL = Result.constInit(170003, "游历事件未处理");
    public static final Result TRAVEL_EVENT_CONSORT_NOT_IN = Result.constInit(170004, "游历事件不属于指定妃子列表");
    public static final Result TRAVEL_COST_NOT_ENOUGH = Result.constInit(170005, "游历事件消耗不足");
    public static final Result TRAVEL_COST_FAIL = Result.constInit(170006, "游历事件消耗失败");
    public static final Result TRAVEL_GAMBLE_BET_INVALID = Result.constInit(170007, "博彩押注额度不合法");
```
