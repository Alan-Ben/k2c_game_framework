## 核心管理类

### MarsPeopleEventMgr

火星事件管理器，负责:
- 随机事件生成
- 事件触发条件判断
- 事件奖励发放

### MarsPeopleLetterMgr

信件管理器，负责:
- 信件生成
- 信件奖励处理
- 信件过期清理

### MarsPeopleHelpMgr

求助管理器，负责:
- 求助请求处理
- 帮助奖励发放
- 求助状态更新

## 业务逻辑

### 移民流程

1. 触发移民事件
2. 生成移民数据
3. 推送移民到达通知
4. 玩家确认或拒绝
5. 更新人口数据

### 情报处理

1. 定期生成情报
2. 推送情报通知
3. 玩家处理情报
4. 发放情报奖励

### 求助系统

1. 触发求助事件
2. 推送求助通知
3. 玩家选择帮助方式
4. 发放帮助奖励
