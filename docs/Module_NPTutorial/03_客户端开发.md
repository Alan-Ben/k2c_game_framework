# 引导系统客户端开发文档

## 一、组件数据层

### 1.1 引导数据类

#### TutorialData
**路径**: `ClientProtocol/RemarkData/TutorialData.cs`

**功能**: 存储玩家引导数据

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| lastFinishForceTutorial | long | 最后完成的强制引导ID |
| finishTutorialId | List&lt;long&gt; | 已完成的引导ID列表 |

**主要方法**:

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| getLastFinishForceTutorial | - | long | 获取最后完成的强制引导ID |
| getFinishTutorialId | - | List&lt;long&gt; | 获取已完成的引导ID列表 |
| addFinishTutorialId | long id | void | 添加已完成的引导ID |

## 二、引导管理器

### 2.1 引导状态判断

```csharp
// 判断引导是否已完成
public bool isTutorialFinished(long tutorialId)
{
    return tutorialData.getFinishTutorialId().Contains(tutorialId);
}

// 判断强制引导进度
public long getLastForceTutorialId()
{
    return tutorialData.getLastFinishForceTutorial();
}
```

### 2.2 引导触发检查

```csharp
// 检查是否需要触发强制引导
public bool needTriggerForceTutorial(long currentTutorialId)
{
    return currentTutorialId > tutorialData.getLastFinishForceTutorial();
}
```

## 五、引导流程实现

### 5.1 引导初始化

```csharp
// 初始化引导数据
TutorialData tutorialData = NPPlayer.instance.tutorialData;

// 检查是否需要触发引导
if (needTriggerForceTutorial(currentTutorialId))
{
    startTutorial(currentTutorialId);
}
```

### 5.2 引导步骤执行

```csharp
// 执行引导步骤
public void executeTutorialStep(TutorialRefObj tutorialRef)
{
    // 1. 显示引导遮罩
    showTutorialMask();

    // 2. 高亮目标控件
    highlightTarget(tutorialRef.target);

    // 3. 显示引导提示
    showTutorialTip(tutorialRef.tipText);

    // 4. 等待玩家操作
    waitForPlayerAction();
}
```

### 5.3 引导完成处理

```csharp
// 引导完成
public void onTutorialFinish(long tutorialId)
{
    // 1. 更新本地数据
    tutorialData.addFinishTutorialId(tutorialId);

    // 2. 发送消息通知
    WinMsg.SendMsg(WinMsgType.ON_TUTORIAL_FINISH, tutorialId);

    // 3. 检查下一个引导
    checkNextTutorial(tutorialId);
}
```
