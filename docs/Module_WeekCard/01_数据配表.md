# 周卡数据配表文档

## 配表说明

周卡模块相关的配置数据主要存储在以下配表中:

---

## 一、周卡配置

### 通用配置 (RefGeneral)

| 配置项 | 类型 | 说明 |
|--------|------|------|
| week_card_func_simple_unlock_id | int | 周卡功能解锁条件ID |
| week_card_free_trial_time_sec | int | 免费试用时长(秒) |
| week_card_offline_active_min_time_sec | int | 离线激活最小时间(秒) |
| week_card_offline_hosting_max_profit_time_sec | int | 离线挂机最大收益时间(秒) |
| week_card_assign_default_td_show | object | 默认执政官形象 |

---

## 二、结算类型枚举

| 枚举值 | 说明 |

| CONSORT_RND_CALL | 妃子倾诉 |

| COLLEGE_STUDY | 大学学习 |
| TRAVEL | 游历 |

## 三、NPC类型枚举

### EWeekCardNPCType - 周卡NPC类型

| 枚举值 | 说明 |

| NONE | 无 |

## 四、周卡状态枚举

### EWeekCardStat - 周卡状态

| 枚举值 | 说明 |
|--------|------|
| NONE | 未使用过免费试用 |
| IN_WEEK_CARD | 周卡生效中 |
| EXPIREED | 已过期 |

---

## 五、数据结构

### WeekCard_Info - 周卡信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| expireTimeTagS | int | 过期时间戳 |
| hadUseFreeTrial | bool | 是否使用过免费试用 |
| npcType | EWeekCardNPCType | NPC类型 |
| npcId | long | NPC ID |

### WeekCard_SettleInfo - 结算信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| detailList | List&lt;WeekCard_SettleDetailInfo&gt; | 结算详情列表 |
| itemList | List&lt;RewardItem&gt; | 奖励物品列表 |

### WeekCard_SingleSettingInfo - 单项设置信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | EWeekCardSettleType | 结算类型 |
| settingData | byte[] | 设置数据 |
