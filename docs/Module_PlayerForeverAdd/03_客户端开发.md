# 永久属性加成客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerForeverAddComponent
**路径**: `GameComponent/PlayerForeverAdd/PlayerForeverAddComponent.cs`

**功能**: 管理玩家所有永久属性加成数据

**继承关系**:
```
PlayerForeverAddComponent : _ANPBasicPlayerComponent
```

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| playerPropertyContainer | NPPlayerPropertyContainer | 玩家属性容器 |
| onForeverAddChanged | Action&lt;long, int&gt; | 永久加成变化事件 |

**主要方法**:

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| onForeverAddChg | GS2GC_021_075_OnForeverAddChg | void | 处理永久加成变化 |

## 二、组件特性

### 2.1 提前初始化

该组件支持提前初始化（canPreInit = true）：

```csharp
public override bool canPreInit { get { return true; } }

public override void presendInitProtocol()
{
    _reqInit();  // 提前发送初始化请求
}
```

### 2.2 属性容器管理

永久加成通过属性容器管理玩家属性：

```csharp
// 添加属性修改器
_m_playerPropertyContainer.addModifier(foreverAddRefObj.getProperty(count));

// 移除属性修改器
_m_playerPropertyContainer.removeModifier(foreverAddRefObj.getProperty(oldValue));
```

## 三、使用示例

### 3.1 获取永久加成组件

```csharp
// 获取永久加成组件
PlayerForeverAddComponent foreverAddComp = NPPlayer.instance.foreverAddComponent;

// 获取属性容器
NPPlayerPropertyContainer propContainer = foreverAddComp.playerPropertyContainer;
```

### 3.2 监听永久加成变化

```csharp
// 注册永久加成变化事件
NPPlayer.instance.foreverAddComponent.onForeverAddChanged += (addId, count) =>
{
    Debug.Log($"永久加成变化: ID={addId}, 数量={count}");
};
```

### 3.3 查询加成属性

```csharp
// 通过属性容器查询加成后的属性值
long totalPower = NPPlayer.instance.playerPropertyContainer.getPropValue(EPropertyType.POWER);
```
