# 副本系统 - 数据配表

## 概述

副本系统 (DungeonOp, p024) 包含午间副本和晚间副本，是游戏中的定时PVE玩法。

## 配表文件

### 1. 午间副本配置 (MiddayDungeon)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dungeon_id | int | 副本ID |
| dungeon_name | string | 副本名称 |
| open_time | string | 开启时间 |
| duration | int | 持续时间 |
| daily_count | int | 每日次数 |

### 2. 午间副本宝箱配置 (MiddayDungeonBox)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| box_id | int | 宝箱ID |
| box_quality | int | 宝箱品质 |
| reward_list | array | 奖励列表 |
| draw_condition | json | 领取条件 |

### 3. 晚间副本配置 (EveningDungeon)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dungeon_id | int | 副本ID |
| dungeon_name | string | 副本名称 |
| open_time | string | 开启时间 |
| boss_list | array | Boss列表 |

### 4. 晚间副本Boss配置 (EveningDungeonBoss)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| boss_id | int | Boss ID |
| boss_name | string | Boss名称 |
| boss_level | int | Boss等级 |
| hp | long | 血量 |
| reward | array | 击杀奖励 |

## 副本状态枚举

```csharp
public enum EDungeonState
{
    CLOSED = 0,     // 未开启
    OPENING = 1,    // 开启中
    ENDED = 2       // 已结束
}
```

## 公会副本配置 (GuildDungeon)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dungeon_id | int | 副本ID |
| guild_level | int | 公会等级需求 |
| monster_list | array | 怪物列表 |
| auto_start | bool | 是否自动开始 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Dungeon/`
- 服务端配置：`game_server/Config/dungeon/`
