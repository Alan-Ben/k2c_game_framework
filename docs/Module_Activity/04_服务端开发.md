# 活动模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

活动模块（Activity Module）负责管理游戏中各类活动，包括：
- 限时活动管理
- 排行榜活动
- 阶段奖励活动
- 活动商店系统
- 活动基金系统
- 七日目标系统
- 充值返利活动

### 1.2 模块编号

协议模块编号: `p017`, `p033`

---

## 二、核心数据结构

### 2.1 活动信息 (Activity_Info)

**路径**: `ClientProtocol/Common/ActivityObj/Activity_Info.cs`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| activityId | long | 活动ID |
| status | EActivityState | 活动状态 |
| playerData | Activity_PlayerData | 玩家数据 |
| stepRewardInfo | Activity_StepRewardInfo | 阶段奖励信息 |

### 2.2 活动状态枚举 (EActivityState)

**路径**: `ClientProtocol/Common/ActivityEnum/EActivityState.cs`

| 枚举值 | 说明 |
|--------|------|
| None | 无状态 |
| NotStart | 未开始 |
| InProgress | 进行中 |
| Ended | 已结束 |
| Rewarded | 已领奖 |

### 2.3 活动商店信息 (Activity_ShopInfo)

**路径**: `ClientProtocol/Common/ActivityObj/Activity_ShopInfo.cs`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| shopId | long | 商店ID |
| refreshNum | int | 刷新次数 |
| goodsList | List | 商品列表 |

## 四、核心逻辑流程

### 4.1 领取活动奖励流程

```
客户端                          服务端
   |                               |
   |--- ReqDrawActivityReward ---->|
   |                               | 1. 验证活动是否存在
   |                               | 2. 验证活动状态
   |                               | 3. 验证奖励条件
   |                               | 4. 发放奖励
   |                               | 5. 更新活动数据
   |<-- RetDrawActivityReward -----|
   |                               |
```

### 4.2 活动商店购买流程

```
客户端                          服务端
   |                               |
   |--- ReqBuyActivityShopItem --->|
   |                               | 1. 验证商店是否开放
   |                               | 2. 验证商品是否存在
   |                               | 3. 验证购买次数
   |                               | 4. 扣除货币
   |                               | 5. 发放商品
   |<-- RetBuyActivityShopItem ----|
   |                               |
```

## 六、服务配置

```csharp
// 协议主序号
public const byte ACTIVITY_MODULE_ORDER = 17;
public const byte SIMPLE_ACTIVITY_ORDER = 33;

// 协议处理器注册
protocolHandler.Register<GC2GS_017_001_ReqDrawActivityRankReward>(OnDrawActivityRankReward);

```

### 6.2 服务依赖

活动模块依赖以下服务：
- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
- 排行榜服务 (RankService)
- 定时任务服务 (ScheduleService)
