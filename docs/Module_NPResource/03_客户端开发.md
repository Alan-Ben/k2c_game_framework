# NPResource 玩家资源模块 - 客户端开发文档

## 客户端组件

资源数据存储在 NPPlayerInfo 组件中，本模块提供辅助功能。

## 主要功能

### 资源获取

```csharp
// 获取资源数量
long gold = NPPlayerInfo.Instance.GetResource(ResourceType.GOLD);
long gem = NPPlayerInfo.Instance.GetResource(ResourceType.GEM);
```

### 资源检查

```csharp
// 检查资源是否足够
bool hasEnough = NPPlayerInfo.Instance.HasResource(ResourceType.GOLD, 1000);
```

### 资源显示

```csharp
// 格式化显示
string display = ResourceHelper.FormatAmount(amount);

// 简短显示 (如 1.5K, 2.3M)
string shortDisplay = ResourceHelper.FormatShort(amount);
```

### 资源变化监听

```csharp
// 监听资源变化
NPPlayerInfo.Instance.OnResourceChanged += (resourceType, oldVal, newVal) => {
    UpdateResourceUI(resourceType);
};
```
