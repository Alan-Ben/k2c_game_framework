## 核心逻辑

### 午间副本攻击

```java
public void middayAttack(long playerId) {
    // 1. 检查开启时间
    if (!isMiddayDungeonOpen()) {
        throw new BusinessException(ErrorCode.DUNGEON_NOT_OPEN);
    }

    // 2. 检查攻击次数
    PlayerMiddayDungeon data = middayDao.selectById(playerId);
    if (data.getAttackCount() >= MAX_DAILY_ATTACK) {
        throw new BusinessException(ErrorCode.ATTACK_COUNT_EXCEEDED);
    }

    // 3. 执行攻击，获取奖励
    List<ItemInfo> rewards = doMiddayAttack(playerId);

    // 4. 增加攻击次数
    data.setAttackCount(data.getAttackCount() + 1);
    middayDao.updateById(data);

    // 5. 发放奖励
    itemService.giveItems(playerId, rewards);

    return rewards;
}
```

### 晚间副本攻击

```java
public long eveningAttack(long playerId, int bossId) {
    // 1. 检查开启时间
    if (!isEveningDungeonOpen()) {
        throw new BusinessException(ErrorCode.DUNGEON_NOT_OPEN);
    }

    // 2. 获取Boss信息
    EveningDungeonBoss boss = eveningBossDao.selectById(bossId);
    if (boss == null || boss.getCurrentHp() <= 0) {
        throw new BusinessException(ErrorCode.BOSS_ALREADY_DEAD);
    }

    // 3. 计算伤害
    long damage = calculateDamage(playerId);

    // 4. 更新Boss血量
    boss.setCurrentHp(Math.max(0, boss.getCurrentHp() - damage));
    eveningBossDao.updateById(boss);

    // 5. 更新玩家伤害
    EveningDungeonDamage damageRecord = damageDao.selectByPlayerAndBoss(playerId, bossId);
    if (damageRecord == null) {
        damageRecord = new EveningDungeonDamage();
        damageRecord.setPlayerId(playerId);
        damageRecord.setBossId(bossId);
        damageRecord.setTotalDamage(damage);
        damageRecord.setAttackCount(1);
        damageDao.insert(damageRecord);
    } else {
        damageRecord.setTotalDamage(damageRecord.getTotalDamage() + damage);
        damageRecord.setAttackCount(damageRecord.getAttackCount() + 1);
        damageDao.updateById(damageRecord);
    }

    // 6. 检查是否击杀
    if (boss.getCurrentHp() <= 0) {
        boss.setKillPlayerId(playerId);
        eveningBossDao.updateById(boss);

        // 发放击杀奖励
        giveKillReward(playerId, bossId);

        // 推送Boss死亡通知
        pushBossDeath(bossId, playerId);
    }

    return damage;
}
```

### 公会副本攻击

```java
public void guildDungeonAttack(long playerId, long guildId, int monsterId) {
    // 1. 获取公会副本
    GuildDungeon dungeon = guildDungeonDao.selectByGuildId(guildId);
    if (dungeon == null) {
        throw new BusinessException(ErrorCode.GUILD_DUNGEON_NOT_FOUND);
    }

    // 2. 检查怪物是否存在
    MonsterInfo monster = findMonster(dungeon.getMonsterList(), monsterId);
    if (monster == null || monster.getHp() <= 0) {
        throw new BusinessException(ErrorCode.MONSTER_ALREADY_DEAD);
    }

    // 3. 计算伤害
    long damage = calculateDamage(playerId);

    // 4. 更新怪物血量
    monster.setHp(Math.max(0, monster.getHp() - damage));
    guildDungeonDao.updateMonsterList(guildId, dungeon.getMonsterList());

    // 5. 更新伤害排行
    updateDamageRank(guildId, playerId, damage);

    // 6. 检查怪物死亡
    if (monster.getHp() <= 0) {
        // 发放击杀奖励给公会
        giveGuildMonsterKillReward(guildId, monsterId);

        // 推送通知
        pushMonsterDeath(guildId, monsterId);
    }
}
```

## 定时任务

### 午间副本开启

```java
@Scheduled(cron = "0 0 12 * * ?") // 每天12点
public void openMiddayDungeon() {
    // 发送广播
    broadcastDungeonOpen(EDungeonType.MIDDAY);
}
```

### 晚间副本开启

```java
@Scheduled(cron = "0 0 20 * * ?") // 每天20点
public void openEveningDungeon() {
    // 创建Boss
    createEveningBoss();

    // 发送广播
    broadcastDungeonOpen(EDungeonType.EVENING);
}
```

### 每日重置

```java
@Scheduled(cron = "0 0 0 * * ?")
public void dailyReset() {
    // 重置午间副本攻击次数
    middayDao.resetDailyAttackCount();

    // 重置晚间副本
    eveningBossDao.deleteAll();
    damageDao.deleteAll();
}
```

## 注意事项

1. 副本有固定的开启时间
2. Boss血量需要原子操作
3. 公会副本需要公会等级解锁
4. 伤害排行需要实时更新
