# 火星系统 - 协议文档

## 协议编号

模块编号：p038 (MarsOp) / p039 (MarsBuildingOp) / p040 (MarsPeopleOp) / p041 (MarsExploreOp)

## 客户端请求协议 (GC2GS)

### MarsOp (p038)

#### GC2GS_038_001_ReqStartToGoMars

**说明**：请求前往火星

---

#### GC2GS_038_002_ReqArriveMarsStage

**说明**：请求到达火星阶段

---

#### GC2GS_038_003_ReqSendDoneMarquee

**说明**：请求发送完成跑马灯

---

#### GC2GS_038_004_ReqSendStageMsg

**说明**：请求发送阶段消息

---

#### GC2GS_038_005_ReqGetStageMsgList

**说明**：请求获取阶段消息列表

---

## 服务端响应协议 (GS2GC)

### GS2GC_038_050_OnGoToStageArrived

**说明**：通知到达阶段

---

### GS2GC_038_051_OnGoToAllStageDone

**说明**：通知所有阶段完成

---

## 数据结构

### MarsInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| currentStage | int | 当前阶段 |
| routeList | array | 航程列表 |
| buildingList | array | 建筑列表 |
| peopleList | array | 人员列表 |

### MarsBuildingInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| buildingId | int | 建筑ID |
| level | int | 等级 |
| state | int | 状态 |

### MarsPeopleInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| peopleId | int | 人员ID |
| state | int | 状态 |
| assignBuilding | int | 分配建筑 |

### MarsExploreInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| exploreId | int | 探索ID |
| progress | int | 进度 |
| state | int | 状态 |
