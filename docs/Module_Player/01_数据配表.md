# 玩家模块数据配表文档

## 配表说明

玩家模块相关的配置数据主要存储在以下配表中:

---

## 一、玩家等级配表

### PlayerLevelRefObj - 玩家等级配置
**文件**: `player_level_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| level | long | 等级 |
| exp | long | 升级所需经验 |
| unlock_feature | object | 解锁功能 |
| reward | object | 升级奖励 |
| energy_limit | int | 体力上限 |

---

## 二、玩家属性配表

### PlayerAttrRefObj - 玩家属性配置
**文件**: `player_attr_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 属性ID |
| name | string | 属性名称 |
| type | int | 属性类型 |
| base_value | long | 基础值 |
| growth_rate | float | 成长率 |

---

## 七、配表加载方式

```csharp
// 获取玩家等级配置
PlayerLevelRefObj levelRef = GRefdataCoreMgr.instance.playerLevelRefCore.getRef(level);

// 获取玩家头像配置
PlayerIconRefObj iconRef = GRefdataCoreMgr.instance.playerIconRefCore.getRef(iconId);

// 获取玩家称号配置
PlayerTitleRefObj titleRef = GRefdataCoreMgr.instance.playerTitleRefCore.getRef(titleId);
```
