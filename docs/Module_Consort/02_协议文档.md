```mermaid

        +long consortId
        +long intimacy
        +long charm
        +long charmPoint
```

## 协议交互流程

### 邀约流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant DB as 数据库

    Client->>Server: GC2GS_015_004_ReqCallRand
    Server->>DB: 查询伴侣列表
    DB-->>Server: 返回伴侣数据
    Server->>Server: 随机选择伴侣和剧情
    Server->>Server: 计算奖励(加护点/CG/子嗣)
    Server->>DB: 更新数据
    Server-->>Client: GS2GC_015_004_RetCallRand
    Server-->>Client: GS2GC_015_053_OnConsortCharmPointChg
    opt 获得CG
        Server-->>Client: GS2GC_015_061_OnCgChg
    end
    opt 获得子嗣
        Server-->>Client: OnChildAdd
    end
```

### 升级羁绊流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant DB as 数据库

    Client->>Server: GC2GS_015_001_ReqUpgradeFettersLvl
    Server->>DB: 查询伴侣数据
    DB-->>Server: 返回数据
    Server->>Server: 检查亲密度是否足够
    Server->>DB: 扣除消耗，更新羁绊等级
    DB-->>Server: 更新成功
    Server-->>Client: GS2GC_015_001_RetUpgradeFettersLvl
    Server-->>Client: GS2GC_015_057_OnFettersChg
```
