## 核心逻辑

### 开始游历

```java
public void startTravel(long playerId) {
    // 1. 检查玩家状态
    Player player = playerManager.getPlayer(playerId);
    if (!canStartTravel(player)) {
        sendError(playerId, ErrorCode.TRAVEL_NOT_READY);
        return;
    }

    // 2. 初始化游历状态
    TravelData travelData = new TravelData();
    travelData.setPlayerId(playerId);
    travelData.setCurrentPos(1);
    travelData.setTravelState(TravelState.TRAVELING);
    travelData.setStartTime(System.currentTimeMillis());

    // 3. 生成初始事件
    List<TravelEvent> events = eventManager.generateEvents(player, 1);
    travelData.setEventList(events);

    // 4. 保存数据
    travelDataManager.save(travelData);

    // 5. 返回结果
    sendRetStartTravel(playerId, travelData);
}
```

### 事件生成

```java
public List<TravelEvent> generateEvents(Player player, int posId) {
    List<TravelEvent> events = new ArrayList<>();

    // 获取位置可触发的事件配置
    List<EventConfig> configs = eventConfigDao.getByPosId(posId);

    // 根据权重随机选择事件
    for (EventConfig config : configs) {
        if (RandomUtil.hit(config.getWeight())) {
            TravelEvent event = createEvent(config);
            events.add(event);
        }
    }

    return events;
}
```

### 处理事件

```java
public void dealEvent(long playerId, int eventId, int eventType) {
    // 1. 获取游历数据
    TravelData travelData = travelDataManager.getByPlayerId(playerId);

    // 2. 查找事件
    TravelEvent event = findEvent(travelData, eventId);
    if (event == null || event.getState() != EventState.PENDING) {
        sendError(playerId, ErrorCode.EVENT_NOT_FOUND);
        return;
    }

    // 3. 根据事件类型处理
    EventResult result = processEventByType(player, event, eventType);

    // 4. 发放奖励
    if (result.getRewards() != null) {
        rewardManager.giveRewards(playerId, result.getRewards());
    }

    // 5. 更新事件状态
    event.setState(EventState.FINISHED);
    travelDataManager.updateEvent(travelData, event);

    // 6. 返回结果
    sendRetDealEvent(playerId, result);
}
```

### 妃子事件处理

```java
public void dealConsortEvent(long playerId, int eventId, long consortId) {
    Player player = playerManager.getPlayer(playerId);

    // 1. 检查妃子是否解锁
    Consort consort = consortManager.getConsort(playerId, consortId);
    if (consort == null) {
        sendError(playerId, ErrorCode.CONSORT_NOT_UNLOCK);
        return;
    }

    // 2. 处理妃子事件
    TravelEvent event = findEvent(playerId, eventId);
    EventResult result = new EventResult();

    // 增加好感度
    int likeAdd = event.getLikeAdd();
    consortManager.addLike(playerId, consortId, likeAdd);

    // 通知客户端
    notifyConsortChg(playerId, consortId, consort.getLike() + likeAdd);
}
```

## 定时任务

### 游历进度更新

```java
@Scheduled(fixedRate = 60000) // 每分钟执行
public void updateTravelProgress() {
    List<TravelData> travelingList = travelDataManager.getTravelingList();

    for (TravelData data : travelingList) {
        // 检查是否到达下一个位置
        if (checkReachNextPos(data)) {
            // 生成新事件
            List<TravelEvent> newEvents = eventManager.generateEvents(
                data.getPlayerId(), data.getCurrentPos() + 1);

            // 通知客户端
            notifyEventAdd(data.getPlayerId(), newEvents);
        }
    }
}
```

### 事件过期处理

```java
@Scheduled(fixedRate = 300000) // 每5分钟执行
public void cleanExpiredEvents() {
    long now = System.currentTimeMillis();
    List<TravelData> expiredList = travelDataManager.getExpiredEvents(now);

    for (TravelData data : expiredList) {
        // 清理过期事件
        eventManager.cleanExpiredEvents(data);

        // 通知客户端
        notifyEventDel(data.getPlayerId(), data.getExpiredEventIds());
    }
}
```

## 注意事项

1. 事件生成需要考虑权重和概率
2. 妃子事件需要验证妃子是否已解锁
3. 奖励发放需要事务保证
4. 注意处理并发问题，避免重复处理事件
5. 定时任务需要处理服务器重启后的数据恢复
