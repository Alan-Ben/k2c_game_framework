# GuildRelatedOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p042
**模块名称**: GuildRelatedOp (公会相关操作)
**主要功能**: 提供公会援助、公会宝箱、公会集结等功能

## 配置文件

### 关联配置表

| 配置表名称 | 用途 |
|-----------|------|
| GuildHelpConfig | 公会援助配置 |
| GuildBoxConfig | 公会宝箱配置 |
| GuildRallyConfig | 公会集结配置 |
| GuildActiveConfig | 公会活跃度配置 |

## 数据结构

### 火星援助信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| helpId | long | 援助ID |
| helpType | int | 援助类型 |
| requestCid | long | 请求者CID |
| requestTime | long | 请求时间 |
| status | int | 状态 |

### 公会宝箱信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| boxId | long | 宝箱ID |
| boxType | int | 宝箱类型 |
| rewardList | List | 奖励列表 |
| isAnonymous | boolean | 是否匿名 |

### 集结信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| rallyId | long | 集结ID |
| targetId | long | 目标ID |
| leaderCid | long | 发起者CID |
| memberList | List | 参与者列表 |
| startTime | long | 开始时间 |
| endTime | long | 结束时间 |
