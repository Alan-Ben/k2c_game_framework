# 玩家皮肤系统 - 数据配表

## 概述

玩家皮肤系统 (PlayerSkinOp, p018) 管理玩家的外观系统，包括皮肤、称号、头像框等个性化装扮。

## 配表文件

### 1. 玩家皮肤配置 (PlayerSkin)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| skin_id | int | 皮肤ID |
| skin_name | string | 皮肤名称 |
| skin_type | int | 皮肤类型 |
| quality | int | 品质 |
| unlock_condition | json | 解锁条件 |
| upgrade_cost | array | 升级消耗 |

### 2. 称号配置 (Title)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| title_id | int | 称号ID |
| title_name | string | 称号名称 |
| title_type | int | 称号类型(普通/组合) |
| effect_list | array | 效果列表 |
| expire_type | int | 过期类型 |

### 3. 组合称号配置 (ComboTitle)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| combo_id | int | 组合ID |
| pre_title_id | int | 前缀称号ID |
| sfx_title_id | int | 特效称号ID |
| bg_title_id | int | 背景称号ID |

### 4. 头像框配置 (IconBgk)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| bgk_id | int | 头像框ID |
| bgk_name | string | 头像框名称 |
| bgk_res | string | 资源路径 |

## 皮肤类型枚举

```csharp
public enum EPlayerSkinType
{
    ROLE = 1,       // 角色皮肤
    ROOM = 2,       // 房间皮肤
    SCENE = 3       // 场景皮肤
}
```

public enum ETitleType
