# Anecdote 轶事/奇遇模块 - 协议文档

## 模块说明

本模块为客户端独立组件，不涉及服务端协议通信。

事件数据和奖励数据由其他模块（如 Building、Travel 等）通过业务协议同步。

## 关联协议

### 数据来源

轶事事件通常由以下模块触发:

| 模块 | 触发场景 |
|------|----------|
| Building | 建筑随机事件 |
| Travel | 游历奇遇 |
| Activity | 活动事件 |
