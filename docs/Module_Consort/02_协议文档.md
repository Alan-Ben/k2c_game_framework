## 数据结构

### ConsortInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| consortId | long | 伴侣ID |
| intimacy | int | 亲密度 |
| charm | int | 魅力 |
| fettersLvl | int | 羁绊等级 |
| curSkinId | int | 当前皮肤ID |
| skinList | array | 已解锁皮肤列表 |
| haloLvl | int | 光环等级 |
| businessSkillList | array | 商务技能列表 |
| blessSkillList | array | 祝福技能列表 |

### ConsortChatInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| chatId | long | 聊天ID |
| consortId | long | 伴侣ID |
| msgList | array | 消息列表 |
| optionList | array | 选项列表 |
