# 英雄模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerHeroComponent
**路径**: `GameComponent/Hero/PlayerHeroComponent.cs`

**功能**: 英雄(大臣)管理器，管理玩家所有英雄数据

**继承关系**:
```
PlayerHeroComponent : _ANPBasicPlayerComponent
```

**依赖组件**:
- `ENPPlayerCompType.CONSORT` - 伴侣组件
- `ENPPlayerCompType.EQIUP` - 装备组件

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| heroList | List<HeroInfo> | 英雄列表 |
| totalPower | long | 总实力值 |
| heroListFilterType | ESpecAttrType | 英雄列表筛选类型 |
| commonUnionBonusMgr | CommonUnionBonusMgr | 英雄属性加成管理器 |
| heroSkinUnionBonusMgr | CommonUnionBonusMgr | 英雄皮肤属性加成管理器 |
| playerPropertyContainer | NPPlayerPropertyContainer | 玩家属性容器 |

**主要方法**:

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| getAllList | List<HeroInfo> | void | 获取所有英雄列表 |
| getHeroInfoById | long heroId | HeroInfo | 根据ID获取英雄信息 |
| getHeroSuitInfo | long suitId | HeroSuitInfo | 获取套系信息 |
| reCalcAllHero | bool showEffect | void | 重新计算所有英雄属性 |
| reqHeroInit | - | void | 请求英雄初始化数据 |

## 四、访问方式

### 4.1 获取英雄组件
```csharp
// 获取英雄组件
PlayerHeroComponent heroComp = NPPlayer.instance.heroComponent;

// 获取所有英雄列表
List<HeroInfo> heroList = new List<HeroInfo>();
heroComp.getAllList(heroList);

// 获取指定英雄
HeroInfo hero = heroComp.getHeroInfoById(heroId);

// 获取总实力
long totalPower = heroComp.totalPower;
```

### 4.2 英雄属性获取
```csharp
HeroInfo hero = NPPlayer.instance.heroComponent.getHeroInfoById(heroId);

// 基础属性
long level = hero.level;
long step = hero.curStep;
long star = hero.star;

// 技能列表
var talentSkills = hero.heroTalentSkillInfoMgr;
var businessSkills = hero.heroBusinessSkillInfoMgr;

// 实力值
long power = hero.power;
```
