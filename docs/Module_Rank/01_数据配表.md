# 排行榜系统 - 数据配表

## 概述

排行榜系统 (RankOp, p031) 展示各类排名数据，包括战力榜、等级榜、竞技榜等。

## 配表文件

### 1. 排行榜类型配置 (RankType)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rank_type | int | 榜单类型 |
| rank_name | string | 榜单名称 |
| refresh_time | int | 刷新间隔 |
| show_count | int | 显示数量 |

### 2. 排行榜奖励配置 (RankReward)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rank_type | int | 榜单类型 |
| min_rank | int | 最低排名 |
| max_rank | int | 最高排名 |
| reward_list | array | 奖励列表 |

## 排行榜类型枚举

```csharp
public enum ERankType
{
    POWER = 1,      // 战力榜
    LEVEL = 2,      // 等级榜
    ARENA = 3,      // 竞技榜
    GUILD = 4,      // 公会榜
    TOWER = 5       // 爬塔榜
}
```
