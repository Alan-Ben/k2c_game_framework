## 核心类说明

### AnecdoteViewMgr

轶事视图管理器，负责:
- 管理轶事事件显示
- 处理玩家选择
- 展示奖励结果

### AnecdotePosView

轶事位置视图，负责:
- 显示轶事触发位置
- 管理轶事图标显示

### AnecdoteEventChoiceView

事件选择视图，负责:
- 显示选择项
- 处理玩家点击
- 触发选择结果

## 主要功能

### 事件触发

- 在特定位置触发随机事件
- 显示事件内容和选项

### 选择处理

- 玩家做出选择
- 计算选择结果
- 显示收益/惩罚

### 奖励展示

- 显示获得奖励
- 播放奖励动画
- 记录历史事件

## 使用示例

### 触发轶事事件

```csharp
// 创建事件信息
var eventInfo = new AnecdoteEventInfo();
eventInfo.setEventId(1001);
eventInfo.setTitle("神秘商人");
eventInfo.setContent("你遇到了一个神秘商人...");

// 显示轶事界面
AnecdoteViewMgr.Instance.ShowEvent(eventInfo);
```

### 处理玩家选择

```csharp
public void OnChoiceSelected(int choiceId)
{
    // 根据选择ID获取结果
    var earnings = AnecdoteManager.Instance.GetChoiceResult(choiceId);

    // 显示收益
    AnecdoteViewMgr.Instance.ShowEarnings(earnings);
}
```
