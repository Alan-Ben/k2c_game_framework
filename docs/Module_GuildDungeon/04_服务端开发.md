## 核心管理类

### GuildDungeonMgr

公会副本管理器，负责:
- 副本生命周期管理
- 怪物生成和状态管理
- 伤害统计和排行
- 奖励结算

### GuildDungeonInstanceInfo

副本实例信息，存储:
- 当前怪物状态
- 副本进度
- 时间信息

### GuildDungeonDamageRank

伤害排行榜，支持:
- 实时更新伤害
- 排名计算
- 排行奖励发放

## 业务逻辑

### 攻击流程

1. 验证玩家公会成员身份
2. 验证英雄战斗次数
3. 计算伤害值
4. 更新怪物血量
5. 更新伤害排行
6. 广播状态变更

### 副本开启

1. 验证公会等级
2. 检查副本冷却
3. 创建副本实例
4. 生成怪物
5. 通知公会成员

### 奖励发放

1. 检查奖励条件
2. 计算奖励内容
3. 发放奖励
4. 更新领取状态

## 数据存储

- 公会副本设置: 存储在公会数据中
- 玩家战斗信息: 存储在玩家组件中
- 伤害排行: 运行时数据，副本结束时持久化
