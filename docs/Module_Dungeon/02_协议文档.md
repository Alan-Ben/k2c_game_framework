## 一、客户端请求协议 (GC2GS)

### 1.1 午间副本协议

#### GC2GS_024_001_ReqMiddayDungeonAttack - 请求午间副本攻击

**功能说明**: 请求玩家对午间副本进行攻击，获取攻击奖励

| 序号 | 字段名 | 类型 | 说明 | 示例 |
|------|--------|------|------|------|
| 1 | dungeonId | int | 副本ID | 1 |

**服务端处理流程**:
1. 验证副本是否开启
2. 检查玩家今日攻击次数
3. 检查玩家体力是否充足
4. 扣减体力
5. 执行攻击，计算奖励
6. 更新攻击次数
7. 返回攻击结果和奖励

**响应**: `GS2GC_024_001_RetMiddayDungeonAttack`

### 4.1 午间副本攻击流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant DB as 数据库
    participant Push as 推送服务

    Client->>Server: GC2GS_024_001_ReqMiddayDungeonAttack
    Server->>Server: 验证副本开启状态
    Server->>Server: 检查攻击次数
    Server->>Server: 扣减体力
    Server->>DB: 更新攻击次数
    Server->>Server: 计算奖励
    Server->>DB: 发放奖励
    Server->>Client: GS2GC_024_001_RetMiddayDungeonAttack
    Server->>Push: GS2GC_024_051_OnMiddayDungeonInfoChg
    Push-->>Client: 推送副本信息变化
```
