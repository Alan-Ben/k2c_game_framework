# 太空寻宝系统 - 数据配表

## 概述

太空寻宝系统 (TreasureHuntOp, p036) 是游戏中的探索玩法，玩家可以在太空中探索获取矿石和宝藏。

## 配表文件

### 1. 太空站配置 (TreasureStation)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| station_id | int | 站点ID |
| station_name | string | 站点名称 |
| station_type | int | 站点类型 |
| ore_type | int | 矿石类型 |

### 2. 矿石配置 (TreasureOre)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| ore_id | int | 矿石ID |
| ore_name | string | 矿石名称 |
| ore_rarity | int | 稀有度 |
| base_value | int | 基础价值 |

### 3. 宝藏配置 (Treasure)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| treasure_id | int | 宝藏ID |
| treasure_name | string | 宝藏名称 |
| treasure_type | int | 宝藏类型 |
| reward_list | array | 奖励列表 |

### 4. 矿石技能配置 (TreasureOreSkill)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| skill_id | int | 技能ID |
| skill_name | string | 技能名称 |
| skill_type | int | 技能类型 |
| effect_value | int | 效果值 |

### 5. 合成配置 (TreasureComposite)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| composite_id | int | 合成ID |
| material_list | array | 材料列表 |
| output | json | 产出 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/TreasureHunt/`
- 服务端配置：`game_server/Config/treasure_hunt/`
