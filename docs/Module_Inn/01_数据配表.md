# 客栈模块 - 数据配表

## 概述

客栈模块 (InnOp, p034) 是游戏中的特色经营玩法，玩家经营客栈接待客人获取收益。核心数据通过配表配置，包含设施、菜品、客人、勋章等配置表。

## 配表关系图

```mermaid

    inn_dish ||--o{ inn_dish_level : "菜品等级"
```

## 一、客栈等级配置 (inn_level)

### 1.1 表结构

| 字段名 | 类型 | 说明 | 示例值 |
|-------|------|------|--------|
| level | int | 客栈等级（主键） | 1 |
| need_popularity | long | 升级所需人气值 | 1000 |
| receive_guest_limit | int | 接待客人上限 | 10 |

### 1.2 服务端引用类

```java
// 文件路径: game_server/GameRes/src/NPGameRes/Refs/Inn/RefInnLevel.java
@RefTable(tableName = "inn_level")
public class RefInnLevel extends RefBase {
    public int level;                   // 等级（主键）
    public long need_popularity;        // 所需人气值
    public int receive_guest_limit;     // 接收客人上限
}
```

## 七、配表加载流程

```mermaid
sequenceDiagram
    participant Server as GameServer
    participant RefMgr as RefDataManager
    participant Tables as 配表文件

    Server->>RefMgr: 启动时加载配表
    RefMgr->>Tables: 读取所有inn_*表
    Tables-->>RefMgr: 返回配置数据
    RefMgr->>RefMgr: 解析并建立关联关系
    RefMgr->>RefMgr: 缓存到容器中
    RefMgr-->>Server: 加载完成

    Note over RefMgr: RefInnLevel.init()<br/>RefInnStation.init()<br/>RefInnDish.init()<br/>...
```
