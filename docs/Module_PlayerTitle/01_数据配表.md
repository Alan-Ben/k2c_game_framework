# 玩家称号数据配表文档

## 配表说明

玩家称号模块相关的配置数据主要存储在以下配表中:

---

## 一、普通称号配置表

### RefPlayerTitle - 玩家称号配置
**文件**: `player_title.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 称号ID |
| add_type | ENPTimeAddType | 时间叠加类型 |

---

## 二、组合称号配置表

### RefPlayerTitlePrefix - 称号前缀配置
**文件**: `player_title_prefix.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 前缀ID |
| name | string | 前缀名称 |
| unlock_condition | object | 解锁条件 |

### RefPlayerTitleSuffix - 称号后缀配置
**文件**: `player_title_suffix.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 后缀ID |
| name | string | 后缀名称 |
| unlock_condition | object | 解锁条件 |

### RefPlayerTitleBg - 称号底框配置
**文件**: `player_title_bg.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 底框ID |
| name | string | 底框名称 |
| unlock_condition | object | 解锁条件 |

---

## 三、时间叠加类型

### ENPTimeAddType - 时间叠加类型枚举

| 枚举值 | 说明 |
|--------|------|
| NONE | 无叠加 |
| ADD | 时间叠加 |
| REPLACE | 时间替换 |
| MAX | 取最大值 |

---

## 四、称号类型

### ENPPlayerTitleType - 玩家称号类型

| 枚举值 | 说明 |
|--------|------|
| COMMON | 普通称号(固定/限时) |
| COMBO | 组合称号 |

---

## 五、配表加载方式

```csharp
// 获取普通称号配置
RefPlayerTitle titleRef = GRefdataCoreMgr.instance.playerTitleRefCore.getRef(titleId);

// 获取组合称号前缀配置
RefPlayerTitlePrefix prefixRef = GRefdataCoreMgr.instance.playerTitlePrefixRefCore.getRef(prefixId);

// 获取组合称号后缀配置
RefPlayerTitleSuffix suffixRef = GRefdataCoreMgr.instance.playerTitleSuffixRefCore.getRef(suffixId);

// 获取组合称号底框配置
RefPlayerTitleBg bgRef = GRefdataCoreMgr.instance.playerTitleBgRefCore.getRef(bgId);
```
