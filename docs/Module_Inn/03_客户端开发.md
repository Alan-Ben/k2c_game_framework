## 数据管理

### InnComponent

```csharp
public class InnComponent : _ANPBasicPlayerComponent
{
    // 旅店信息
    private InnInfo _m_innInfo;

    /// <summary>
    /// 请求接待客人
    /// </summary>
    public void reqReceiveGuest(int stationId, int guestId, Action callback)
    {
        NPGSClientListener.sendRequest(
            NPGSWriter_034_InnOp.make_001_ReqInnReceiveGuest(stationId, guestId),
            new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_034_001_RetInnReceiveGuest>((msg) =>
            {
                callback?.Invoke();
            }));
    }

    /// <summary>
    /// 请求结算
    /// </summary>
    public void reqSettle(int stationId, Action callback)
    {
        NPGSClientListener.sendRequest(
            NPGSWriter_034_InnOp.make_006_ReqInnSettle(stationId),
            new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_034_006_RetInnSettle>((msg) =>
            {
                callback?.Invoke();
            }));
    }
}
```

## UI 窗口

### 旅店主界面

```csharp
public class InnMainWindow : BaseWindow
{
    // 接待客人
    public void onClickReceiveGuest(int stationId)
    {
        // 打开客人选择界面
        UIManager.openWindow<InnGuestSelectWindow>((win) =>
        {
            win.setStationId(stationId);
        });
    }

    // 结算
    public void onClickSettle(int stationId)
    {
        InnComponent.instance.reqSettle(stationId, () =>
        {
            refreshUI();
            showSettleEffect();
        });
    }
}
```

## 注意事项

1. 座位需要解锁才能使用
2. 菜品品质影响客人满意度
3. 特殊客人有额外奖励
