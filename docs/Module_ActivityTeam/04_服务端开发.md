## 业务逻辑

### 创建队伍流程

1. 验证玩家是否已在队伍中
2. 验证活动实例有效性
3. 创建队伍并设置队长
4. 广播队伍创建通知

### 加入队伍流程

1. 验证队伍存在性
2. 验证加入条件(等级、战力等)
3. 根据joinType处理:
   - FREE: 直接加入
   - APPLY: 创建申请记录
   - INVITE: 验证邀请有效性
4. 广播成员加入通知

### 踢人流程

1. 验证操作者是否为队长
2. 验证被踢者是否在队伍中
3. 移除成员数据
4. 广播移除通知

## 扩展开发
