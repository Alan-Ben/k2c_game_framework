# 阶段目标模块实现细节

## 一、计算公式

### 1.1 阶段进度计算公式

```
阶段完成率 = 已完成任务数 / 总任务数 × 100%
```

**示例计算**：
```
已完成任务：4个
总任务数：5个

阶段完成率 = 4 / 5 × 100% = 80%
```

### 1.2 任务进度计算公式

```
任务进度百分比 = min(当前值 / 目标值 × 100%, 100%)
```

**示例计算**：
```
当前值：强化18次
目标值：强化20次

任务进度百分比 = min(18 / 20 × 100%, 100%) = 90%
```

### 1.3 TOP1玩家判定公式

```
TOP1 = 当前阶段数最大的玩家
若阶段数相同，则比较完成时间
```

**示例计算**：
```
玩家A：阶段5，完成时间 10:30:00
玩家B：阶段5，完成时间 10:25:00
玩家C：阶段4

TOP1 = 玩家B（同阶段，时间更早）
```

### 1.4 首达奖励判定公式

```
首达资格 = 当前阶段无首达记录 AND 玩家完成阶段
```

## 四、错误处理策略

### 4.1 阶段目标模块错误码

| 错误码 | 错误信息 | 处理策略 | 用户提示 |
|--------|----------|----------|----------|
| 70001 | 阶段未解锁 | 检查解锁条件 | "该阶段尚未解锁" |
| 70002 | 任务未完成 | 检查任务进度 | "任务尚未完成" |
| 70003 | 奖励已领取 | 检查领取记录 | "奖励已领取" |
| 70004 | 无首达资格 | 检查首达记录 | "首达奖励已被领取" |
| 70005 | 阶段未完成 | 检查阶段状态 | "阶段尚未完成" |
| 70006 | 配置不存在 | 检查配置表 | "配置数据异常" |
| 70007 | 参数错误 | 检查请求参数 | "参数错误" |

### 4.2 奖励领取错误处理流程

```mermaid
flowchart TD
    A[领取请求] --> B{阶段验证}
    B -->|未解锁| C[返回阶段未解锁]
    B -->|已解锁| D{任务/阶段验证}
    D -->|未完成| E[返回未完成]
    D -->|已完成| F{领取验证}
    F -->|已领取| G[返回已领取]
    F -->|未领取| H[发放奖励]
    H --> I{发放结果}
    I -->|成功| J[更新状态]
    I -->|失败| K[回滚数据]
    J --> L[返回成功]
    K --> M[返回失败]
```

### 4.3 异常处理策略

| 异常场景 | 处理策略 | 数据处理 |
|----------|----------|----------|
| 首达并发竞争 | 使用分布式锁保证唯一 | 只记录第一个 |
| 奖励发放失败 | 事务回滚 | 恢复原始状态 |
| 配置数据缺失 | 使用默认值，记录日志 | 继续执行 |
| 进度更新异常 | 忽略本次更新 | 不影响其他任务 |

## 五、关键代码示例

### 5.1 阶段初始化伪代码

```csharp
public Result InitStageGoal(long playerId)
{
    // 1. 获取所有大阶段配置
    List<RefStageGoalBigStep> bigSteps = configService.GetAllBigSteps();

    List<StageGoal_BigStepInfo> bigStepList = new List<StageGoal_BigStepInfo>();
    List<StageGoal_TaskInfo> taskList = new List<StageGoal_TaskInfo>();
    List<long> firstReachRewardList = new List<long>();

    foreach (var bigStep in bigSteps)
    {
        // 2. 获取玩家阶段数据
        PlayerBigStep playerStep = stageGoalDao.GetPlayerBigStep(playerId, bigStep.big_step);

        if (playerStep == null)
        {
            // 初始化阶段数据
            playerStep = new PlayerBigStep
            {
                cid = playerId,
                big_step_id = bigStep.big_step,
                status = CheckUnlockCondition(playerId, bigStep) ? 1 : 0
            };
            stageGoalDao.InsertPlayerBigStep(playerStep);
        }

        // 3. 构建阶段信息
        bigStepList.Add(new StageGoal_BigStepInfo
        {
            bigStepId = bigStep.big_step,
            status = playerStep.status,
            progress = CalculateProgress(playerId, bigStep)
        });

        // 4. 获取任务列表
        List<RefStageGoalTask> tasks = configService.GetTasksByBigStep(bigStep.big_step);
        foreach (var task in tasks)
        {
            PlayerStageTask playerTask = stageGoalDao.GetPlayerTask(playerId, task.id);
            if (playerTask == null)
            {
                playerTask = new PlayerStageTask
                {
                    cid = playerId,
                    task_id = task.id,
                    progress = 0,
                    target_value = task.target_value,
                    status = 0
                };
                stageGoalDao.InsertPlayerTask(playerTask);
            }

            taskList.Add(new StageGoal_TaskInfo
            {
                taskId = task.id,
                status = playerTask.status,
                progress = playerTask.progress,
                targetValue = playerTask.target_value
            });
        }
    }

    // 5. 获取已领取的首达奖励
    firstReachRewardList = stageGoalDao.GetFirstReachRewardList(playerId);

    return Result.Success(new StageGoalInitData
    {
        bigStepList = bigStepList,
        taskList = taskList,
        firstReachRewardList = firstReachRewardList
    });
}
```

### 5.2 任务进度更新伪代码

```csharp
public void UpdateTaskProgress(long playerId, int taskType, long value)
{
    // 1. 获取相关任务
    List<PlayerStageTask> tasks = stageGoalDao.GetTasksByType(playerId, taskType);

    foreach (var task in tasks)
    {
        // 2. 检查任务状态
        if (task.status != 0) continue;

        // 3. 获取任务配置
        RefStageGoalTask taskConfig = configService.GetTaskConfig(task.task_id);

        // 4. 更新进度
        switch (taskConfig.progressType)
        {
            case ProgressType.ADD:
                task.progress += (int)value;
                break;
            case ProgressType.SET:
                task.progress = Math.Max(task.progress, (int)value);
                break;
        }

        // 5. 检查完成
        if (task.progress >= task.target_value)
        {
            task.progress = task.target_value;
            task.status = 1; // 已完成

            // 推送任务完成
            PushTaskComplete(playerId, task);

            // 检查阶段完成
            CheckBigStepComplete(playerId, taskConfig.big_step_id);
        }

        stageGoalDao.UpdatePlayerTask(task);
    }
}
```

### 5.3 首达记录处理伪代码

```csharp
public bool RecordFirstReach(long playerId, string playerName, long bigStepId, long reachTimeMs)
{
    // 1. 使用分布式锁
    string lockKey = $"first_reach:{bigStepId}";
    using (var lock = distributedLock.Acquire(lockKey))
    {
        // 2. 检查是否已有首达
        if (firstReachDao.HasFirstReach(bigStepId))
        {
            return false;
        }

        // 3. 创建首达记录
        BigStageGoalFirstReachBO record = new BigStageGoalFirstReachBO
        {
            big_stage_id = bigStepId,
            cid = playerId,
            player_name = playerName,
            reach_time_ms = reachTimeMs
        };

        firstReachDao.Insert(record);

        // 4. 推送首达通知
        PushFirstReachNotice(playerId, playerName, bigStepId);

        return true;
    }
}
```

### 5.4 TOP1玩家追踪伪代码

```csharp
public void UpdateTop1Player(long playerId, long earnings, long step)
{
    // 1. 获取当前TOP1
    StageGoalTopPlayer top1 = topPlayerDao.GetTop1();

    bool needUpdate = false;

    if (top1 == null)
    {
        // 首次记录
        needUpdate = true;
    }
    else if (step > top1.step)
    {
        // 阶段更高
        needUpdate = true;
    }
    else if (step == top1.step && earnings > top1.cacheEarnings)
    {
        // 阶段相同，收益更高
        needUpdate = true;
    }

    if (needUpdate)
    {
        // 2. 更新TOP1
        if (top1 == null)
        {
            top1 = new StageGoalTopPlayer
            {
                cid = playerId,
                step = step,
                cache_earnings = earnings
            };
            topPlayerDao.Insert(top1);
        }
        else
        {
            top1.cid = playerId;
            top1.step = step;
            top1.cache_earnings = earnings;
            topPlayerDao.Update(top1);
        }

        // 3. 推送TOP1变化
        PushTop1Change(top1);
    }
}
```

### 5.5 领取首达奖励伪代码

```csharp
public Result DrawFirstReachReward(long playerId, long bigStepId)
{
    // 1. 检查首达记录
    BigStageGoalFirstReachBO record = firstReachDao.GetByBigStepId(bigStepId);
    if (record == null)
    {
        return Result.Error(70004, "首达奖励未产生");
    }

    // 2. 检查是否为本人
    if (record.cid != playerId)
    {
        return Result.Error(70004, "无首达资格");
    }

    // 3. 检查是否已领取
    if (firstReachDao.HasDrawnFirstReachReward(playerId, bigStepId))
    {
        return Result.Error(70003, "奖励已领取");
    }

    // 4. 获取首达奖励配置
    RefStageGoalBigStep config = configService.GetBigStepConfig(bigStepId);

    // 5. 发放奖励
    itemService.GiveItems(playerId, config.first_reach_reward);

    // 6. 记录领取
    firstReachDao.MarkFirstReachRewardDrawn(playerId, bigStepId);

    // 7. 推送领取结果
    PushFirstReachRewardDrawn(playerId, bigStepId, config.first_reach_reward);

    return Result.Success(config.first_reach_reward);
}
```
