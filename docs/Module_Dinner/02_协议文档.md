#### 客户端处理

```csharp
// 监听器处理
public class GSSubDealer_019_050_OnDinnerAdd : _AGSSubDealerBase
{
    public override void deal(NPPlayer _player, GS2GC_019_050_OnDinnerAdd _msg)
    {
        Dinner_Info dinnerInfo = _msg.getDinnerInfo();
        _player.dinnerComp.retOnDinnerAdd(dinnerInfo);
    }
}

// 组件处理
public void retOnDinnerAdd(Dinner_Info _info)
{
    if (null == _info) return;

    DinnerInfo dinnerInfo = new DinnerInfo(_info);
    _m_dinnerList.Add(dinnerInfo);

    WinMsg.SendMsg(WinMsgType.ON_DINNER_ADD, dinnerInfo);
}
```

## 五、协议交互流程

### 5.1 举办宴会完整流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Item as 道具模块
    participant Push as 推送服务

    C->>S: GC2GS_019_001_ReqStartDinner<br/>(dinnerCfgId)

    S->>S: 验证宴会配置
    S->>S: 检查是否已举办宴会
    S->>S: 计算消耗资源

    alt 资源不足
        S-->>C: 返回错误码: 资源不足
    else 检查通过
        S->>Item: 扣除消耗资源
        S->>DB: 创建宴会记录
        S->>DB: 举办者自动加入
        S->>S: 设置结束时间

        S-->>C: GS2GC_019_001_RetStartDinner<br/>(dinnerInfo)

        S->>Push: 推送宴会添加通知
        Push-->>C: GS2GC_019_050_OnDinnerAdd
    end
```

### 5.2 加入宴会完整流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库

    C->>S: GC2GS_019_008_ReqJoinDinner<br/>(dinnerId, hostPlayerId)

    S->>DB: 查询宴会信息
    DB-->>S: 返回宴会数据

    alt 宴会不存在
        S-->>C: 返回错误码: 宴会不存在
    else 宴会已结束
        S-->>C: 返回错误码: 宴会已结束
    else 宴会已满
        S-->>C: 返回错误码: 宴会已满
    else 已加入过
        S-->>C: 返回错误码: 已加入
    else 检查通过
        S->>DB: 添加参与记录
        S->>DB: 更新参与人数
        S-->>C: GS2GC_019_008_RetJoinDinner<br/>(dinnerId, joinerInfo)
        S-->>C: GS2GC_019_053_OnJoinerAdd
    end
```

### 5.3 领取奖励流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Reward as 奖励模块

    C->>S: GC2GS_019_009_ReqTakeOpenReward<br/>(dinnerId)

    S->>DB: 查询参与记录
    DB-->>S: 返回参与数据

    alt 未参加宴会
        S-->>C: 返回错误码: 未参加宴会
    else 已领取
        S-->>C: 返回错误码: 奖励已领取
    else 检查通过
        S->>S: 计算基础奖励
        S->>S: 检查许可额外奖励
        S->>Reward: 发放奖励
        S->>DB: 更新领取状态
        S-->>C: GS2GC_019_009_RetTakeOpenReward<br/>(rewardList)
    end
```

### 5.4 发送邀请流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Friend as 好友模块

    C->>S: GC2GS_019_013_ReqSendInviteToPlayer<br/>(targetPlayerId)

    S->>DB: 查询正在举办的宴会
    DB-->>S: 返回宴会数据

    alt 没有举办宴会
        S-->>C: 返回错误码: 没有进行中的宴会
    else 宴会已结束
        S-->>C: 返回错误码: 宴会已结束
    else
        S->>Friend: 检查好友关系
        alt 非好友关系
            S-->>C: 返回错误码: 非好友关系
        else 是好友
            S->>DB: 创建邀请记录
            S-->>C: GS2GC_019_013_RetSendInviteToPlayer
            Note over S: 推送邀请给目标玩家
        end
    end
```

### 5.5 宴会结束定时检查流程

```mermaid
sequenceDiagram
    participant Timer as 定时器
    participant S as 服务端
    participant DB as 数据库
    participant C as 客户端

    loop 每分钟检查
        Timer->>S: 检查过期宴会
        S->>DB: 查询state=1且end_time<=now
        DB-->>S: 返回过期宴会列表

        loop 遍历每个宴会
            S->>DB: 更新状态为已结束
            S-->>C: GS2GC_019_051_OnDinnerEnd
        end
    end
```

## 六、协议错误码

### 6.1 宴会模块错误码定义

| 错误码 | 常量名 | 说明 | 触发场景 | 用户提示 |
|--------|--------|------|----------|----------|
| 19001 | DINNER_CONFIG_NOT_FOUND | 宴会配置不存在 | 查询配置时 | "宴会类型不存在" |
| 19002 | DINNER_ALREADY_HOSTED | 已举办未结束的宴会 | 举办宴会时 | "您已举办了宴会，请等待结束" |
| 19003 | DINNER_NOT_FOUND | 宴会不存在 | 查询宴会时 | "该宴会不存在" |
| 19004 | DINNER_ENDED | 宴会已结束 | 加入宴会时 | "该宴会已结束" |
| 19005 | DINNER_FULL | 宴会已满 | 加入宴会时 | "该宴会人数已满" |
| 19006 | ALREADY_JOINED | 已加入该宴会 | 加入宴会时 | "您已参加该宴会" |
| 19007 | NOT_JOINED | 未参加该宴会 | 领取奖励时 | "您未参加该宴会" |
| 19008 | REWARD_TAKEN | 奖励已领取 | 领取奖励时 | "奖励已领取" |
| 19009 | PERMIT_NOT_FOUND | 许可不存在 | 使用许可时 | "许可不存在" |

```mermaid
flowchart TD
    A[新版本协议] --> B{检查客户端版本}
    B -->|旧版本| C[兼容处理]
    B -->|新版本| D[正常处理]

    C --> E[忽略新增字段]

    C --> G[返回兼容响应]

    D --> H[使用完整功能]

        I["新增字段: 旧版本忽略"]

    end
```

| 升级类型 | 兼容性 | 处理方式 |
|----------|--------|----------|
| 新增字段 | 向后兼容 | 旧版本忽略，新版本使用 |
| 新增协议 | 向后兼容 | 旧版本不调用，新版本使用 |
| 删除字段 | 不兼容 | 需要强制更新 |
