# 活动模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### CommonActivityComponent
**路径**: `GameComponent/CommonActivity/CommonActivityComponent.cs`

**功能**: 通用活动管理器，管理各类活动数据

**继承关系**:
```
CommonActivityComponent : _ANPBasicPlayerComponent
```

**协议模块**: p017_ActivityOp, p033_SimpleActivityOp

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| activityList | List<ActivityInfo> | 活动列表 |
| activityShopDic | Dictionary | 活动商店字典 |
| stepRewardDic | Dictionary | 阶段奖励字典 |

---

### 1.2 活动信息类

#### ActivityInfo (基类)
**路径**: `GameComponent/CommonActivity/Base/_ABaseActivityInfo.cs`

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| activityId | long | 活动ID |
| activityType | int | 活动类型 |
| startTime | long | 开始时间 |
| endTime | long | 结束时间 |
| status | int | 活动状态 |

---

### 1.3 活动类型

| 类型 | 类名 | 说明 |
|------|------|------|
| 默认活动 | DefaultActivityInfo | 通用活动 |
| 组队活动 | FirstTeamActivityInfo | 首期组队 |
| 排行冲刺 | ActivityRankRushInfo | 排行榜冲刺 |
| 阶段奖励 | ActivityStepRewardInfo | 阶段任务奖励 |

---

## 四、访问方式

```csharp
// 获取活动组件
CommonActivityComponent activityComp = NPPlayer.instance.commonActivityComponent;

// 获取活动列表
var activities = activityComp.activityList;

// 获取指定活动
var activity = activities.FirstOrDefault(a => a.activityId == activityId);
```
