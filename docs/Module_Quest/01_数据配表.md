# 任务模块数据配表文档

## 配表说明

任务模块相关的配置数据主要存储在以下配表中:

---

## 一、主线任务配表

### QuestRefObj - 任务配置
**文件**: `quest_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 任务配置ID |
| name | string | 任务名称 |
| type | int | 任务类型 |
| chapter | int | 所属章节 |
| step | int | 任务步骤 |
| target | object | 任务目标 |
| reward | object | 任务奖励 |
| pre_quest | long | 前置任务ID |
| next_quest | long | 后续任务ID |

---

### QuestTargetRefObj - 任务目标配置
**文件**: `quest_target_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 目标ID |
| type | int | 目标类型 |
| param | object | 目标参数 |
| count | int | 目标数量 |
| description | string | 目标描述 |

**目标类型枚举**:
| 类型ID | 说明 |
|--------|------|
| 1 | 击杀怪物 |
| 2 | 收集物品 |
| 3 | 到达地点 |
| 4 | 对话NPC |
| 5 | 完成副本 |
| 6 | 升级建筑 |

---

## 二、日常任务配表

### DailyQuestRefObj - 日常任务配置
**文件**: `daily_quest_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 任务ID |
| name | string | 任务名称 |
| type | int | 任务类型 |
| target | object | 任务目标 |
| reward | object | 任务奖励 |
| active_point | int | 活跃度点数 |

---

### DailyActiveRefObj - 活跃度奖励配置
**文件**: `daily_active_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| point | int | 活跃度点数 |
| reward | object | 奖励内容 |

---

## 三、系统任务配表

### SystemQuestRefObj - 系统任务配置
**文件**: `system_quest_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 任务ID |
| name | string | 任务名称 |
| type | int | 任务类型 |
| target_list | array | 目标列表 |
| reward_list | array | 奖励列表 |
| time_limit | long | 时间限制（秒） |

---

## 四、任务状态枚举

### EQuestStatus
**文件**: `ClientProtocol/Common/QuestEnum/EQuestStatus.cs`

| 枚举值 | 说明 |
|--------|------|
| None | 无状态 |
| NotStart | 未开始 |
| InProgress | 进行中 |
| Completed | 已完成 |
| Rewarded | 已领奖 |

---

## 五、配表加载方式

```csharp
// 获取任务配置
QuestRefObj questRef = GRefdataCoreMgr.instance.questRefCore.getRef(questId);

// 获取日常任务配置
DailyQuestRefObj dailyRef = GRefdataCoreMgr.instance.dailyQuestRefCore.getRef(dailyQuestId);

// 获取系统任务配置
SystemQuestRefObj systemRef = GRefdataCoreMgr.instance.systemQuestRefCore.getRef(systemQuestId);
```
