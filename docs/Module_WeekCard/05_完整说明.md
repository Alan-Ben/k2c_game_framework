# 周卡模块完整说明

## 一、模块概述

### 1.1 业务背景

周卡模块是 K2C 游戏的付费特权系统，玩家购买周卡后可获得持续一周的特权福利，包括离线挂机收益、自动处理功能、专属NPC形象等。该模块通过离线收益机制，为付费玩家提供便捷的游戏体验，同时也为游戏带来稳定的收入。

### 1.2 目标用户

- **付费玩家**：购买周卡享受特权福利
- **时间有限玩家**：通过离线挂机减少在线时间需求
- **追求效率玩家**：使用自动处理功能提升游戏效率

### 1.3 核心价值

1. **离线收益**：玩家离线期间仍可获得收益
2. **自动化处理**：自动处理日常任务和事件
3. **专属特权**：独特的NPC形象和功能特权
4. **付费留存**：提升付费玩家满意度和留存率

## 三、业务流程详解

### 3.1 周卡激活流程

```mermaid
flowchart TD
    A[玩家购买/激活周卡] --> B{检查当前状态}
    B -->|首次激活| C[记录激活时间]
    B -->|已过期| D[重新激活]
    B -->|生效中| E[延长有效期]
    C --> F[计算过期时间]
    D --> F
    E --> G[累加有效时间]
    G --> H[更新数据]
    F --> H
    H --> I[检查各模块设置]
    I --> J[推送周卡变化]
    J --> K[显示周卡状态]
```

**详细步骤说明**：

1. **状态检查**
   - 检查是否首次激活
   - 检查当前周卡状态
   - 计算新过期时间

2. **时间计算**
   - 首次：当前时间 + 周卡时长
   - 已过期：重新开始计算
   - 生效中：累加到当前过期时间

3. **初始化**
   - 检查各代理模块设置
   - 初始化默认配置
   - 推送状态变化

### 3.2 离线结算流程

```mermaid
flowchart TD
    A[玩家上线] --> B{检查周卡状态}
    B -->|未生效| C[正常登录流程]
    B -->|已生效| D[获取离线时间]
    D --> E{检查离线时长}
    E -->|过短| C
    E -->|足够| F[计算结算范围]
    F --> G[遍历代理模块]
    G --> H[计算各模块溢出CD]
    H --> I[汇总结算收益]
    I --> J{是否有收益}
    J -->|无| C
    J -->|有| K[显示结算界面]
    K --> L[玩家确认领取]
    L --> M[发放离线收益]
    M --> N[更新各模块状态]
```

**详细步骤说明**：

1. **离线验证**
   - 检查周卡是否生效
   - 检查离线时长是否达标
   - 验证结算条件

2. **收益计算**
   - 遍历所有代理模块
   - 计算各模块溢出CD
   - 汇总所有收益

3. **结算发放**
   - 显示结算界面
   - 玩家确认后发放
   - 更新各模块状态

## 四、关键规则

### 4.1 周卡时间规则

1. **有效时长**
   - 购买获得7天（168小时）
   - 可累计延长
   - 无上限

2. **时间计算**
   - 以服务器时间为准
   - 精确到秒
   - 持续倒计时

3. **过期处理**
   - 过期后特权失效
   - 数据保留但不生效
   - 续费后重新激活

### 4.2 离线收益规则

1. **离线时长**
   - 最小离线时长：30分钟
   - 最大收益时长：12小时
   - 超出部分不计收益

2. **收益计算**
   - 按离线时间比例计算
   - 各模块独立计算
   - 有收益上限限制

3. **领取规则**
   - 上线时自动弹出结算界面
   - 需手动确认领取
   - 不可补领过期未领

### 4.3 代理处理规则

1. **代理类型**
   - 征收：自动完成征收CD
   - 政务：自动处理政务事件
   - 妃子倾诉：自动处理妃子倾诉
   - 大学学习：自动完成学习任务
   - 游历：自动处理游历事件

2. **处理条件**
   - 周卡必须生效
   - 对应代理功能已开启
   - 满足各模块的处理条件

3. **处理策略**
   - 可配置处理优先级
   - 可配置处理参数
   - 支持条件判断

### 4.4 免费试用规则

1. **试用条件**
   - 新玩家首次体验
   - 每个账号仅一次
   - 无需付费

2. **试用时长**
   - 默认24小时
   - 可配置调整

3. **试用转正**
   - 试用期间购买周卡
   - 试用时间累加到购买时间
