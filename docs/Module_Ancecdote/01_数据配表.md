# Anecdote 轶事/奇遇模块 - 数据配表文档

## 模块概述

**模块名称**: Anecdote (轶事/奇遇)
**模块类型**: 客户端独立组件
**主要功能**: 提供游戏内随机事件、奇遇系统的管理和展示

## 配置文件

### 配置表

| 配置表名称 | 用途 |
|-----------|------|
| AnecdoteEventConfig | 轶事事件配置 |
| AnecdoteChoiceConfig | 选择项配置 |
| AnecdoteRewardConfig | 奖励配置 |

## 数据结构

### 事件信息 (AnecdoteEventInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| eventId | int | 事件ID |
| eventType | int | 事件类型 |
| title | String | 事件标题 |
| content | String | 事件内容 |
| triggerCondition | Object | 触发条件 |

### 选择信息 (AnecdoteEventChoiceInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| choiceId | int | 选择ID |
| choiceText | String | 选择文本 |
| resultType | int | 结果类型 |
| rewardInfo | Object | 奖励信息 |

### 收益信息 (AnecdoteEventEarningsInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| earningsType | int | 收益类型 |
| earningsValue | long | 收益值 |
| earningsDesc | String | 收益描述 |

### 位置信息 (AnecdotePosInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| posId | int | 位置ID |
| posX | float | X坐标 |
| posY | float | Y坐标 |
| eventId | int | 事件ID |
