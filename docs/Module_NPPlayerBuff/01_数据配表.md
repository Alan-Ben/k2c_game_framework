# NPPlayerBuff 玩家Buff模块 - 数据配表文档

## 模块概述

**模块名称**: NPPlayerBuff (玩家Buff)
**模块类型**: 客户端独立组件
**主要功能**: 管理玩家身上的Buff状态和效果

## 配置文件

### 配置表

| 配置表名称 | 用途 |
|-----------|------|
| PlayerBuffConfig | 玩家Buff配置 |
| BuffEffectConfig | Buff效果配置 |

## 数据结构

### Buff信息 (NPPlayerBuffInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| buffId | int | Buff ID |
| buffType | int | Buff类型 |
| remainTime | long | 剩余时间 |
| effectValue | long | 效果值 |
| sourceType | int | 来源类型 |

### Buff组件 (NPPlayerBuffComponent)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| buffList | List | Buff列表 |
| totalEffect | Object | 总效果加成 |

## Buff类型

| 类型ID | 类型名 | 说明 |
|--------|--------|------|
| 1 | ATTACK | 攻击加成 |
| 2 | DEFENSE | 防御加成 |
| 3 | SPEED | 速度加成 |
| 4 | RESOURCE | 资源产量加成 |
| 5 | SPECIAL | 特殊效果 |
