# 公会模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

公会模块（Guild Module）负责管理公会相关的数据和业务逻辑，包括：
- 公会创建、加入、退出
- 公会成员管理
- 公会建设与升级
- 公会宝箱系统
- 公会求助与帮助系统
- 火星系统公会功能

### 1.2 模块编号

协议模块编号: `p032`, `p042`

## 四、核心逻辑流程

### 4.1 创建公会流程

```
客户端                          服务端
   |                               |
   |--- ReqCreateGuild ----------->|
   |                               | 1. 验证玩家是否已有公会
   |                               | 2. 验证创建资源是否足够
   |                               | 3. 扣除创建资源
   |                               | 4. 创建公会数据
   |                               | 5. 设置玩家为盟主
   |<-- RetCreateGuild ------------|
   |                               |
```

### 4.2 加入公会流程

```
客户端                          服务端
   |                               |
   |--- ReqJoinGuild ------------->|
   |                               | 1. 验证玩家是否已有公会
   |                               | 2. 验证公会是否存在
   |                               | 3. 验证公会是否满员
   |                               | 4. 加入公会（自动或审批）
   |<-- RetJoinGuild --------------|
   |<-- OnGuildMemberChg ----------| (推送成员变化)
   |                               |
```

## 六、服务配置

### 6.1 协议注册

```csharp
// 协议主序号
public const byte GUILD_MODULE_ORDER = 32;
public const byte GUILD_RELATED_ORDER = 42;

// 协议处理器注册
protocolHandler.Register<GC2GS_032_001_ReqCreateGuild>(OnCreateGuild);
protocolHandler.Register<GC2GS_032_002_ReqJoinGuild>(OnJoinGuild);

```

### 6.2 服务依赖

公会模块依赖以下服务：
- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
- 跨服服务 (CrossServerService)
