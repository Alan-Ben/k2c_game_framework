## 核心管理类

### MarsExploreMgr

探索管理器，负责:
- 探索队伍管理
- 探索进度计算
- 探索奖励结算

### MarsMineMgr

矿点管理器，负责:
- 矿点生成和刷新
- 矿点占领状态
- 采集进度管理
- PVP战斗处理

## 业务逻辑

### 探索流程

1. 派遣探索队伍
2. 到达目标矿点
3. 开始采集
4. 采集完成或被打断
5. 队伍返回

### PVP流程

1. 玩家发起攻击
2. 战斗计算
3. 更新矿点归属
4. 记录PVP日志
5. 通知双方玩家

### 公会分享流程

1. 玩家分享矿点
2. 推送给公会成员
3. 成员协助采集
4. 分配采集收益
