# 红点系统协议文档

## 协议模块编号: p002 (InitOp) / p007 (CommOp)

---

## 一、客户端请求协议 (GC2GS)

### 1.1 初始化相关

#### GC2GS_002_080_ReqRedDotInit - 请求红点初始化
**功能说明**: 请求获取玩家所有红点状态

| 字段名 | 类型 | 说明 |
|--------|------|------|
| (无参数) | - | - |

---

### 1.2 红点操作

#### GC2GS_007_031_ReqClearRedDot - 清除红点
**功能说明**: 清除指定类型的红点

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | ERedDotType | 红点类型 |

---

#### GC2GS_007_032_ReqCheckRedDot - 检查红点
**功能说明**: 检查指定类型的红点状态

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | ERedDotType | 红点类型 |

---

## 二、服务端响应协议 (GS2GC)

### 2.1 初始化响应

#### GS2GC_002_080_RetRedDotInit - 返回红点初始化数据
**功能说明**: 返回玩家所有红点状态

| 字段名 | 类型 | 说明 |
|--------|------|------|
| redDotList | List&lt;Common_RedDotInfo&gt; | 红点列表 |

---

### 2.2 操作响应

#### GS2GC_007_031_RetClearRedDot - 清除红点结果
**功能说明**: 返回清除红点结果

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | ERedDotType | 红点类型 |
| result | Result | 操作结果 |

---

#### GS2GC_007_032_RetCheckRedDot - 检查红点结果
**功能说明**: 返回检查红点结果

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | ERedDotType | 红点类型 |
| shouldShow | bool | 是否应显示 |
| expireTimeMs | long | 过期时间 |

---

### 2.3 推送通知协议

#### GS2GC_007_059_PushRedDotChg - 红点变化推送
**功能说明**: 推送红点添加或更新

| 字段名 | 类型 | 说明 |
|--------|------|------|
| redDotInfo | Common_RedDotInfo | 红点信息 |

---

#### GS2GC_007_060_PushRedDotRemove - 红点移除推送
**功能说明**: 推送红点移除

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | ERedDotType | 红点类型 |

---

## 三、协议调用流程

### 3.1 红点初始化流程
```
客户端                          服务端
   |                               |
   |--- ReqRedDotInit ------------>|
   |                               | (获取红点状态)
   |<-- RetRedDotInit -------------|
   |                               |
```

### 3.2 红点变化推送流程
```
服务端                           客户端
   |                               |
   | (检测到红点条件变化)           |
   |--- PushRedDotChg ------------>|
   |                               | (更新本地红点状态)
   |                               |
```

### 3.3 红点清除流程
```
客户端                          服务端
   |                               |
   |--- ReqClearRedDot ----------->|
   |                               | (清除红点)
   |<-- RetClearRedDot ------------|
   |<-- PushRedDotRemove ---------| (可选)
   |                               |
```

---

## 四、红点特性

### 4.1 内存存储

红点系统只在内存中维护数据，不进行数据库持久化。

### 4.2 自动推送

当红点状态变化时，服务端自动推送到客户端。

### 4.3 过期机制

红点支持过期时间，过期后自动消失。
