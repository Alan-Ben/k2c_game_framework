# 玩家称号客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerTitleComponent
**路径**: `GameComponent/PlayerTitle/PlayerTitleComponent.cs`

**功能**: 管理玩家所有称号数据

**继承关系**:
```
PlayerTitleComponent : _ANPBasicPlayerComponent
```

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| isShowOthers | bool | 是否展示给其他玩家 |
| curTitle | PlayerInfo_CurTitle | 当前穿戴的称号 |

## 二、数据管理

### 2.1 称号列表管理

组件维护多种称号列表：

| 列表 | 类型 | 说明 |
|------|------|------|
| _m_lPlayerTitleInfoList | List&lt;PlayerTitleInfo&gt; | 普通/限时称号列表 |
| _m_lComboPreList | List&lt;PlayerTitleComboPreInfo&gt; | 组合称号前缀列表 |
| _m_lComboSfxList | List&lt;PlayerTitleComboSfxInfo&gt; | 组合称号后缀列表 |
| _m_lComboBgList | List&lt;PlayerTitleComboBgInfo&gt; | 组合称号底框列表 |

## 三、主要方法

### 3.1 获取称号信息

```csharp
// 获取普通称号信息
PlayerTitleInfo titleInfo = NPPlayer.instance.playerTitleComponent.getTitleInfo(titleId);

// 获取组合称号前缀信息
PlayerTitleComboPreInfo preInfo = NPPlayer.instance.playerTitleComponent.getTitleComboPreInfo(preId);

// 获取组合称号后缀信息
PlayerTitleComboSfxInfo sfxInfo = NPPlayer.instance.playerTitleComponent.getTitleComboSfxInfo(sfxId);

// 获取组合称号底框信息
PlayerTitleComboBgInfo bgInfo = NPPlayer.instance.playerTitleComponent.getTitleComboBgInfo(bgId);
```

### 3.2 获取当前穿戴称号

```csharp
// 获取当前穿戴的组合称号
PlayerInfo_ComboTitle comboTitle = NPPlayer.instance.playerTitleComponent.getCurWearComboTitleInfo();

// 获取当前穿戴的普通称号
PlayerInfo_Title commTitle = NPPlayer.instance.playerTitleComponent.getCurWearCommonTitleInfo();
```

## 四、请求方法

### 4.1 称号穿戴请求

```csharp
// 穿戴普通称号
NPPlayer.instance.playerTitleComponent.reqSetCommTitle(titleId, () =>
{
    Debug.Log("穿戴成功");
});

// 穿戴组合称号
NPPlayer.instance.playerTitleComponent.reqSetComboTitle(prefixId, suffixId, bgId, () =>
{
    Debug.Log("穿戴成功");
});

// 设置是否展示
NPPlayer.instance.playerTitleComponent.reqSetTitleShow(true);
```

### 4.2 组合称号解锁请求

```csharp
// 解锁前缀
NPPlayer.instance.playerTitleComponent.reqUnlockComboTitlePre(preId);

// 解锁后缀
NPPlayer.instance.playerTitleComponent.reqUnlockComboTitleSfx(sfxId);

// 解锁底框
NPPlayer.instance.playerTitleComponent.reqUnlockComboTitleBg(bgId);
```

### 4.3 设置已查看

```csharp
// 设置称号已查看
NPPlayer.instance.playerTitleComponent.setReadTitleRedTip(titleId);

// 设置前缀已查看
NPPlayer.instance.playerTitleComponent.setReadPrefixTitleRedTip(preId);

// 设置后缀已查看
NPPlayer.instance.playerTitleComponent.setReadSuffixTitleRedTip(sfxId);

// 设置底框已查看
NPPlayer.instance.playerTitleComponent.setReadBgTitleRedTip(bgId);
```
