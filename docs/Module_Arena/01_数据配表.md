# 竞技场系统 - 数据配表

## 概述

竞技场系统 (ArenaOp, p023) 是游戏中的PVP玩法，玩家可以挑战其他玩家提升排名，获取奖励。

## 配表文件

### 1. 竞技场配置 (Arena)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| arena_id | int | 竞技场ID |
| arena_name | string | 竞技场名称 |
| season_duration | int | 赛季时长 |
| rank_reward | array | 段位奖励 |

### 2. 竞技场段位配置 (ArenaRank)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rank_id | int | 段位ID |
| rank_name | string | 段位名称 |
| min_score | int | 最低分数 |
| max_score | int | 最高分数 |
| reward | array | 段位奖励 |

### 3. 竞技场Buff配置 (ArenaBuff)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| buff_id | int | Buff ID |
| buff_name | string | Buff名称 |
| buff_type | int | Buff类型 |
| effect_value | float | 效果值 |

### 4. 爬塔配置 (Tower)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| tower_id | int | 爬塔ID |
| chapter_id | int | 章节ID |
| floor | int | 层数 |
| enemy_list | array | 敌人列表 |
| reward | array | 通关奖励 |

### 5. 爬塔研究配置 (TowerResearch)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| research_id | int | 研究ID |
| research_name | string | 研究名称 |
| cost | array | 消耗 |
| effect | json | 效果 |

## 竞技场状态枚举

```csharp
public enum EArenaState
{
    IDLE = 0,       // 空闲
    MATCHING = 1,   // 匹配中
    FIGHTING = 2    // 战斗中
}
```
