# 任务模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerQuestComponent
**路径**: `GameComponent/Quest/PlayerQuestComponent.cs`

**功能**: 任务模块管理类，管理玩家任务数据

**继承关系**:
```
PlayerQuestComponent : _ANPBasicPlayerComponent
```

**协议模块**: p028_QuestOp

**依赖组件**:
- `ENPPlayerCompType.BASIC_INFO`

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| questItemMgr | QuestItemMgr | 任务数据管理类 |
| questCountItemMgr | QuestCountItemMgr | 任务计数管理类 |
| questEntryIsShow | bool | 任务入口是否展示 |
| canShowTargetFinishTip | bool | 是否可显示目标完成提示 |

---

#### PlayerDailyQuestComponent
**路径**: `GameComponent/Quest/PlayerDailyQuestComponent.cs`

**功能**: 日常/周常任务管理

**继承关系**:
```
PlayerDailyQuestComponent : _ANPBasicPlayerComponent
```

---

### 1.2 任务信息类

#### QuestItem
**路径**: `GameComponent/Quest/QuestItem.cs`

**主要属性**:

| 属性名 | 类型 | 说明 |

#### QuestCountItem
**路径**: `GameComponent/Quest/QuestCountItem.cs`

## 二、协议接口

### 2.1 请求协议

| 协议名 | 说明 |
|--------|------|
| GC2GS_028_001_ReqStartQuest | 开始任务 |
| GC2GS_028_002_ReqFinishQuest | 完成任务 |
| GC2GS_028_003_ReqDropQuest | 放弃任务 |
| GC2GS_028_004_ReqAddClientTargetCount | 增加客户端目标计数 |

### 2.2 日常任务协议

| 协议名 | 说明 |
|--------|------|
| GC2GS_028_010_ReqFinishDailyQuest | 完成日常任务 |
| GC2GS_028_011_ReqDrawActiveReward | 领取活跃度奖励 |
| GC2GS_028_012_ReqDailyQuestTryFresh | 刷新日常任务 |
| GC2GS_028_013_ReqDailyQuestAKeyDrawFinishReward | 一键领取完成奖励 |
| GC2GS_028_014_ReqDailyQuestAKeyDrawActiveReward | 一键领取活跃奖励 |

### 2.3 响应协议

| 协议名 | 说明 |
|--------|------|
| GS2GC_028_001_RetStartQuest | 开始任务结果 |
| GS2GC_028_002_RetFinishQuest | 完成任务结果 |
| GS2GC_028_003_RetDropQuest | 放弃任务结果 |
| GS2GC_028_010_RetFinishDailyQuest | 完成日常任务结果 |
| GS2GC_028_050_OnQuestAdd | 任务新增推送 |
| GS2GC_028_051_OnQuestRemove | 任务移除推送 |
| GS2GC_028_052_OnQuestUpdate | 任务更新推送 |
| GS2GC_028_053_OnQuestTargetUpdate | 任务目标更新推送 |

## 五、访问方式

```csharp
// 获取任务组件
PlayerQuestComponent questComp = NPPlayer.instance.questComp;

// 获取任务管理器
QuestItemMgr mgr = questComp.questItemMgr;

// 获取指定任务
QuestItem quest = mgr.getQuest(questId);

// 获取日常任务组件
PlayerDailyQuestComponent dailyComp = NPPlayer.instance.dailyQuestComp;
```
