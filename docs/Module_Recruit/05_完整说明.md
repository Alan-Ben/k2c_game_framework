# 招募模块完整说明

## 一、模块概述

### 1.1 业务背景

招募模块是 K2C 游戏的抽卡系统，负责管理玩家的招募行为和招募结果。玩家可以通过招募获得英雄、伴侣、道具等游戏资源。招募系统是游戏的核心玩法之一，也是重要的商业变现途径。

### 1.2 目标用户

- **所有游戏玩家**：每位玩家都可以参与招募
- **付费玩家**：通过付费获得更多招募机会
- **收集型玩家**：追求收集所有角色

### 1.3 核心价值

1. **角色获取**：获得英雄、伴侣等核心角色
2. **付费转化**：是主要的付费点之一
3. **游戏乐趣**：抽卡的期待感和惊喜感
4. **公平机制**：保底机制保障玩家利益

## 三、业务流程详解

### 3.1 单次招募流程

```mermaid
flowchart TD
    A[请求单次招募] --> B{检查招募池配置}
    B -->|配置不存在| C[返回错误]
    B -->|配置有效| D{检查招募次数}
    D -->|次数非法| E[返回参数错误]
    D -->|次数合法| F{检查资源是否足够}
    F -->|资源不足| G[返回资源不足]
    F -->|资源充足| H[扣除招募资源]
    H --> I{检查保底状态}
    I -->|触发保底| J[按保底规则抽取]
    I -->|未触发保底| K[按概率抽取]
    J --> L[发放招募结果]
    K --> L
    L --> M[更新保底计数]
    M --> N[推送招募结果]
    N --> O[显示招募动画]
```

**详细步骤说明**：

1. **配置验证**
   - 验证招募池ID是否有效
   - 获取招募池配置信息

2. **资源检查**
   - 检查招募所需资源
   - 验证资源是否充足

3. **概率抽取**
   - 检查是否触发保底
   - 根据概率表随机抽取

4. **结果处理**
   - 发放抽取到的物品
   - 更新保底计数
   - 记录招募历史

### 3.2 十连招募流程

```mermaid
flowchart TD
    A[请求十连招募] --> B{检查招募池配置}
    B -->|配置不存在| C[返回错误]
    B -->|配置有效| D{检查资源是否足够x10}
    D -->|资源不足| E[返回资源不足]
    D -->|资源充足| F[扣除招募资源]
    F --> G[循环10次招募]
    G --> H{第i次招募}
    H --> I{检查保底状态}
    I -->|触发保底| J[保底抽取]
    I -->|未触发| K[概率抽取]
    J --> L[记录结果]
    K --> L
    L --> M{是否还有次数}
    M -->|是| H
    M -->|否| N[批量发放奖励]
    N --> O[更新保底计数]
    O --> P[保存招募记录]
    P --> Q[推送招募结果]
```

**详细步骤说明**：

1. **批量处理**
   - 一次性扣除十次资源
   - 逐次执行招募逻辑

2. **保底检查**
   - 每次招募独立检查保底
   - 保底计数逐次更新

3. **结果汇总**
   - 汇总十次招募结果
   - 批量发放物品
   - 显示汇总结果

### 3.3 保底机制流程

```mermaid
flowchart TD
    A[招募开始] --> B[获取当前保底计数]
    B --> C{是否达到大保底}
    C -->|是| D[必出UP角色]
    C -->|否| E{是否达到小保底}
    E -->|是| F[必出高稀有度]
    E -->|否| G[正常概率抽取]
    D --> H[重置保底计数]
    F --> I{是否为UP角色}
    I -->|是| H
    I -->|否| J[设置大保底标记]
    G --> K{抽取结果}
    K -->|高稀有度| L{是否为UP角色}
    K -->|普通| M[保底计数+1]
    L -->|是| H
    L -->|否| N[保底计数+1]
    N --> O{是否触发大保底标记}
    O -->|是| I
    O -->|否| P[更新计数]
```

### 3.4 招募记录保存流程

```mermaid
flowchart TD

    B --> C[设置记录ID]

    E --> F[记录招募时间]
    F --> G[保存到数据库]
    G --> H[推送记录通知]
```

## 四、关键规则

### 4.1 招募规则

1. **次数规则**
   - 单次招募：1次
   - 十连招募：10次
   - 只支持这两种次数

2. **资源规则**
   - 不同招募池消耗不同资源
   - 十连招募一次性扣除资源

### 4.2 概率规则

1. **概率配置**
   - 每个物品配置独立权重
   - 概率 = 物品权重 / 总权重

2. **稀有度概率**
   - 不同稀有度有不同概率区间
   - 高稀有度概率较低

### 4.3 保底规则

1. **小保底**
   - 每90次招募必出高稀有度
   - 出高稀有度后计数重置

2. **大保底**
   - 小保底出非UP角色后触发
   - 下次高稀有度必为UP角色
