# SimpleActivityOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p033
**模块名称**: SimpleActivityOp (简单活动操作)
**主要功能**: 提供收益目标、七日目标、充值返利等简单活动功能

## 配置文件

### 关联配置表

| 配置表名称 | 用途 |
|-----------|------|
| EarningsGoalConfig | 收益目标配置 |
| SevenDayGoalsConfig | 七日目标配置 |
| RechargeRebateConfig | 充值返利配置 |

## 数据结构

### 收益目标数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| goalId | int | 目标ID |
| progress | long | 当前进度 |
| targetValue | long | 目标值 |
| status | int | 状态(0未完成,1可领取,2已领取) |

### 七日目标数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| dayIndex | int | 第几天 |
| taskList | List | 任务列表 |
| rewardStatus | int | 奖励状态 |

### 充值返利数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| rebateId | int | 返利ID |
| rechargeAmount | long | 充值金额 |
| rebateRate | float | 返利比例 |
| rebateStatus | int | 返利状态 |
