## 核心逻辑

### 随机匹配

```java
public ArenaMatchInfo randomMatch(long playerId) {
    // 1. 获取玩家分数
    PlayerArena playerArena = arenaDao.selectById(playerId);
    int score = playerArena.getScore();

    // 2. 查找相近分数的玩家
    int scoreRange = 100; // 分数范围
    List<Long> candidateList = arenaDao.selectByScoreRange(
        score - scoreRange, score + scoreRange, playerId);

    if (candidateList.isEmpty()) {
        // 扩大范围
        candidateList = arenaDao.selectByScoreRange(
            score - scoreRange * 2, score + scoreRange * 2, playerId);
    }

    // 3. 随机选择
    Long targetId = candidateList.get(
        ThreadLocalRandom.current().nextInt(candidateList.size()));

    // 4. 创建匹配信息
    ArenaMatchInfo matchInfo = new ArenaMatchInfo();
    matchInfo.setAttackerId(playerId);
    matchInfo.setDefenderId(targetId);
    matchInfo.setMatchTime(new Date());

    return matchInfo;
}
```

### 战斗结算

```java
public void settleBattle(long battleId, boolean attackerWin) {
    // 1. 获取战斗信息
    ArenaBattle battle = battleDao.selectById(battleId);

    // 2. 计算分数变化
    int scoreChange = calculateScoreChange(battle, attackerWin);

    // 3. 更新攻击者
    PlayerArena attacker = arenaDao.selectById(battle.getAttackerId());
    if (attackerWin) {
        attacker.setScore(attacker.getScore() + scoreChange);
        attacker.setWinCount(attacker.getWinCount() + 1);
    } else {
        attacker.setScore(Math.max(0, attacker.getScore() - scoreChange / 2));
        attacker.setLoseCount(attacker.getLoseCount() + 1);
    }
    arenaDao.updateById(attacker);

    // 4. 更新防守者
    PlayerArena defender = arenaDao.selectById(battle.getDefenderId());
    if (!attackerWin) {
        defender.setScore(defender.getScore() + scoreChange / 2);
    } else {
        defender.setScore(Math.max(0, defender.getScore() - scoreChange));
    }
    arenaDao.updateById(defender);

    // 5. 保存战报
    saveBattleReport(battle, attackerWin, scoreChange);

    // 6. 更新排名
    updateRank(attacker, defender);
}
```

### 爬塔战斗

```java
public boolean towerFight(long playerId, int chapterId, int floor) {
    // 1. 获取爬塔信息
    PlayerTower tower = towerDao.selectByPlayerAndChapter(playerId, chapterId);
    if (tower == null) {
        tower = createNewTower(playerId, chapterId);
    }

    // 2. 检查层数
    if (floor != tower.getFloor() + 1) {
        throw new BusinessException(ErrorCode.INVALID_FLOOR);
    }

    // 3. 获取关卡配置
    TowerFloorConfig config = towerFloorConfigDao.getByChapterAndFloor(chapterId, floor);

    // 4. 执行战斗
    boolean win = doTowerBattle(playerId, config);

    // 5. 更新层数
    if (win) {
        tower.setFloor(floor);
        if (floor > tower.getHighestFloor()) {
            tower.setHighestFloor(floor);
        }
        towerDao.updateById(tower);

        // 发放奖励
        giveFloorReward(playerId, config.getReward());
    }

    // 6. 推送通知
    pushTowerPosChg(playerId, chapterId, floor, win);

    return win;
}
```

```java
@Scheduled(cron = "0 0 0 ? * MON") // 每周一
public void seasonEnd() {
    // 发放段位奖励
    List<PlayerArena> rankList = arenaDao.selectOrderByScore();
    for (int i = 0; i < rankList.size(); i++) {
        PlayerArena arena = rankList.get(i);
        int rank = i + 1;
        List<ItemInfo> reward = getRankReward(rank);
        itemService.giveItems(arena.getPlayerId(), reward);
    }

    // 重置分数
    arenaDao.resetAllScore();
}
```
