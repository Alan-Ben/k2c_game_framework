## 核心逻辑

### 玩家登录初始化

```java
public void onPlayerLogin(long playerId) {
    // 1. 加载玩家基础信息
    PlayerBase playerBase = playerBaseDao.selectById(playerId);
    if (playerBase == null) {
        // 新玩家创建
        playerBase = createNewPlayer(playerId);
    }

    // 2. 更新登录信息
    playerBase.setLastLoginTime(new Date());
    playerBase.setLoginCount(playerBase.getLoginCount() + 1);
    playerBaseDao.updateById(playerBase);

    // 3. 发送玩家基础信息
    sendRetPlayerInfo(playerId, playerBase);

    // 4. 触发登录事件
    eventBus.publish(new PlayerLoginEvent(playerId));
}
```

```java
public void loadModuleData(long playerId, int moduleId) {
    switch (moduleId) {

private void loadAchieveData(long playerId) {
    // 查询成就数据
    List<PlayerAchieve> achieveList = achieveDao.selectByPlayerId(playerId);

    // 查询成就点数据
    List<PlayerAchievePoint> pointList = achievePointDao.selectByPlayerId(playerId);

    // 发送初始化响应
    GS2GC_002_050_RetAchieveInit response = new GS2GC_002_050_RetAchieveInit();
    response.setAchieveList(convertAchieveList(achieveList));
    response.setAchievePointList(convertPointList(pointList));

    sendToClient(playerId, response);
}
```

### 数据缓存策略

```java
@Component
public class InitCacheManager {

    @Autowired
    private RedisTemplate<String, Object> redisTemplate;

    private static final int CACHE_EXPIRE = 300; // 5分钟

    // 缓存玩家初始化数据
    public void cachePlayerData(long playerId, int moduleId, Object data) {
        String key = buildCacheKey(playerId, moduleId);
        redisTemplate.opsForValue().set(key, data, CACHE_EXPIRE, TimeUnit.SECONDS);
    }

    // 获取缓存的初始化数据
    public Object getCachedData(long playerId, int moduleId) {
        String key = buildCacheKey(playerId, moduleId);
        return redisTemplate.opsForValue().get(key);
    }

    // 清除玩家缓存
    public void clearPlayerCache(long playerId) {
        String pattern = "init:" + playerId + ":*";
        Set<String> keys = redisTemplate.keys(pattern);
        if (keys != null && !keys.isEmpty()) {
            redisTemplate.delete(keys);
        }
    }

    private String buildCacheKey(long playerId, int moduleId) {
        return "init:" + playerId + ":" + moduleId;
    }
}
```

## 数据推送

### 登录后数据推送

```java
public void pushLoginData(long playerId) {
    // 推送离线期间产生的数据
    pushOfflineMails(playerId);
    pushOfflineRewards(playerId);
    pushOfflineEvents(playerId);
}

private void pushOfflineMails(long playerId) {
    // 查询离线期间的新邮件
    List<PlayerMail> newMails = mailDao.selectUnreadByPlayerId(playerId);

    for (PlayerMail mail : newMails) {
        GS2GC_009_051_OnMailAdded notification = new GS2GC_009_051_OnMailAdded();
        notification.setMailInfo(convertMailInfo(mail));
        sendToClient(playerId, notification);
    }
}
```

## 性能优化

### 1. 数据预加载

```java
public void preloadPlayerData(long playerId) {
    // 异步预加载常用数据
    CompletableFuture.allOf(
        CompletableFuture.runAsync(() -> loadCurrencyData(playerId)),
        CompletableFuture.runAsync(() -> loadBagData(playerId)),
        CompletableFuture.runAsync(() -> loadHeroData(playerId))
    );
}
```

### 2. 增量同步

```java
public void syncIncrementalData(long playerId, long lastSyncTime) {
    // 只同步上次同步后的变化数据
    List<DataChange> changes = dataChangeDao.selectByPlayerIdAndTime(playerId, lastSyncTime);

    for (DataChange change : changes) {
        pushDataChange(playerId, change);
    }
}
```

## 注意事项

1. 初始化请求需要验证玩家登录状态
2. 大数据量模块需要分页加载
3. 使用缓存减少数据库压力
4. 注意处理玩家重复登录的情况
5. 初始化失败需要有重试机制
