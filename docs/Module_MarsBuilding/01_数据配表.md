# MarsBuildingOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p039
**模块名称**: MarsBuildingOp (火星建筑操作)
**主要功能**: 提供火星基地建筑建造、升级、科技研究等功能

## 配置文件

### 关联配置表

| 配置表名称 | 用途 |
|-----------|------|
| MarsBuildingConfig | 火星建筑配置 |
| MarsTechnologyConfig | 火星科技配置 |
| MarsBuildingLevelConfig | 建筑等级配置 |
| MarsEnergyConfig | 能源配置 |

## 数据结构

### 建筑信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| buildingId | int | 建筑ID |
| buildingType | int | 建筑类型 |
| level | int | 当前等级 |
| state | int | 状态(空闲/升级中) |
| upgradeEndTime | long | 升级结束时间 |

### 科技信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| techId | int | 科技ID |
| level | int | 当前等级 |
| state | int | 状态(空闲/研究中) |
| researchEndTime | long | 研究结束时间 |

### 能源信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| energyType | int | 能源类型 |
| currentEnergy | long | 当前能源量 |
| maxEnergy | long | 最大能源量 |
| outputRate | long | 产出速率 |

## 建筑类型

| 类型ID | 类型名 | 说明 |
|--------|--------|------|
| 1 | HOME | 住宅建筑 |
| 2 | FOOD | 食物建筑 |
| 3 | POWER | 能源建筑 |
| 4 | RESEARCH | 科研建筑 |
| 5 | DEFENSE | 防御建筑 |
