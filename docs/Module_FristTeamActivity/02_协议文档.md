**功能**: 测试游戏主体逻辑

| 字段名 | 类型 | 说明 |
|--------|------|------|
| instanceId | long | 活动实例ID |
| param1 | int | 测试参数1 |

**示例代码**:
```csharp
// 客户端发送
var req = new GC2GS_003_001_ReqGameLogicTest();
req.setInstanceId(activityInstanceId);
req.setParam1(testValue);
// 发送协议
```
