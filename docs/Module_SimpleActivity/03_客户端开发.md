# SimpleActivityOp 模块 - 客户端开发文档

## 客户端组件

本模块功能集成在 CommonActivity 组件中。

### 相关组件

| 组件名 | 说明 |
|--------|------|
| SevenDayGoalsComponent | 七日目标组件 |
| RechargeRebateInfo | 充值返利信息 |

## 主要功能

### 收益目标

- 显示收益目标进度
- 领取目标奖励
- 领取荣誉奖励

### 七日目标

- 显示每日任务列表
- 追踪任务进度
- 领取任务奖励
- 领取阶段奖励

### 充值返利

- 显示充值返利信息
- 查看返利比例
- 领取返利奖励
