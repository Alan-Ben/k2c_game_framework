# 建筑模块数据配表文档

## 配表说明

建筑模块相关的配置数据主要存储在以下配表中:

---

## 一、建筑基础配表

### BuildingRefObj - 建筑静态配置
**文件**: `building_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 建筑配置ID |
| name | string | 建筑名称 |
| type | int | 建筑类型（1:农田 2:经营建筑 3:住宅） |
| max_level | long | 最大等级 |
| build_cost | object | 建造消耗 |
| unlock_condition | object | 解锁条件 |

---

### BuildingLevelRefObj - 建筑等级配置
**文件**: `building_level_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| building_id | long | 建筑配置ID |
| level | long | 等级 |
| upgrade_cost | object | 升级消耗 |
| upgrade_time | long | 升级时间（秒） |
| output | object | 产出配置 |
| attr_add | object | 属性加成 |

---

## 五、建筑功能枚举

### EBuildingFuncEnum
**文件**: `ClientProtocol/Common/BuildingEnum/EBuildingFuncEnum.cs`

| 枚举值 | 说明 |
|--------|------|
| None | 无功能 |
| Farm | 农田 |
| Business | 经营建筑 |

---

## 六、配表加载方式

```csharp
// 获取建筑静态配置
BuildingRefObj buildingRef = GRefdataCoreMgr.instance.buildingRefCore.getRef(buildingId);

// 获取建筑等级配置
BuildingLevelRefObj levelRef = GRefdataCoreMgr.instance.buildingLevelRefCore.getRef(buildingId, level);

// 获取农田配置
FarmRefObj farmRef = GRefdataCoreMgr.instance.farmRefCore.getRef(farmId);

// 获取经营建筑配置
BusinessRefObj businessRef = GRefdataCoreMgr.instance.businessRefCore.getRef(businessId);
```
