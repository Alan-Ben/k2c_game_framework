# 博物馆系统 - 协议文档

## 协议编号

模块编号：p035 (MuseumOp)

## 客户端请求协议 (GC2GS)

### GC2GS_035_001_ReqMuseumItemUpgrade

**说明**：请求升级藏品

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemId | int | 藏品ID |

**返回**：GS2GC_035_001_RetMuseumItemUpgrade

---

### GC2GS_035_002_ReqMuseumItemActive

**说明**：请求激活藏品

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemId | int | 藏品ID |

**返回**：GS2GC_035_002_RetMuseumItemActive

---

## 服务端响应协议 (GS2GC)

### GS2GC_035_050_OnMuseumItemAdd

**说明**：通知藏品添加

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemInfo | MuseumItemInfo | 藏品信息 |

---

### GS2GC_035_051_OnMuseumItemChg

**说明**：通知藏品变化

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemId | int | 藏品ID |
| level | int | 等级 |
| isActive | bool | 是否激活 |

---

## 数据结构

### MuseumItemInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemId | int | 藏品ID |
| level | int | 等级 |
| isActive | bool | 是否激活 |
| unlockTime | long | 解锁时间 |
