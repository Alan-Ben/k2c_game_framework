# 玩家称号服务端开发文档

## 一、模块架构

### 1.1 模块概述

玩家称号模块（PlayerTitle Module）负责管理玩家的称号数据，包括：
- 普通/限时称号管理
- 组合称号(前缀/后缀/底框)管理
- 称号穿戴状态管理
- 称号过期时间管理

### 1.2 组件类型

组件类型: `ENPPlayerCompType.TITLE_COMP`

---

## 二、核心数据结构

### 2.1 称号组件 (PlayerTitleComponent)

**路径**: `NPUSServer/NPUSUserMgr/UserComp/TitleComp/PlayerTitleComponent.java`

继承自 `_AExpiredItemComponent`，支持过期物品管理：

```java
public class PlayerTitleComponent extends _AExpiredItemComponent<RefPlayerTitle, PlayerTitleInfo>
```

### 2.2 称号信息 (PlayerTitleInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| refId | long | 称号配置ID |
| expireTimeS | int | 过期时间戳 |
| viewed | boolean | 是否已查看 |
| lastGainTs | int | 上次获取时间 |
| gainCount | int | 获取次数 |

## 三、过期物品处理

### 3.1 继承过期组件

称号组件继承自 `_AExpiredItemComponent`，自动处理过期逻辑：

```java
@Override
protected PlayerTitleInfo _createExpiredItem(RefPlayerTitle _ref, int _expiredTimeS)
{
    PlayerTitleBO bo = new PlayerTitleBO();
    bo.setTitleId(getBM(), _ref.id);
    bo.setCid(getBM(), getUserData().getCid());
    bo.setExpireTimeS(getBM(), _expiredTimeS);
    bo.setViewed(getBM(), false);
    bo.setLastGainTs(getBM(), CommonFunc.getNowTimeSec());
    bo.setGainCount(getBM(), 1);
    bo.insert(getBM());

    return new PlayerTitleInfo(getUserData(), _ref, bo);
}
```

### 3.2 过期回调

| 回调方法 | 说明 |
|----------|------|
| onExpiredItemAdd | 称号添加时回调 |
| onExpiredItemChg | 称号变化时回调 |
| onExpiredItemDel | 称号删除时回调 |

## 四、物品接口实现

### 4.1 物品类型

称号实现 `_IUserItemBasicDealer` 接口：

```java
@Override
public ENPItemType getItemType()
{
    return ENPItemType.TITLE;
}
```

### 4.2 物品操作

| 方法名 | 说明 |
|--------|------|
| getItemCount | 获取称号数量(有效为1) |
| hasItem | 检查是否拥有称号 |
| initGainItem | 初始化时获得称号 |
| gainItem | 获得称号 |
| spendItem | 消耗称号(不支持) |

## 六、协议构造

### 6.1 构造数据协议

```java
public void makeProtocol(ArrayList<PlayerInfo_Title> _list)
{
    getUserData().lockUser();
    try
    {
        for (PlayerTitleInfo info : getItemList())
        {
            _list.add(info.makeProto());
        }
    }
    finally
    {
        getUserData().unlockUser();
    }
}
```

### 6.2 获取有效称号

```java
public PlayerTitleInfo getEnableTitle(long _titleId)
{
    getUserData().lockUser();
    try
    {
        PlayerTitleInfo info = _lookupItem(_titleId);
        return info.enable() ? info : null;
    }
    finally
    {
        getUserData().unlockUser();
    }
}
```
