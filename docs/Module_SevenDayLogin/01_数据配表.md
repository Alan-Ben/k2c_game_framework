# 七日登录系统 - 数据配表

## 概述

七日登录系统 (SevenDayLogin) 是游戏中的签到奖励玩法，玩家连续登录可获得丰厚奖励。

## 配表文件

### 1. 七日登录配置 (SevenDayLogin)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| day | int | 天数(1-7) |
| reward_list | array | 奖励列表 |
| is_special | bool | 是否特殊奖励 |

### 2. 七日目标配置 (SevenDayGoals)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| goal_id | int | 目标ID |
| day | int | 所属天数 |
| goal_type | int | 目标类型 |
| target_value | long | 目标值 |
| reward_list | array | 奖励列表 |

### 3. 每日签到配置 (DailyCheck)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| check_id | int | 签到ID |
| check_type | int | 签到类型 |
| reward_list | array | 奖励列表 |
| vip_double | bool | VIP双倍 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/SevenDayLogin/`
- 服务端配置：`game_server/Config/seven_day_login/`
