# 通用操作 - 协议文档

## 协议编号

模块编号：p007 (CommOp)

## 客户端请求协议 (GC2GS)

### 招募相关

#### GC2GS_007_028_ReqRecruit

**说明**：请求招募

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| recruitId | int | 招募ID |
| count | int | 招募次数 |

**返回**：GS2GC_007_028_RetRecruit

## 服务端响应协议 (GS2GC)

| recruitId | int | 招募ID |

---

### GachaResult
