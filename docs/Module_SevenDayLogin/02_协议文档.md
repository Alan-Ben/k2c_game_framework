# 七日登录系统 - 协议文档

## 说明

七日登录系统主要通过 InitOp (p002) 和相关协议进行通信。

## 相关协议

### 初始化协议

#### GC2GS_002_026_ReqPlayerDailyCheckInfo

**说明**：请求每日签到信息

**返回**：GS2GC_002_026_RetDailyCheckInfo

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| todayChecked | bool | 今日是否已签到 |
| totalCheckDays | int | 累计签到天数 |
| checkRewardList | array | 签到奖励列表 |

---

### 签到操作

#### GC2GS_021_XXX_ReqDailyCheck

**说明**：请求每日签到

**请求参数**：无

**返回**：GS2GC_021_XXX_RetDailyCheck

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rewardList | array | 奖励列表 |
| vipDouble | bool | 是否VIP双倍 |

---

### 七日登录

#### GC2GS_002_XXX_ReqSevenDayLoginInfo

**说明**：请求七日登录信息

**返回**：GS2GC_002_XXX_RetSevenDayLoginInfo

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| loginDay | int | 登录天数 |
| rewardTakenList | array | 已领取奖励列表 |
| goalProgressList | array | 目标进度列表 |

---

#### GC2GS_021_XXX_ReqTakeSevenDayReward

**说明**：请求领取七日登录奖励

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| day | int | 天数 |

**返回**：GS2GC_021_XXX_RetTakeSevenDayReward

---

## 数据结构

### DailyCheckInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| todayChecked | bool | 今日是否签到 |
| totalCheckDays | int | 累计签到天数 |
| checkRewardTaken | array | 已领取签到奖励 |

### SevenDayLoginInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| loginDay | int | 当前登录天数 |
| rewardTakenList | array<int> | 已领取奖励天数列表 |
| goalProgressList | array | 目标进度列表 |

### SevenDayGoalProgress

| 字段名 | 类型 | 说明 |
|-------|------|------|
| goalId | int | 目标ID |
| progress | long | 进度 |
| rewardTaken | bool | 是否已领取奖励 |
