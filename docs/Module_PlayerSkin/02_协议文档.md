# 玩家皮肤系统 - 协议文档

## 协议编号

模块编号：p018 (PlayerSkinOp)

## 客户端请求协议 (GC2GS)

### GC2GS_018_001_ReqSetCommTitle

**说明**：请求设置普通称号

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| titleId | int | 称号ID |

**返回**：GS2GC_018_001_RetSetCommTitle

---

### GC2GS_018_002_ReqSetComboTitle

**说明**：请求设置组合称号

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| preTitleId | int | 前缀称号ID |
| sfxTitleId | int | 特效称号ID |
| bgTitleId | int | 背景称号ID |

**返回**：GS2GC_018_002_RetSetComboTitle

---

## 数据结构

### PlayerSkinInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| skinId | int | 皮肤ID |
| skinLevel | int | 皮肤等级 |
| unlockTime | long | 解锁时间 |

### TitleInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| titleId | int | 称号ID |
| expireTime | long | 过期时间 |
| isUsing | bool | 是否使用中 |

### ComboTitleInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| preTitleId | int | 前缀称号ID |
| sfxTitleId | int | 特效称号ID |
| bgTitleId | int | 背景称号ID |
