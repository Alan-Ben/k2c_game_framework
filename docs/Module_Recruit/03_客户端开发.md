## 数据管理

### RecruitComponent

```csharp
public class RecruitComponent : _ANPBasicPlayerComponent
{
    // 招募商店列表
    private Dictionary<int, RecruitShopInfo> _m_shopDic;

    // 招募记录
    private List<RecruitRecordInfo> _m_recordList;

    /// <summary>
    /// 请求招募
    /// </summary>
    public void reqRecruit(int recruitId, int count, Action<List<RecruitResult>> callback)
    {
        NPGSClientListener.sendRequest(
            NPGSWriter_007_CommOp.make_028_ReqRecruit(recruitId, count),
            new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_007_028_RetRecruit>((msg) =>
            {
                callback?.Invoke(msg.getResultList());
            }));
    }
}
```

## UI 窗口

### 招募界面

```csharp
public class RecruitWindow : BaseWindow
{
    private int _currentRecruitId;

    // 单抽
    public void onClickSingleRecruit()
    {
        RecruitComponent.instance.reqRecruit(_currentRecruitId, 1, (resultList) =>
        {
            showRecruitResult(resultList);
        });
    }

    // 十连
    public void onClickTenRecruit()
    {
        RecruitComponent.instance.reqRecruit(_currentRecruitId, 10, (resultList) =>
        {
            showRecruitResult(resultList);
        });
    }

    // 显示招募结果
    private void showRecruitResult(List<RecruitResult> resultList)
    {
        PlayRecruitAnimation(resultList, () =>
        {
            UIManager.openWindow<RecruitResultWindow>(resultList);
        });
    }
}
```
