# 火星建筑模块完整说明

## 一、模块概述

### 1.1 业务背景

火星建筑模块是 K2C 游戏火星玩法核心模块之一，负责管理玩家火星基地的建筑系统。玩家可以在火星上建造、升级各类功能性建筑，发展科技研究，管理能源供应，形成完整的火星殖民地生态系统。

### 1.2 目标用户

- **所有解锁火星玩法的玩家**：等级达到要求后解锁火星建筑功能
- **策略型玩家**：通过合理规划建筑布局和升级顺序获得优势
- **长期养成玩家**：通过持续升级建筑和科技获得长期收益

### 1.3 核心价值

1. **基地建设**：提供完整的火星基地建设体验
2. **资源生产**：通过建筑产出各类资源和能源
3. **科技发展**：科技研究系统增强整体实力
4. **能源管理**：供电分配策略增加游戏深度

## 三、业务流程详解

### 3.1 建筑创建流程

```mermaid
flowchart TD
    A[玩家选择建造建筑] --> B{检查建筑槽位}
    B -->|无空闲槽位| C[提示槽位不足]
    B -->|有空闲槽位| D{检查资源是否充足}
    D -->|资源不足| E[提示资源不足]
    D -->|资源充足| F{检查前置条件}
    F -->|条件不满足| G[提示前置条件未达成]
    F -->|条件满足| H[扣除建造资源]
    H --> I[开始建造计时]
    I --> J[推送建筑状态变更]
    J --> K{等待建造完成}
    K -->|时间到| L[建筑建造完成]
    K -->|玩家加速| M[使用加速道具]
    M --> L
    L --> N[推送建筑完成通知]
```

**详细步骤说明**：

1. **条件检查**
   - 验证是否有空闲建筑槽位
   - 验证玩家等级是否满足要求
   - 验证前置建筑是否已建造

2. **资源扣除**
   - 扣除建造所需的各类资源
   - 记录资源消耗日志

3. **建造过程**
   - 开始建造计时
   - 推送建造状态给客户端

4. **完成处理**
   - 建筑进入可用状态
   - 如有首建奖励则发放

### 3.2 建筑升级流程

```mermaid
flowchart TD
    A[玩家选择升级建筑] --> B{检查建筑状态}
    B -->|正在升级| C[提示建筑升级中]
    B -->|空闲| D{检查等级上限}
    D -->|已达上限| E[提示已达最高等级]
    D -->|未达上限| F{检查升级资源}
    F -->|资源不足| G[提示资源不足]
    F -->|资源充足| H[扣除升级资源]
    H --> I[开始升级计时]
    I --> J[推送升级状态]
    J --> K{等待升级完成}
    K -->|时间到| L[建筑升级完成]
    K -->|玩家加速| M[使用加速道具]
    M --> L
    L --> N[更新建筑等级]
    N --> O[检查功能解锁]
    O --> P[推送升级完成通知]
```

**详细步骤说明**：

1. **状态验证**
   - 建筑必须处于空闲状态
   - 未达到等级上限

2. **资源消耗**
   - 扣除升级所需资源
   - 资源类型和数量由配置表决定

3. **升级效果**
   - 建筑属性提升
   - 可能解锁新功能

### 3.3 科技研究流程

```mermaid
flowchart TD
    A[玩家选择研究科技] --> B{检查前置科技}
    B -->|前置未完成| C[提示需要先完成前置科技]
    B -->|前置已完成| D{检查研究队列}
    D -->|队列已满| E[提示研究队列已满]
    D -->|队列有空位| F{检查研究资源}
    F -->|资源不足| G[提示资源不足]
    F -->|资源充足| H[扣除研究资源]
    H --> I[开始研究计时]
    I --> J[推送研究状态]
    J --> K{等待研究完成}
    K -->|时间到| L[科技研究完成]
    K -->|玩家加速| M[使用加速道具]
    M --> L
    L --> N[应用科技效果]
    N --> O[推送研究完成通知]
```

**详细步骤说明**：

1. **前置检查**
   - 检查前置科技是否已研究
   - 检查科技是否已达到等级上限

2. **研究过程**
   - 扣除研究资源
   - 开始研究计时

3. **效果应用**
   - 科技效果全局生效
   - 更新玩家属性加成

### 3.4 能源管理流程

```mermaid
flowchart TD
    A[玩家请求能源操作] --> B{操作类型}
    B -->|获取能源| C[计算能源产出]
    C --> D[累加能源值]
    D --> E{检查能源上限}
    E -->|超过上限| F[设为上限值]
    E -->|未超过| G[保持计算值]
    F --> H[推送能源变化]
    G --> H
    B -->|分配供电| I{检查能源余量}
    I -->|余量不足| J[提示能源不足]
    I -->|余量充足| K[更新供电分配]
    K --> L[推送供电状态]
    B -->|断电操作| M[停止建筑供电]
    M --> N[更新建筑状态]
    N --> O[推送断电通知]
```

**详细步骤说明**：

1. **能源产出**
   - 发电建筑按配置产出能源
   - 能源有存储上限

2. **能源分配**
   - 为建筑分配供电
   - 能源消耗建筑需要供电才能运作

3. **断电效果**
   - 断电建筑停止产出
   - 断电建筑无法进行升级操作

## 四、关键规则

### 4.1 建筑规则

1. **建造限制**
   - 建筑槽位有上限，可通过升级基地扩展
   - 不同建筑有不同的解锁条件

2. **升级规则**
   - 建筑等级上限由建筑类型决定
   - 升级时间和消耗随等级递增

3. **建筑类型**
   - 住宅建筑：增加人口上限
   - 食物建筑：产出食物资源
   - 能源建筑：产出能源
   - 科研建筑：提供科技研究加成
   - 防御建筑：提供防御能力

### 4.2 科技规则

1. **研究规则**
   - 科技有前置依赖关系
   - 同一时间只能研究有限数量的科技

2. **科技效果**
   - 科技效果为永久加成
   - 科技等级越高效果越强

### 4.3 能源规则

1. **能源产出**
   - 发电建筑按时间产出能源
   - 能源存储有上限

2. **能源消耗**
   - 部分建筑需要消耗能源才能运作
   - 能源不足时建筑停止运作
