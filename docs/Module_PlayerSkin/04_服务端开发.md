## 核心逻辑

### 解锁皮肤

```java
public void unlockSkin(long playerId, int skinId) {
    // 1. 检查皮肤配置
    PlayerSkinConfig config = skinConfigDao.getById(skinId);
    if (config == null) {
        throw new BusinessException(ErrorCode.SKIN_NOT_FOUND);
    }

    // 2. 检查是否已解锁
    PlayerSkin existingSkin = skinDao.selectByPlayerAndSkin(playerId, skinId);
    if (existingSkin != null) {
        throw new BusinessException(ErrorCode.SKIN_ALREADY_UNLOCKED);
    }

    // 3. 检查解锁条件
    if (!checkUnlockCondition(playerId, config.getUnlockCondition())) {
        throw new BusinessException(ErrorCode.UNLOCK_CONDITION_NOT_MET);
    }

    // 4. 扣除消耗
    if (config.getCostList() != null) {
        itemService.consumeItems(playerId, config.getCostList());
    }

    // 5. 解锁皮肤
    PlayerSkin skin = new PlayerSkin();
    skin.setPlayerId(playerId);
    skin.setSkinId(skinId);
    skin.setSkinLevel(1);
    skin.setUnlockTime(new Date());
    skinDao.insert(skin);

    // 6. 推送通知
    pushSkinUnlock(playerId, skinId);
}
```

### 升级皮肤

```java
public void upgradeSkin(long playerId, int skinId) {
    // 1. 获取皮肤信息
    PlayerSkin skin = skinDao.selectByPlayerAndSkin(playerId, skinId);
    if (skin == null) {
        throw new BusinessException(ErrorCode.SKIN_NOT_UNLOCKED);
    }

    // 2. 检查等级上限
    PlayerSkinConfig config = skinConfigDao.getById(skinId);
    if (skin.getSkinLevel() >= config.getMaxLevel()) {
        throw new BusinessException(ErrorCode.SKIN_MAX_LEVEL);
    }

    // 3. 扣除升级消耗
    List<ItemInfo> costList = calculateUpgradeCost(config, skin.getSkinLevel());
    itemService.consumeItems(playerId, costList);

    // 4. 升级
    skin.setSkinLevel(skin.getSkinLevel() + 1);
    skinDao.updateById(skin);

    // 5. 推送通知
    pushSkinUpgrade(playerId, skinId, skin.getSkinLevel());
}
```

### 设置称号

```java
public void setTitle(long playerId, int titleId) {
    // 1. 检查称号是否存在
    PlayerTitle title = titleDao.selectByPlayerAndTitle(playerId, titleId);
    if (title == null) {
        throw new BusinessException(ErrorCode.TITLE_NOT_UNLOCKED);
    }

    // 2. 检查是否过期
    if (title.getExpireTime() != null && title.getExpireTime().before(new Date())) {
        throw new BusinessException(ErrorCode.TITLE_EXPIRED);
    }

    // 3. 更新当前称号
    PlayerBase player = playerDao.selectById(playerId);
    player.setCurTitleId(titleId);
    playerDao.updateById(player);

    // 4. 推送通知
    pushTitleChg(playerId, titleId);
}
```

## 注意事项

1. 称号有效期需要定时检查清理
2. 皮肤升级消耗随等级递增
3. 组合称号需要分别解锁三部分
