# 背包模块数据配表文档

## 配表说明

背包模块相关的配置数据主要存储在以下配表中:

---

## 一、物品基础配表

### ItemRefObj - 物品配置
**文件**: `item_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 物品配置ID |
| name | string | 物品名称 |
| type | int | 物品类型 |
| quality | int | 品质 |
| max_stack | int | 最大堆叠数 |
| description | string | 物品描述 |
| icon | string | 图标资源路径 |

**物品类型枚举**:
| 类型ID | 说明 |
|--------|------|
| 1 | 消耗品 |
| 2 | 材料 |
| 3 | 礼包 |
| 4 | 碎片 |
| 5 | 任务物品 |

---

## 二、物品使用效果配表

### ItemUseEffectRefObj - 物品使用效果配置
**文件**: `item_use_effect_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 效果ID |
| item_id | long | 物品ID |
| effect_type | int | 效果类型 |
| effect_param | object | 效果参数 |
| use_count | int | 使用数量限制 |

**效果类型枚举**:
| 类型ID | 说明 |
|--------|------|
| 1 | 获得货币 |
| 2 | 获得物品 |
| 3 | 增加经验 |
| 4 | 抽奖 |
| 5 | 召唤英雄 |

---

## 三、礼包配表

### GiftPackRefObj - 礼包配置
**文件**: `gift_pack_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 礼包ID |
| name | string | 礼包名称 |
| reward_list | array | 奖励列表 |
| preview | bool | 是否显示预览 |

---

## 四、物品品质枚举

### EItemQuality
| 枚举值 | 说明 |
|--------|------|
| 1 | 普通（白） |
| 2 | 优秀（绿） |
| 3 | 精良（蓝） |
| 4 | 史诗（紫） |
| 5 | 传说（橙） |
| 6 | 神话（红） |

---

## 五、配表加载方式

```csharp
// 获取物品配置
ItemRefObj itemRef = GRefdataCoreMgr.instance.itemRefCore.getRef(itemId);

// 获取物品使用效果
ItemUseEffectRefObj effectRef = GRefdataCoreMgr.instance.itemUseEffectRefCore.getRef(effectId);

// 获取礼包配置
GiftPackRefObj giftRef = GRefdataCoreMgr.instance.giftPackRefCore.getRef(giftId);
```
