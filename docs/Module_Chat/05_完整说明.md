# ChatOp 模块 - 完整说明文档

## 模块概述

**模块编号**: p022
**模块名称**: ChatOp (聊天操作)
**主要功能**: 聊天模块业务背景、功能清单、业务流程、用户故事

## 一、模块概述

### 1.1 业务背景

聊天模块是 K2C 游戏的核心社交功能模块，负责管理游戏内所有玩家间的即时通讯功能。包括全区频道、单服频道、公会频道、私聊系统等多种聊天场景，是玩家互动交流的主要渠道。

### 1.2 目标用户

- **所有游戏玩家**：通过聊天进行社交互动、组队邀请、交易协商等
- **运营人员**：通过系统消息发布公告、活动通知
- **公会管理**：通过公会频道进行内部管理

### 1.3 核心价值

1. **社交连接**：为玩家提供实时沟通渠道，增强游戏社交体验
2. **信息传播**：支持频道广播，快速传达游戏信息
3. **私聊互动**：支持一对一私密对话，保护玩家隐私
4. **内容安全**：内置敏感词过滤，维护健康的游戏环境

## 三、业务流程详解

### 3.1 聊天登录流程

```mermaid
flowchart TD
    A[客户端请求聊天登录] --> B{验证玩家身份}
    B -->|验证失败| C[返回登录失败]
    B -->|验证成功| D[建立聊天连接]
    D --> E[加载玩家聊天数据]
    E --> F[加载黑名单列表]
    F --> G[加入默认频道]
    G --> H[返回登录成功]
    H --> I[推送离线消息]
```

**详细步骤说明**：

1. **身份验证**
   - 验证玩家Token有效性
   - 验证玩家账号状态

2. **连接建立**
   - 建立WebSocket连接
   - 注册消息监听器

3. **数据加载**
   - 加载玩家黑名单
   - 加载最近聊天记录

4. **频道加入**
   - 自动加入世界频道
   - 加入公会频道（如有公会）

### 3.2 发送房间消息流程

```mermaid
flowchart TD
    A[客户端发送房间消息] --> B{验证玩家在房间内}
    B -->|不在房间| C[返回未加入房间]
    B -->|在房间内| D{检查发言冷却}
    D -->|冷却中| E[返回发言冷却中]
    D -->|可发言| F{过滤敏感词}
    F --> G[构建消息数据]
    G --> H[保存消息记录]
    H --> I[广播消息到房间]
    I --> J[推送消息给房间成员]
```

**详细步骤说明**：

1. **权限验证**
   - 检查玩家是否已加入该房间
   - 检查玩家是否被禁言

2. **频率控制**
   - 检查发言冷却时间
   - 防止刷屏行为

3. **内容处理**
   - 过滤敏感词
   - 处理特殊字符

4. **消息广播**
   - 构建消息对象
   - 推送给房间内所有成员

### 3.3 发送私聊消息流程

```mermaid
flowchart TD
    A[客户端发送私聊消息] --> B{验证目标玩家存在}
    B -->|不存在| C[返回玩家不存在]
    B -->|存在| D{检查是否被屏蔽}
    D -->|被屏蔽| E[返回发送失败]
    D -->|未屏蔽| F{检查双方状态}
    F -->|对方禁言| G[返回对方无法接收]
    F -->|正常| H{过滤敏感词}
    H --> I[构建私聊消息]
    I --> J[保存消息记录]
    J --> K{对方在线}
    K -->|在线| L[推送给对方]
    K -->|离线| M[存储为离线消息]
```

**详细步骤说明**：

1. **目标验证**
   - 验证目标玩家ID有效性
   - 验证目标玩家账号状态

2. **屏蔽检查**
   - 检查目标是否屏蔽发送者
   - 检查发送者是否在黑名单中

3. **消息处理**
   - 过滤敏感词
   - 构建消息对象

4. **消息投递**
   - 在线则直接推送
   - 离线则存储待推送

### 3.4 加入/退出频道流程

```mermaid
flowchart TD
    A[请求加入频道] --> B{验证频道存在}
    B -->|不存在| C[返回频道不存在]
    B -->|存在| D{检查加入权限}
    D -->|无权限| E[返回无权限]
    D -->|有权限| F[添加到频道成员列表]
    F --> G[推送加入通知]
    G --> H[返回加入成功]

    I[请求退出频道] --> J{验证在频道内}
    J -->|不在| K[返回未加入]
    J -->|在频道内| L[从成员列表移除]
    L --> M[推送退出通知]
    M --> N[返回退出成功]
```

## 四、关键规则

### 4.1 频道类型规则

> 源码: `ClientProtocol/NPEnum/ENPChatRoomType.cs`

| 频道类型 | 类型ID | 说明 | 冷却时间 | 解锁条件 |
|---------|--------|------|----------|----------|
| 全区频道 | 1 | TOTAL_AREA - 跨服聊天 | 配表配置 | 配表条件 |
| 单服频道 | 2 | US_SERVER - 默认聊天室 | 配表配置 | 默认解锁 |
| 联盟频道 | 3 | GUILD - 联盟内部聊天 | 配表配置 | 加入联盟 |
| 活动组队 | 4 | ACTIVITY_TEAM - 临时队伍 | 配表配置 | 加入活动队伍 |

### 4.2 发言规则

1. **冷却时间**
   - 世界频道：5秒冷却
   - 公会频道：3秒冷却
   - 私聊频道：无冷却

2. **消息长度**
   - 最大字符数：200字符
   - 超出部分自动截断

3. **敏感词处理**
   - 敏感词替换为***
   - 严重违规可能触发禁言

### 4.3 黑名单规则

1. **屏蔽效果**：被屏蔽玩家发送的消息不会显示
2. **数量限制**：最多屏蔽100名玩家
3. **双向生效**：A屏蔽B后，B发给A的消息会被拦截

### 11.1 客户端调用接口

| 接口名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| SendRoomMessage | roomId, msgType, content | void | 发送房间消息 |
| SendPrivateMessage | targetId, msgType, content | void | 发送私聊消息 |
| JoinRoom | roomId, roomType | void | 加入房间 |

| RemoveBlackList | targetId | void | 移除黑名单 |
