# 背包模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### PlayerBagComponent
**路径**: `GameComponent/NPBag/PlayerBagComponent.cs`

**功能**: 背包管理类，管理玩家所有物品数据

**继承关系**:
```
PlayerBagComponent : _ANPBasicPlayerComponent
```

**协议模块**: p006_BagItemOp

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| itemList | List<BagItem> | 物品列表 |

**主要方法**:

| 方法名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| getItem | long itemId | BagItem | 根据ID获取物品 |
| getItemCount | long refId | int | 获取指定配置ID的物品数量 |
| setBagViewed | - | void | 设置背包已查看 |
| setItemIsViewed | long itemId | void | 设置物品已查看 |
| reqItemList | - | void | 请求物品列表 |

---

### 1.2 物品信息类

#### BagItem
**路径**: `GameComponent/NPBag/BagItem.cs`

**功能**: 单个物品的数据信息

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| itemId | long | 物品唯一ID |
| refId | long | 物品配置ID |
| count | long | 物品数量 |
| clickTimeS | int | 点击时间戳 |
| isNew | bool | 是否为新物品 |

---

## 二、协议接口

### 2.1 请求协议

| 协议名 | 说明 |
|--------|------|
| GC2GS_006_001_ReqItemList | 请求物品列表 |
| GC2GS_006_002_ReqUseItem | 请求使用物品 |
| GC2GS_006_003_ReqRefreshQuitBagTime | 刷新退出背包时间 |
| GC2GS_006_004_ReqClickBagTime | 点击物品时间同步 |

### 2.2 响应协议

| 协议名 | 说明 |
|--------|------|
| GS2GC_006_001_RetItemList | 物品列表返回 |
| GS2GC_006_002_RetUseItem | 使用物品结果 |
| GS2GC_006_003_OnItemAdd | 物品新增推送 |
| GS2GC_006_004_OnItemRemove | 物品移除推送 |
| GS2GC_006_005_OnItemUpdate | 物品更新推送 |

```csharp
// 获取物品数量
int count = bagComp.getItemCount(refId);

// 获取指定物品
BagItem item = bagComp.getItem(itemId);

// 遍历所有物品
foreach (var item in bagComp.itemList)
{
    // 处理物品
}
```
