# 商店模块 - 数据配表

## 模块概述

**模块编号**: p030
**模块名称**: ShopOp (商店操作)
**主要功能**: 提供商品购买、商店刷新、礼包系统、限时礼包推送等功能

---

## 4. 商品折扣配置 (RefShopItemDiscount)

**配表名**: `shop_item_discount`

### 完整字段列表

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|

| discount | int | 是 | 10000 | 折扣比例（万分比，10000=100%） |
| ui_res_id | int | 否 | 0 | UI资源ID |

### 折扣计算公式

```
实际价格 = 原价 × discount / 10000
```

**示例计算**:

| discount值 | 折扣 | 计算示例 |
|------------|------|----------|
| 10000 | 100%（无折扣） | 500 × 10000/10000 = 500 |
| 8000 | 80%（8折） | 500 × 8000/10000 = 400 |
| 5000 | 50%（5折） | 500 × 5000/10000 = 250 |
| 3000 | 30%（3折） | 500 × 3000/10000 = 150 |

### 代码示例

```java
// 获取折扣配置
RefShopItemDiscount discountRef = RefShopItemDiscount.getMgr().get(discountId);
if (discountRef != null) {
    // 应用折扣
    long actualPrice = originalPrice * discountRef.discount / 10000;
}
```

### 限时礼包触发流程

```mermaid
sequenceDiagram
    participant Game as 游戏事件
    participant Trigger as 触发检测
    participant Gift as 礼包服务
    participant Player as 玩家数据
    participant Push as 推送服务

    Game->>Trigger: 触发事件(升级/充值等)
    Trigger->>Gift: 检查触发条件
    Gift->>Gift: 查找匹配配置
    Gift->>Player: 检查是否已触发
    alt 未触发过
        Gift->>Player: 创建限时礼包实例
        Gift->>Push: 推送礼包通知
        Push-->>Game: 显示礼包弹窗
    else 已触发过
        Gift-->>Trigger: 无操作
    end
```
