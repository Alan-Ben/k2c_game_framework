# 子女系统 - 数据配表

## 概述

子女系统 (ChildOp, p014) 是游戏中的核心养成玩法，玩家可以培养子女，成年后可与其他玩家子女联姻。

## 配表文件

### 1. 子女配置 (Child)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| child_id | int | 子女配置ID |
| child_name | string | 子女名称 |
| gender | int | 性别(1男2女) |
| talent_init | int | 初始天赋 |
| max_level | int | 最大等级 |

### 2. 子女培养配置 (ChildTrain)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| train_id | int | 培养ID |
| cost_list | array | 消耗列表 |
| exp_add | int | 经验增加 |
| talent_add | int | 天赋增加 |

### 3. 座位配置 (Seat)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| seat_id | int | 座位ID |
| seat_type | int | 座位类型 |
| unlock_condition | json | 解锁条件 |
| energy_max | int | 最大能量 |

### 4. 成年联姻配置 (Marriage)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| marriage_id | int | 联姻ID |
| require_talent | int | 需要天赋值 |
| reward_list | array | 联姻奖励 |

## 子女状态枚举

```csharp
public enum EChildState
{
    CHILD = 1,      // 幼年期
    ADULT = 2,      // 成年期
    MARRIED = 3     // 已婚
}
```
