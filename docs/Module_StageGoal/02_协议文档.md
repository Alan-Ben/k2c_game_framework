## 二、服务端响应协议 (GS2GC)

### 2.1 初始化响应

#### GS2GC_002_062_RetStageGoalInit - 返回阶段目标初始化数据
**功能说明**: 返回玩家阶段目标数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| bigStepList | List&lt;StageGoal_BigStepInfo&gt; | 大阶段列表 |
| taskList | List&lt;StageGoal_TaskInfo&gt; | 任务列表 |
| firstReachRewardList | List&lt;Long&gt; | 已领取首达奖励的大阶段ID列表 |

---

### 2.2 信息查询响应

#### GS2GC_007_016_RetStageGoalFirstReachDetailInfo - 返回首达详情

| 字段名 | 类型 | 说明 |
|--------|------|------|
| bigStepId | long | 大阶段ID |
| detailList | List&lt;StageGoal_BigStepFirstReachInfo&gt; | 首达详情列表 |

#### GS2GC_007_017_RetStageGoalFirstReachBaseInfo - 返回首达基础信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| baseList | List&lt;StageGoal_BigStepFirstReachInfo&gt; | 基础信息列表 |
| topPlayerInfo | StageGoal_TopPlayerInfo | TOP1玩家信息 |

---

## 三、协议调用流程

### 3.1 阶段目标初始化流程
```
客户端                          服务端
   |                               |
   |--- ReqStageGoalInit --------->|
   |                               | (查询玩家阶段目标数据)
   |<-- RetStageGoalInit ----------|
   |                               |
```

### 3.2 领取首达奖励流程
```
客户端                          服务端
   |                               |
   |--- ReqStageGoalFirstReachBaseInfo -->|
   |<-- RetStageGoalFirstReachBaseInfo ---|
   |                               |
   |--- ReqDrawStageGoalFirstReachReward -->|
   |                               | (验证并发放奖励)
   |<-- RetDrawStageGoalFirstReachReward --|
   |                               |
```

## 四、错误码

### StageGoalErr - 阶段目标系统错误

| 错误码 | 说明 |
|--------|------|
| STAGE_GOAL_NOT_UNLOCK | 阶段目标未解锁 |
| STAGE_GOAL_ALREADY_REWARD | 已领取奖励 |
| STAGE_GOAL_NOT_COMPLETE | 任务未完成 |
