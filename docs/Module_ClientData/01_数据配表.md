# 客户端数据 - 数据配表

## 概述

客户端数据模块 (ClientDataOp, p011) 用于存储和管理客户端本地数据，支持客户端与服务端的数据同步。

## 配表文件

### 1. 客户端数据类型配置 (ClientDataType)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| data_type | int | 数据类型ID |
| data_name | string | 数据名称 |
| max_size | int | 最大存储大小 |
| sync_type | int | 同步类型 |

### 2. 同步类型枚举

```csharp
public enum EClientDataSyncType
{
    MANUAL = 0,     // 手动同步
    LOGIN = 1,      // 登录同步
    LOGOUT = 2,     // 登出同步
    REALTIME = 3    // 实时同步
}
```

## 数据类型

| 类型ID | 类型名称 | 说明 |
|-------|---------|------|
| 1 | Settings | 客户端设置 |
| 2 | Tutorial | 引导进度 |
| 3 | RedDot | 红点状态 |
| 4 | UIState | UI状态 |
| 5 | Cache | 缓存数据 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ClientProtocol/Common/ClientData/`
- 服务端配置：`game_server/Config/client_data/`

## 注意事项

1. 客户端数据有大小限制
2. 敏感数据不应存储在客户端
3. 数据同步需要考虑版本兼容
