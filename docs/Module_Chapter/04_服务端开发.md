# 章节模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

章节模块（Chapter Module）负责管理游戏章节进度，包括：
- 章节进度管理
- 章节事件处理
- Boss战系统
- 章节激励系统
- 剧情奖励发放

### 1.2 模块编号

协议模块编号: `p016`

---

## 二、核心数据结构

### 2.1 章节事件信息 (Chapter_EventInfo)

**路径**: `ClientProtocol/Common/ChapterObj/Chapter_EventInfo.cs`

| 字段名 | 类型 | 说明 |

## 四、核心逻辑流程

### 4.1 章节前进流程

```
客户端                          服务端
   |                               |
   |--- ReqChapterForward -------->|
   |                               | 1. 验证章节是否解锁
   |                               | 2. 验证当前位置
   |                               | 3. 更新章节进度
   |                               | 4. 触发事件（如有）
   |<-- RetChapterForward ---------|
   |<-- OnChapterProgressChg -----| (推送进度变化)
   |                               |
```

### 4.2 Boss战流程

```
客户端                          服务端
   |                               |
   |--- ReqChapterFightBoss ------>|
   |                               | 1. 验证Boss是否可挑战
   |                               | 2. 验证战力要求
   |                               | 3. 执行战斗计算
   |                               | 4. 发放奖励（如胜利）
   |<-- RetChapterFightBoss -------|
   |<-- OnChapterBossDefeated ----| (推送Boss击败)
   |                               |
```

## 六、服务配置

protocolHandler.Register<GC2GS_016_001_ReqChapterForward>(OnChapterForward);

### 6.2 服务依赖

章节模块依赖以下服务：
- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
- 英雄服务 (HeroService)
- 战斗服务 (BattleService)
