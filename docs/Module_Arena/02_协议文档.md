## 数据结构

### ArenaBattleInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| battleId | long | 战斗ID |
| attackerId | long | 攻击者ID |
| defenderId | long | 防守者ID |
| attackerScore | int | 攻击者分数 |
| defenderScore | int | 防守者分数 |
| battleTime | long | 战斗时间 |

### ArenaInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rank | int | 排名 |
| score | int | 分数 |
| winCount | int | 胜利次数 |
| loseCount | int | 失败次数 |
| attackCount | int | 攻击次数 |

### TowerInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| chapterId | int | 章节ID |
| floor | int | 当前层数 |
| highestFloor | int | 最高层数 |
| starList | array | 星星列表 |
