# 英雄模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

英雄模块（Hero Module）负责管理玩家所有英雄（大臣）的数据和业务逻辑，包括：
- 英雄基础属性管理（等级、阶段、觉醒星级）
- 英雄皮肤系统
- 英雄技能系统（资质技能、经营技能、觉醒技能）
- 英雄光环系统
- 英雄套系系统
- 装备系统

### 1.2 模块编号

协议模块编号: `p013`

## 四、核心逻辑流程

### 4.1 英雄升级流程

```
客户端                          服务端
   |                               |
   |--- ReqHeroUpgrade ----------->|
   |                               | 1. 验证英雄是否存在
   |                               | 2. 验证资源是否足够
   |                               | 3. 扣除升级资源
   |                               | 4. 增加英雄经验/等级
   |                               | 5. 计算新属性
   |<-- RetHeroUpgrade ------------|
   |<-- OnHeroLevelChg ------------| (推送等级变化)
   |                               |
```

### 4.2 英雄穿戴装备流程

```
客户端                          服务端
   |                               |
   |--- ReqHeroWearEquip --------->|
   |                               | 1. 验证装备是否存在
   |                               | 2. 验证装备是否可穿戴
   |                               | 3. 卸下原装备（如有）
   |                               | 4. 穿戴新装备
   |                               | 5. 重新计算英雄属性
   |<-- RetHeroWearEquip ----------|
   |<-- OnEquipBaseChg ------------| (推送装备变化)
   |                               |
```

### 4.3 装备分解流程

```
客户端                          服务端
   |                               |
   |--- ReqEquipDisassemble ------>|
   |                               | 1. 验证装备是否可分解
   |                               | 2. 验证装备是否锁定
   |                               | 3. 移除装备数据
   |                               | 4. 计算分解奖励
   |                               | 5. 发放分解奖励
   |<-- RetEquipDisassemble -------|
   |<-- OnEquipRemove ------------| (推送装备移除)
   |                               |
```

## 六、服务配置

### 6.1 协议注册

英雄模块协议在服务端启动时注册：

```csharp
// 协议主序号
public const byte HERO_MODULE_ORDER = 13;

// 协议处理器注册
protocolHandler.Register<GC2GS_013_001_ReqHeroUpgrade>(OnHeroUpgrade);
protocolHandler.Register<GC2GS_013_004_ReqHeroStepUpgrade>(OnHeroStepUpgrade);
// ... 其他协议注册
```

### 6.2 服务依赖

英雄模块依赖以下服务：
- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
