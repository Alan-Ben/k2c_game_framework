## 数据结构

### TreasureHuntInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| stationList | array | 站点列表 |
| oreList | array | 矿石列表 |
| treasureList | array | 宝藏列表 |
| capturePower | int | 捕获力 |

### TreasureStationInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| stationId | int | 站点ID |
| state | int | 状态 |
| oreCount | int | 矿石数量 |

### TreasureOreInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| oreId | int | 矿石ID |
| count | int | 数量 |
| skillLevel | int | 技能等级 |
