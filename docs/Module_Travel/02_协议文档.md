# 游历系统 - 协议文档

## 协议编号

模块编号：p008 (TravelOp)

## 客户端请求协议 (GC2GS)

### GC2GS_008_001_ReqStartTravel

**说明**：请求开始游历

**请求参数**：无

**返回**：GS2GC_008_001_RetStartTravel

---

## 服务端响应协议 (GS2GC)

### GS2GC_008_001_RetStartTravel

**说明**：返回开始游历结果

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| result | int | 结果码 |
| travelInfo | Travel_Info | 游历信息 |

---

### GS2GC_008_050_OnEventAdd

**说明**：通知事件添加

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| eventInfo | Travel_Event | 事件信息 |

---

### GS2GC_008_051_OnEventDel

**说明**：通知事件删除

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| eventId | int | 事件ID |

---

### GS2GC_008_052_OnConsortChg

**说明**：通知妃子信息变化

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| consortInfo | Travel_Consort | 妃子信息 |

---

## 数据结构

### Travel_Event

| 字段名 | 类型 | 说明 |
|-------|------|------|
| eventId | int | 事件ID |
| eventType | int | 事件类型 |
| eventState | int | 事件状态 |
| triggerTime | long | 触发时间 |

### Travel_Consort

| 字段名 | 类型 | 说明 |
|-------|------|------|
| consortId | long | 妃子ID |
| like | int | 好感度 |

### Travel_EventResult

| 字段名 | 类型 | 说明 |
|-------|------|------|
| resultCode | int | 结果码 |
| rewardList | array | 奖励列表 |
| extInfo | object | 扩展信息 |
