# 章节模块数据配表文档

## 配表说明

章节模块相关的配置数据主要存储在以下配表中:

---

## 一、章节基础配表

### ChapterRefObj - 章节配置
**文件**: `chapter_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 章节配置ID |
| name | string | 章节名称 |
| chapter | int | 章节序号 |
| pre_chapter | long | 前置章节ID |
| unlock_condition | object | 解锁条件 |

---

## 二、章节事件配表

### ChapterEventRefObj - 章节事件配置
**文件**: `chapter_event_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 事件ID |
| chapter_id | long | 所属章节ID |
| type | EChapterEventType | 事件类型 |
| position | object | 位置信息 |
| trigger_condition | object | 触发条件 |
| reward | object | 奖励 |

**事件类型枚举 (EChapterEventType)**:
| 枚举值 | 说明 |
|--------|------|
| 1 | 战斗事件 |
| 2 | 选择事件 |
| 3 | 奖励事件 |
| 4 | 剧情事件 |
| 5 | 派遣事件 |

---

## 三、章节Boss配表

### ChapterBossRefObj - 章节Boss配置
**文件**: `chapter_boss_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | BossID |
| chapter_id | long | 所属章节ID |
| name | string | Boss名称 |
| power | long | 战力要求 |
| reward | object | 击败奖励 |

---

## 四、章节激励配表

### ChapterInspireRefObj - 章节激励配置
**文件**: `chapter_inspire_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 激励ID |
| type | EChapterInspireType | 激励类型 |
| cost | object | 消耗 |
| effect | object | 效果 |
| max_count | int | 最大次数 |

**激励类型枚举 (EChapterInspireType)**:
| 枚举值 | 说明 |
|--------|------|
| 1 | 攻击加成 |
| 2 | 防御加成 |
| 3 | 生命加成 |

---

## 五、配表加载方式

```csharp
// 获取章节配置
ChapterRefObj chapterRef = GRefdataCoreMgr.instance.chapterRefCore.getRef(chapterId);

// 获取章节事件配置
ChapterEventRefObj eventRef = GRefdataCoreMgr.instance.chapterEventRefCore.getRef(eventId);

// 获取章节Boss配置
ChapterBossRefObj bossRef = GRefdataCoreMgr.instance.chapterBossRefCore.getRef(bossId);
```
