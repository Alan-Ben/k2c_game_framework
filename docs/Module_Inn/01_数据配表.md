# 旅店系统 - 数据配表

## 概述

旅店系统 (InnOp, p034) 是游戏中的经营玩法，玩家可以经营旅店接待客人获得收益。

## 配表文件

### 1. 旅店配置 (Inn)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| inn_id | int | 旅店ID |
| inn_name | string | 旅店名称 |
| max_level | int | 最大等级 |
| max_station | int | 最大座位 |

### 2. 旅店座位配置 (InnStation)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| station_id | int | 座位ID |
| station_name | string | 座位名称 |
| unlock_level | int | 解锁等级 |
| guest_capacity | int | 客人容量 |

### 3. 旅店菜品配置 (InnDish)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dish_id | int | 菜品ID |
| dish_name | string | 菜品名称 |
| dish_quality | int | 菜品品质 |
| cook_time | int | 烹饪时间 |
| cost_list | array | 消耗列表 |

### 4. 旅店客人配置 (InnGuest)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| guest_id | int | 客人ID |
| guest_name | string | 客人名称 |
| guest_type | int | 客人类型 |
| favorite_dish | array | 喜爱菜品 |
| reward_list | array | 服务奖励 |

### 5. 旅店勋章配置 (InnMedal)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| medal_id | int | 勋章ID |
| medal_name | string | 勋章名称 |
| unlock_condition | json | 解锁条件 |
| buff_list | array | Buff列表 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Inn/`
- 服务端配置：`game_server/Config/inn/`
