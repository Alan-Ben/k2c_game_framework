# 伴侣系统完整说明

## 一、模块概述

### 1.1 业务背景

伴侣系统是 K2C 游戏的核心养成社交玩法，玩家可以与游戏中的伴侣角色建立亲密关系，通过培养亲密度、羁绊等级来解锁更多互动内容。该系统融合了养成、对话、皮肤收集等多种玩法元素。

### 1.2 目标用户

- **养成玩家**：享受培养伴侣亲密度的过程
- **收集玩家**：收集伴侣皮肤和CG
- **社交玩家**：体验伴侣AI对话互动

### 1.3 核心价值

1. **情感陪伴**：AI伴侣提供情感互动体验
2. **养成成长**：培养伴侣属性，解锁更多内容
3. **收集乐趣**：收集伴侣皮肤和CG
4. **属性加成**：伴侣提供玩家属性加成

## 三、业务流程详解

### 3.1 升级羁绊流程

```mermaid
flowchart TD
    A[请求升级羁绊] --> B{检查伴侣存在}
    B -->|不存在| C[返回伴侣不存在]
    B -->|存在| D{检查羁绊等级}
    D -->|已达上限| E[返回已达最高等级]
    D -->|未达上限| F{检查亲密度}
    F -->|不足| G[返回亲密度不足]
    F -->|充足| H[提升羁绊等级]
    H --> I[推送羁绊变化]
    I --> J[返回升级成功]
```

**详细步骤说明**：

1. **伴侣验证**
   - 验证伴侣存在且已解锁
   - 验证伴侣属于当前玩家

2. **等级检查**
   - 检查当前羁绊等级
   - 检查是否达到上限

3. **亲密度检查**
   - 检查亲密度是否满足升级要求
   - 不同等级需要不同亲密度

4. **升级处理**
   - 提升羁绊等级
   - 解锁新功能（如有）

### 3.2 解锁皮肤流程

```mermaid
flowchart TD
    A[请求解锁皮肤] --> B{检查伴侣存在}
    B -->|不存在| C[返回伴侣不存在]
    B -->|存在| D{检查皮肤配置}
    D -->|不存在| E[返回皮肤不存在]
    D -->|存在| F{检查皮肤归属}
    F -->|不属于| G[返回皮肤不属于该伴侣]
    F -->|属于| H{检查是否已解锁}
    H -->|已解锁| I[返回皮肤已解锁]
    H -->|未解锁| J{检查解锁条件}
    J -->|条件不满足| K[返回条件不满足]
    J -->|条件满足| L{检查消耗资源}
    L -->|资源不足| M[返回资源不足]
    L -->|资源充足| N[扣除消耗资源]
    N --> O[解锁皮肤]
    O --> P[推送皮肤添加]
```

### 3.3 AI聊天流程

```mermaid
flowchart TD
    A[请求AI聊天] --> B{检查伴侣存在}
    B -->|不存在| C[返回伴侣不存在]
    B -->|存在| D[记录玩家消息]
    D --> E[获取伴侣性格配置]
    E --> F[调用AI服务]
    F --> G[生成伴侣回复]
    G --> H[记录伴侣消息]
    H --> I[推送AI聊天消息]
    I --> J[返回伴侣回复]
```

**详细步骤说明**：

1. **伴侣验证**
   - 验证伴侣存在
   - 获取伴侣配置信息

2. **消息记录**
   - 记录玩家发送的消息

3. **AI处理**
   - 根据伴侣性格生成回复
   - 调用外部AI服务

4. **回复推送**
   - 保存聊天记录
   - 推送回复消息

### 3.4 召唤伴侣流程

```mermaid
flowchart TD
    A[请求随机召唤] --> B[获取已解锁伴侣列表]
```

## 四、关键规则

### 4.1 伴侣状态规则

| 状态 | 状态值 | 说明 |
|------|--------|------|
| 未解锁 | 0 | 伴侣未获得 |
| 已解锁 | 1 | 伴侣已获得，可互动 |
| 激活中 | 2 | 当前激活的伴侣 |

### 4.2 羁绊等级规则

1. **等级上限**：根据伴侣配置决定
2. **升级条件**：亲密度达到要求值
3. **解锁功能**：特定等级解锁新功能

### 4.3 亲密度规则

1. **获取方式**：互动、礼物、任务等
2. **上限限制**：每级有亲密度上限
3. **突破机制**：达到上限需要突破

### 4.4 皮肤解锁规则

1. **解锁条件**：等级、成就、活动等
2. **消耗资源**：部分皮肤需要消耗资源
3. **限时皮肤**：部分皮肤有时间限制

### 4.5 AI聊天规则

1. **聊天频率**：无限制
2. **内容过滤**：敏感词过滤
3. **性格影响**：不同伴侣有不同回复风格
