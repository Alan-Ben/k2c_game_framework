# Bonus 奖励系统模块 - 客户端开发文档

## 客户端组件

### 组件结构

```
game_client/Assets/Scripts/LogicScripts/GameComponent/Bonus/
└── BonusInfoNode.cs

game_client/Assets/Scripts/ResScripts/NPResCommon/UnionBonus/
└── BonusReaderMgr.cs
```

## 核心类说明

### BonusInfoNode

奖励信息节点，存储单个奖励的信息。

```csharp
public class BonusInfoNode
{
    public int bonusId;        // 奖励ID
    public int bonusType;      // 奖励类型
    public int resourceId;     // 资源ID
    public long count;         // 数量
    public int quality;        // 品质

    // 获取奖励图标
    public Sprite GetIcon();

    // 获取奖励名称
    public string GetName();

    // 获取奖励描述
    public string GetDesc();
}
```

### BonusReaderMgr

奖励读取管理器，负责:
- 解析奖励数据
- 合并相同类型奖励
- 格式化奖励显示

## 主要功能

### 奖励解析

从协议数据中解析奖励列表。

### 奖励合并

合并相同类型的奖励，减少显示项数量。

### 奖励展示

格式化奖励信息用于UI展示。

## 使用示例

### 解析奖励

```csharp
// 从协议解析奖励
List<BonusInfoNode> bonusList = BonusReaderMgr.Instance.ParseBonus(protocolData);

// 显示奖励
foreach (var bonus in bonusList)
{
    Debug.Log($"{bonus.GetName()} x {bonus.count}");
}
```

### 合并奖励

```csharp
// 合并相同类型奖励
List<BonusInfoNode> mergedList = BonusReaderMgr.Instance.MergeBonus(bonusList);
```
