# 永久属性加成数据配表文档

## 配表说明

永久属性加成模块相关的配置数据主要存储在以下配表中:

---

## 一、永久加成配置表

### RefPlayerForeverAdd - 永久属性加成配置
**文件**: `player_forever_add.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 加成ID |
| add_limit | int | 加成次数上限 |
| player_pro_add | NPPlayerPropertyModifier | 玩家属性加成 |

---

## 二、属性加成结构

### NPPlayerPropertyModifier - 玩家属性修改器

| 字段名 | 类型 | 说明 |
|--------|------|------|
| property_type | int | 属性类型 |
| add_value | long | 加成值 |
| add_ratio | float | 加成比例 |

---

## 三、加成类型说明

永久属性加成可应用于多种玩家属性：

| 属性类型 | 说明 |
|----------|------|
| POWER | 实力值 |
| SPEED | 产速 |
| EFFICIENCY | 效率 |
| CAPACITY | 容量 |

---

## 四、配表加载方式

```csharp
// 获取永久加成配置
PlayerForeverAddRefObj foreverAddRef = GRefdataCoreMgr.instance.playerForeverAddRefCore.getRef(addId);

// 获取属性修改器
NPPlayerPropertyModifier modifier = foreverAddRef.getProperty(count);
```

```java
// 服务端获取配置
RefPlayerForeverAdd ref = RefPlayerForeverAdd.getMgr().get(addId);
```

---

## 五、配置示例

```json
{
  "id": 1001,
  "add_limit": 100,
  "player_pro_add": {
    "property_type": 1,
    "add_value": 100,
    "add_ratio": 0.1
  }
}
```
