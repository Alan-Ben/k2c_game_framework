# 商店模块客户端开发文档

## 一、组件数据层

### 1.1 核心组件类

#### NPPlayerShopComponent
**路径**: `GameComponent/NPShop/NPPlayerShopComponent.cs`

**功能**: 商店管理器，管理玩家商店数据

**继承关系**:
```
NPPlayerShopComponent : _ANPBasicPlayerComponent
```

**协议模块**: p030_ShopOp

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| shopList | List<ShopInfo> | 商店列表 |
| refreshTimeDic | Dictionary | 刷新时间字典 |

---

### 1.2 商店信息类

#### ShopInfo
**功能**: 商店数据

**主要属性**:

| 属性名 | 类型 | 说明 |
|--------|------|------|
| shopId | long | 商店ID |
| shopType | int | 商店类型 |
| itemList | List<ShopItemInfo> | 商品列表 |
| refreshTime | long | 刷新时间 |

#### ShopItemInfo
**功能**: 商品数据

| 属性名 | 类型 | 说明 |
|--------|------|------|
| itemId | long | 商品ID |
| refId | long | 物品配置ID |
| price | long | 价格 |
| buyCount | int | 已购买数量 |
| limitCount | int | 限购数量 |
| discount | float | 折扣 |

---

## 二、协议接口

### 2.1 请求协议

| 协议名 | 说明 |
|--------|------|
| GC2GS_030_001_ReqShopList | 请求商店列表 |
| GC2GS_030_002_ReqShopInfo | 请求商店信息 |
| GC2GS_030_003_ReqBuyItem | 购买商品 |
| GC2GS_030_004_ReqRefreshShop | 刷新商店 |

### 2.2 响应协议

| 协议名 | 说明 |
|--------|------|
| GS2GC_030_001_RetShopList | 商店列表返回 |
| GS2GC_030_002_RetShopInfo | 商店信息返回 |
| GS2GC_030_003_RetBuyItem | 购买结果 |
| GS2GC_030_004_RetRefreshShop | 刷新结果 |
| GS2GC_030_050_OnShopUpdate | 商店更新推送 |

## 四、访问方式

```csharp
// 获取商店组件
NPPlayerShopComponent shopComp = NPPlayer.instance.shopComp;

// 获取商店列表
var shops = shopComp.shopList;

// 获取指定商店
var shop = shops.FirstOrDefault(s => s.shopId == shopId);
```
