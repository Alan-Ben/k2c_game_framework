# 引导系统数据配表文档

## 配表说明

引导系统相关的配置数据主要存储在以下配表中:

---

## 一、引导配置表

### TutorialRefObj - 引导步骤配置
**文件**: `tutorial_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 引导ID |
| name | string | 引导名称 |
| type | int | 引导类型(强制/非强制) |
| step | int | 引导步骤 |
| trigger_condition | object | 触发条件 |
| target | object | 引导目标 |
| next_tutorial_id | long | 下一个引导ID |

---

## 二、引导类型枚举

### ENPTutorialType - 引导类型

| 枚举值 | 说明 |
|--------|------|
| NONE | 无 |
| FORCE | 强制引导 |
| OPTIONAL | 可选引导 |

---

## 三、触发条件配置

引导触发条件配置在 `RefGeneral` 通用配置中：

| 配置项 | 说明 |
|--------|------|
| tutorial_force_start_id | 强制引导起始ID |
| tutorial_optional_list | 可选引导ID列表 |

---

## 四、引导数据结构

### TutorialData - 引导数据
**路径**: `ServerProtocol/src/Common/TutorialData.java`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| lastFinishForceTutorial | long | 最后完成的强制引导ID |
| finishTutorialId | ArrayList&lt;Long&gt; | 已完成的引导ID列表 |

---

## 五、配表加载方式

```csharp
// 获取引导配置
TutorialRefObj tutorialRef = GRefdataCoreMgr.instance.tutorialRefCore.getRef(tutorialId);

// 获取玩家引导数据
TutorialData tutorialData = NPPlayer.instance.tutorialData;
```
