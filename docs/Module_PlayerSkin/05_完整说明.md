# 玩家皮肤模块完整说明

## 一、模块概述

### 1.1 业务背景

玩家皮肤模块是 K2C 游戏的个性化装扮系统，负责管理玩家的皮肤、称号、头像框等外观装饰。玩家可以通过解锁和装备各种皮肤来展示个性，同时部分皮肤还提供属性加成，兼具美观与实用性。

### 1.2 目标用户

- **所有游戏玩家**：每位玩家都可以获得和使用皮肤
- **付费玩家**：通过付费获得稀有限定皮肤
- **运营人员**：配置皮肤解锁条件和活动

### 1.3 核心价值

1. **个性化展示**：丰富的皮肤选择让玩家展示独特个性
2. **成就系统**：部分皮肤作为成就奖励，增加游戏目标感
3. **属性加成**：皮肤提供额外属性，增强玩家实力
4. **商业价值**：付费皮肤是重要的收入来源

## 三、业务流程详解

### 3.1 皮肤解锁流程

```mermaid
flowchart TD
    A[请求解锁皮肤] --> B{检查皮肤配置}
    B -->|配置不存在| C[返回皮肤不存在]
    B -->|配置有效| D{检查是否已解锁}
    D -->|已解锁| E[返回已拥有]
    D -->|未解锁| F{检查解锁条件}
    F -->|条件不满足| G[返回条件不足]
    F -->|条件满足| H[检查资源消耗]
    H -->|资源不足| I[返回资源不足]
    H -->|资源充足| J[扣除消耗资源]
    J --> K[创建皮肤记录]
    K --> L[推送解锁通知]
    L --> M[显示解锁动画]
```

**详细步骤说明**：

1. **配置验证**
   - 验证皮肤ID是否有效
   - 获取皮肤配置信息（品质、类型、解锁条件）

2. **状态检查**
   - 检查玩家是否已解锁该皮肤
   - 避免重复解锁

3. **条件验证**
   - 检查解锁条件（等级、成就、VIP等）
   - 检查资源消耗（钻石、道具等）

4. **执行解锁**
   - 扣除消耗资源
   - 创建皮肤记录
   - 推送通知到客户端

### 3.2 皮肤装备流程

```mermaid
flowchart TD
    A[请求装备皮肤] --> B{检查皮肤是否解锁}
    B -->|未解锁| C[返回皮肤未解锁]
    B -->|已解锁| D{检查皮肤类型}
    D --> E[获取当前同类型皮肤]
    E --> F[取消当前皮肤效果]
    F --> G[应用新皮肤效果]
    G --> H[更新皮肤设置]
    H --> I[推送装备变化]
```

**详细步骤说明**：

1. **状态验证**
   - 检查皮肤是否已解锁
   - 检查皮肤类型是否匹配

2. **切换处理**
   - 取消当前同类型皮肤的属性加成
   - 应用新皮肤的属性加成

3. **数据更新**
   - 更新玩家的皮肤设置
   - 推送变化到客户端

### 3.3 皮肤升级流程

```mermaid
flowchart TD
    A[请求升级皮肤] --> B{检查皮肤是否存在}
    B -->|不存在| C[返回皮肤未解锁]
    B -->|存在| D{检查等级上限}
    D -->|已达上限| E[返回已达最高级]
    D -->|未达上限| F[计算升级消耗]
    F --> G{检查资源是否足够}
    G -->|不足| H[返回资源不足]
    G -->|充足| I[扣除升级资源]
    I --> J[皮肤等级+1]
    J --> K[更新属性加成]
    K --> L[推送升级通知]
```

### 3.4 称号设置流程

```mermaid
flowchart TD
    A[请求设置称号] --> B{检查称号类型}
    B -->|普通称号| C{检查是否拥有}
    B -->|组合称号| D{检查各部分是否拥有}
    C -->|未拥有| E[返回称号未解锁]
    C -->|已拥有| F{检查是否过期}
    F -->|已过期| G[返回称号已过期]
    F -->|有效| H[更新称号设置]
    D -->|部分未拥有| E
    D -->|全部拥有| I{检查各部分是否过期}
    I -->|有部分过期| G
    I -->|全部有效| J[组合称号设置]
    H --> K[推送称号变化]
    J --> K
```

## 四、关键规则

### 4.1 皮肤规则

1. **解锁规则**
   - 部分皮肤有解锁条件（等级、成就、活动）
   - 部分皮肤需要消耗资源解锁
   - 限定皮肤有获取时间限制

2. **装备规则**
   - 同类型皮肤只能装备一个
   - 卸下皮肤恢复默认外观
   - 皮肤属性加成可叠加

3. **升级规则**
   - 皮肤可升级提升属性
   - 升级消耗随等级递增
   - 每个皮肤有等级上限

### 4.2 称号规则

1. **普通称号规则**
   - 需要先解锁才能使用
   - 部分称号有有效期限制
   - 同一时间只能展示一个称号

2. **组合称号规则**
   - 由前缀、特效、背景三部分组成
   - 三部分需要分别解锁
   - 可以自由组合三部分

### 6.1 皮肤解锁示例

**输入数据**：
- 玩家ID：20001
- 皮肤ID：1001（角色皮肤-烈焰战甲）
- 皮肤类型：ROLE

**配置数据**：
```json
{
  "skin_id": 1001,
  "skin_name": "烈焰战甲",
  "skin_type": 1,
  "quality": 4,
  "unlock_condition": {
    "level": 30
  },
  "upgrade_cost": [
    {"itemId": 5001, "count": 10},
    {"itemId": 5002, "count": 5}
  ],
  "max_level": 10
}
```

**解锁结果**：
```
皮肤ID：1001
皮肤名称：烈焰战甲
皮肤等级：1
解锁时间：2026-04-07 10:00:00
```

### 6.2 皮肤升级示例

