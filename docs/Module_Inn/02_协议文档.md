## 一、客户端请求协议 (GC2GS)

### 1.1 GC2GS_034_001_ReqInnReceiveGuest - 请求接待客人

**协议号**：034-001

**说明**：请求接待客人，支持一键接待

**请求字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| isAKey | bool | 是否一键接待 |

**客户端代码**：

```csharp
// 文件路径: game_client/Assets/Scripts/ClientProtocol/GC2GS/p034_InnOp/GC2GS_034_001_ReqInnReceiveGuest.cs
public class GC2GS_034_001_ReqInnReceiveGuest : ALBasicProtocolPack._IALProtocolStructure {
    private bool isAKey;  // 是否一键

    public byte getMainOrder() { return (byte)34; }
    public byte getSubOrder() { return (byte)1; }
}
```

## 五、协议交互流程

### 5.1 接待客人流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端

    Client->>Server: GC2GS_034_001_ReqInnReceiveGuest
    Note right of Client: isAKey=true(一键)<br/>isAKey=false(单个)

    Server->>Server: 检查接待条件
    Server->>Server: 分配客人和菜品

    Server-->>Client: GS2GC_034_001_RetInnReceiveGuest
    Server-->>Client: GS2GC_034_050_OnInnReceiveChg
    Note left of Server: 推送接待队列更新

    Note over Client,Server: 接待时间结束...

    Client->>Server: GC2GS_034_006_ReqInnSettle
    Note right of Client: guestNum=接待数量

    Server->>Server: 计算奖励
    Server-->>Client: GS2GC_034_006_RetInnSettle
    Note left of Server: 返回结算信息<br/>人气值、熟练度等

    Server-->>Client: GS2GC_034_058_OnInnPopularityChg
    Note left of Server: 人气值变更推送
```

### 5.2 设施解锁流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端

    Client->>Server: GC2GS_034_002_ReqInnStationUnlock
    Note right of Client: stationId=设施ID

    Server->>Server: 检查解锁条件
    Server->>Server: 扣除建造消耗

    Server-->>Client: GS2GC_034_002_RetInnStationUnlock
    Server-->>Client: GS2GC_034_056_OnInnStationAdd
    Note left of Server: 推送设施添加

    alt 满足客栈升级条件
        Server-->>Client: GS2GC_034_057_OnInnLevelChg
        Note left of Server: 客栈等级提升
    end
```
