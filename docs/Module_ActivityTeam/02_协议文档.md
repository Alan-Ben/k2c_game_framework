## 客户端请求协议 (GC2GS)

### GC2GS_012_001_ReqActivityTeamList

**说明**：请求活动队伍列表

**协议路径**：`GC2GS/p012_ActivityTeamOp/GC2GS_012_001_ReqActivityTeamList.java`

**请求参数**：

| 字段名 | 类型 | 必填 | 说明 |
|-------|------|------|------|
| instanceId | long | 是 | 活动实例ID |
| page | int | 是 | 页码（从1开始） |

**返回**：GS2GC_012_001_RetActivityTeamList

**返回参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| teamList | ArrayList&lt;CrossTeam_Info&gt; | 队伍列表 |
| totalPage | int | 总页数 |

**错误码**：

| 错误码 | 说明 |
|-------|------|
| 70001 | 活动不存在 |

## 协议交互流程

### 创建队伍流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant DB as 数据库

    Client->>Server: GC2GS_012_005_ReqCreateActivityTeam
    Server->>Server: 检查是否已在队伍
    Server->>DB: 查询活动信息
    DB-->>Server: 返回活动数据
    Server->>Server: 验证配置
    Server->>DB: 创建队伍
    DB-->>Server: 创建成功
    Server-->>Client: GS2GC_012_005_RetCreateActivityTeam
    Server-->>Client: GS2GC_012_051_OnJoinActivityTeam
```

### 加入队伍流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant Team as 队伍服务

    Client->>Server: GC2GS_012_006_ReqJoinActivityTeam
    Server->>Team: 获取队伍信息
    Team-->>Server: 返回队伍数据
    Server->>Server: 检查加入条件

    alt 自由加入
        Server->>Team: 加入队伍
        Team-->>Server: 加入成功
        Server-->>Client: GS2GC_012_006_RetJoinActivityTeam
        Server-->>Client: GS2GC_012_051_OnJoinActivityTeam
        Server-->>Team其他成员: GS2GC_012_055_OnActivityTeamMemberAdd
    else 条件加入
        Server->>Team: 创建申请
        Team-->>Server: 申请创建成功
        Server-->>Client: GS2GC_012_010_RetApplyJoinActivityTeam
    end
```

### 申请审批流程

```mermaid
sequenceDiagram
    participant Applicant as 申请者
    participant Server as 服务端
    participant Leader as 队长

    Applicant->>Server: GC2GS_012_010_ReqApplyJoinActivityTeam
    Server->>Server: 创建申请记录
    Server-->>Applicant: GS2GC_012_010_RetApplyJoinActivityTeam
    Server-->>Leader: 通知有新申请

    Leader->>Server: GC2GS_012_011_ReqActivityTeamApplyList
    Server-->>Leader: 返回申请列表

    Leader->>Server: GC2GS_012_013_ReqAgreeActivityTeamApply
    Server->>Server: 处理申请
    Server-->>Leader: GS2GC_012_013_RetAgreeActivityTeamApply
    Server-->>Applicant: GS2GC_012_051_OnJoinActivityTeam
    Server-->>队伍成员: GS2GC_012_055_OnActivityTeamMemberAdd
```
