# 配表类生成 Skill

## 适用场景
- 根据表名、模块名、字段说明生成新的配表类
- 为已有配置表补齐标准化的字段、容器和加载逻辑
- 判断普通表与键值表的实现方式

## 执行步骤
1. 先搜索 `GameRes` 或相关模块中的同类 RefTable 实现，优先复用已有模式。
2. 根据用户提供的表名、模块名、字段列表，判断生成目标是普通表还是键值对表。
3. 映射字段类型，生成类结构、字段定义、解析逻辑和必要容器代码。
4. 校验命名、包路径、导入和容器类型是否与现有项目一致。

## 关键规则
- 普通表优先使用 `RefTableContainer<T>`
- 键值对表使用 `RefSingleContainer<T>`
- 如果用户未明确说明，默认按普通表处理
- 字段类型映射必须参考仓库中已有类似表，不自行发明新模式

## 输出要求
- 生成完整可落地的 Java 代码
- 命名遵循现有项目规范
- 导入使用 `import`，不要在代码中写全限定类名
- 注释保持简洁，优先补业务上不明显的字段含义

## 注意事项
- 先读现有同类表，再生成；不要脱离仓库现状硬写模板
- 如果无法判断表类型或字段语义，优先从相近表推断；仍不清楚时再向用户确认
- 修改生成类时，不要顺手重命名已有生成产物
