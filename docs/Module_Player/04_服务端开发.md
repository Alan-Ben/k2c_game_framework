# 玩家模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

玩家模块（Player Module）负责管理玩家核心数据，包括：
- 玩家基础信息管理
- 等级与经验管理
- 头像、头像框、气泡管理
- 称号系统
- 玩家属性管理

### 1.2 模块编号

协议模块编号: `p004`, `p021`

## 四、核心逻辑流程

### 4.1 玩家升级流程

```
客户端                          服务端
   |                               |
   |--- ReqLevelUp --------------->|
   |                               | 1. 验证经验是否足够
   |                               | 2. 扣除经验
   |                               | 3. 增加等级
   |                               | 4. 发放升级奖励
   |                               | 5. 解锁功能
   |<-- RetLevelUp ----------------|
   |<-- OnPlayerLevelChg ---------| (推送等级变化)
   |                               |
```

### 4.2 设置名称流程

```
客户端                          服务端
   |                               |
   |--- ReqSetName --------------->|
   |                               | 1. 验证名称合法性
   |                               | 2. 验证名称是否重复
   |                               | 3. 检测敏感词
   |                               | 4. 扣除改名道具
   |                               | 5. 更新名称
   |<-- RetSetName ----------------|
   |<-- OnPlayerNameChg ----------| (推送名称变化)
   |                               |
```

## 六、服务配置

### 6.1 协议注册

```csharp
// 协议主序号
public const byte PLAYER_MODULE_ORDER = 4;
public const byte PLAYER_INFO_ORDER = 21;

// 协议处理器注册
protocolHandler.Register<GC2GS_004_001_ReqLevelUp>(OnLevelUp);
protocolHandler.Register<GC2GS_004_004_ReqSetName>(OnSetName);
// ... 其他协议注册
```

### 6.2 服务依赖

玩家模块依赖以下服务：
- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
- 过滤服务 (FilterService)
