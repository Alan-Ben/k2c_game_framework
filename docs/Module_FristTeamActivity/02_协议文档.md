### 2.1 GC2GS_003_001_ReqGameLogicTest - 游戏逻辑测试请求

**协议编号**: `003_001`
**功能说明**: 测试游戏主体逻辑，验证活动逻辑的正确性
**权限要求**: 开发环境可用 / 生产环境需管理员权限

| 字段名 | 类型 | 必填 | 默认值 | 说明 | 示例值 |

| instanceId | long | 是 | - | 活动实例ID | 100001 |
| param1 | int | 否 | 0 | 测试参数1 | 100 |

**类型**: long
**必填**: 是
**说明**: 要测试的活动实例的唯一标识符

**取值范围**: > 0

**验证规则**:

### 4.1 游戏逻辑测试流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Server as 服务端
    participant ActivityMgr as 活动管理器
    participant Dealer as 逻辑处理器

    Client->>Server: GC2GS_003_001_ReqGameLogicTest
    Server->>Server: 权限检查

            else 处理器存在
                Server->>Dealer: dealMsg(msg)
                Dealer-->>Server: 处理完成
                Server-->>Client: GS2GC_003_001_RetGameLogicTest
            end
        end
    end
```

## 五、错误码定义

### 5.1 模块错误码

| 错误码 | 错误名 | 说明 | 客户端提示 |
|--------|--------|------|-----------|
| 30001 | ACTIVITY_NOT_FOUND | 活动未找到 | "指定的活动实例不存在" |
| 30002 | OBJ_ERROR | 对象错误 | "内部对象获取失败" |
| 30003 | PERMISSION_DENIED | 权限不足 | "无测试权限" |
| 30004 | ENV_RESTRICTED | 环境受限 | "当前环境禁止测试" |
| 30005 | TEST_DISABLED | 测试功能禁用 | "测试功能已禁用" |
| 30006 | INVALID_INSTANCE_ID | 无效实例ID | "活动实例ID无效" |

### 5.2 错误码枚举定义

```java
public enum FristTeamActivityErr {
    ACTIVITY_NOT_FOUND(30001, "活动未找到"),
    OBJ_ERROR(30002, "对象错误"),
    PERMISSION_DENIED(30003, "权限不足"),
    ENV_RESTRICTED(30004, "环境受限"),
    TEST_DISABLED(30005, "测试功能禁用"),
    INVALID_INSTANCE_ID(30006, "无效实例ID");

    private final int code;
    private final String desc;

    FristTeamActivityErr(int code, String desc) {
        this.code = code;
        this.desc = desc;
    }

    public int getCode() { return code; }
    public String getDesc() { return desc; }
}
```

### 5.3 错误处理流程

```mermaid
flowchart TD
    A[收到协议请求] --> B{权限检查}
    B -->|权限不足| C[返回 PERMISSION_DENIED]
    B -->|有权限| D{环境检查}
    D -->|环境受限| E[返回 ENV_RESTRICTED]
    D -->|环境允许| F{活动查找}
    F -->|未找到| G[返回 ACTIVITY_NOT_FOUND]
    F -->|找到| H[获取逻辑处理器]
    H --> I{处理器是否存在}
    I -->|不存在| J[返回 OBJ_ERROR]
    I -->|存在| K[执行测试逻辑]
    K --> L[返回成功响应]

    C --> M[客户端显示错误提示]
    E --> M
    G --> M
    J --> M
    L --> N[客户端更新UI]
```

## 十、协议安全说明

### 10.1 权限控制

```mermaid
flowchart TD
    A[协议请求] --> B{环境检查}
    B -->|开发/测试环境| C[允许访问]
    B -->|生产环境| D{管理员检查}
    D -->|是管理员| C
    D -->|非管理员| E[拒绝访问]
    C --> F[执行协议处理]
    E --> G[返回权限错误]
```

### 10.2 安全建议

1. **环境隔离**: 测试协议仅在开发和测试环境开放
2. **权限验证**: 生产环境必须验证管理员权限
3. **日志记录**: 所有测试操作必须记录日志
4. **频率限制**: 建议对测试请求添加频率限制
