# K2C 游戏框架公式汇总

## 一、实力计算公式

### 1.1 英雄实力计算

**公式**：
```
英雄实力 = 基础实力 + 等级加成 + 阶段加成 + 觉醒加成 + 装备加成 + 皮肤加成 + 光环加成 + 额外加成
```

**详细计算**：
```python
def calculate_hero_power(hero):
    power = 0

    # 基础实力
    hero_ref = get_hero_ref(hero.ref_id)
    power += hero_ref.base_power

    # 等级加成
    power += hero.level * hero_ref.level_power_ratio

    # 阶段加成
    power += hero.step * hero_ref.step_power_ratio

    # 觉醒加成
    power += hero.star * hero_ref.star_power_ratio

    # 装备加成
    for equip in get_equips_by_hero(hero.hero_id):
        equip_ref = get_equip_ref(equip.ref_id)
        level_ref = get_equip_level_ref(equip.level)
        power += equip_ref.base_attr * level_ref.attr_ratio

    # 皮肤加成
    if hero.skin_id > 0:
        skin = get_skin_info(hero.hero_id, hero.skin_id)
        skin_ref = get_skin_ref(hero.skin_id)
        power += skin.level * skin_ref.attr_add

    # 光环加成
    if hero.halo_info and hero.halo_info.level > 0:
        halo_ref = get_halo_ref(hero_ref.halo_id)
        power += hero.halo_info.level * halo_ref.attr_add

    # 额外加成
    power += hero.item_add_power
    power += hero.arena_add_power
    power += hero.travel_add_power

    return power
```

**示例**：
```
英雄：关羽
配置：base_power=1000, level_ratio=50, step_ratio=500, star_ratio=800
状态：level=30, step=2, star=3
装备：武器+2000, 防具+1500, 饰品+1000
皮肤：level=5, attr_add=200
光环：level=3, attr_add=300
额外：item=500, arena=300

实力 = 1000 + 30*50 + 2*500 + 3*800 + 4500 + 5*200 + 3*300 + 800
     = 1000 + 1500 + 1000 + 2400 + 4500 + 1000 + 900 + 800
     = 13,100
```

### 1.2 玩家总实力计算

**公式**：
```
总实力 = 英雄实力总和 + 玩家属性加成 + 称号加成 + 其他加成
```

**详细计算**：
```python
def calculate_player_power(player):
    power = 0

    # 英雄实力总和
    for hero in get_all_heroes(player.player_id):
        power += calculate_hero_power(hero)

    # 玩家属性加成
    power += (player.level - 1) * PLAYER_LEVEL_POWER_RATIO

    # 称号加成
    if player.title_id > 0:
        title_ref = get_title_ref(player.title_id)
        power += title_ref.power_add

    # VIP加成
    power += player.vip_level * VIP_POWER_RATIO

    # 公会技能加成
    guild_skills = get_guild_skills(player.player_id)
    for skill in guild_skills:
        skill_ref = get_guild_skill_ref(skill.skill_id)
        power += skill.level * skill_ref.power_ratio

    return power
```

## 二、升级消耗公式

### 2.1 英雄升级消耗

**公式**：
```
升级消耗 = base_cost × level_ratio ^ (target_level - current_level)
```

**示例**：
```python
def calculate_upgrade_cost(current_level, target_level):
    base_cost = 100  # 基础消耗
    level_ratio = 1.15  # 等级系数

    total_cost = 0
    for level in range(current_level, target_level):
        cost = base_cost * (level_ratio ** level)
        total_cost += int(cost)

    return total_cost

# 示例：25级升到30级
cost = calculate_upgrade_cost(25, 30)
# 结果约：875银两
```

## 三、资源相关公式

### 3.1 资源恢复公式

**公式**：
```
恢复量 = floor((当前时间 - 上次恢复时间) / 恢复间隔)
实际恢复 = min(恢复量, 上限 - 当前值)
```

**示例**：
```python
def recover_resource(player, resource_type):
    config = get_resource_config(resource_type)

    elapsed = now() - player.get_recover_time(resource_type)
    recover_count = int(elapsed / config.recover_interval)

    current = player.get_resource(resource_type)
    max_value = get_resource_max(player, resource_type)

    actual_recover = min(recover_count, max_value - current)

    player.set_resource(resource_type, current + actual_recover)
    player.set_recover_time(resource_type, now())

    return actual_recover

# 示例：体力恢复
# 恢复间隔：300秒（5分钟）
# 上次恢复：10:00，当前时间：10:30
# 当前体力：80，上限：100
# 经过时间：1800秒，理论恢复：6点
# 实际恢复：min(6, 100-80) = 6点
```

### 3.2 装备分解产出

**公式**：
```
分解产出 = base_reward × quality_ratio × (1 + level_bonus)
```

**品质系数**：
| 品质 | 系数 |
|------|------|
| 白色 | 1.0 |
| 绿色 | 1.5 |
| 蓝色 | 2.0 |
| 紫色 | 3.0 |
| 橙色 | 5.0 |

**示例**：
```python
def calculate_disassemble_reward(equip):
    base_reward = 10  # 基础材料数量

    quality_ratios = {1: 1.0, 2: 1.5, 3: 2.0, 4: 3.0, 5: 5.0}
    quality_ratio = quality_ratios[equip.quality]

    level_bonus = equip.level * 0.05  # 每级+5%

    return int(base_reward * quality_ratio * (1 + level_bonus))

# 示例：紫色装备20级分解
# 产出 = 10 × 3.0 × (1 + 20×0.05) = 10 × 3 × 2 = 60强化石
```

## 四、战斗相关公式

### 4.1 建筑产出加成

**公式**：
```
建筑产出加成 = base_output × (1 + hero_bonus_ratio)
hero_bonus_ratio = 经营技能等级 × skill_effect_ratio + 相性加成
```

**示例**：
```python
def calculate_building_output(building, hero):
    base_output = get_building_ref(building.ref_id).base_output

    # 经营技能加成
    skill = get_business_skill(hero.hero_id)
    skill_bonus = skill.level * 0.05 if skill else 0

    # 相性加成
    hero_ref = get_hero_ref(hero.ref_id)
    building_ref = get_building_ref(building.ref_id)
    affinity_bonus = 0.2 if hero_ref.spec_attr_type == building_ref.spec_attr_type else 0

    total_bonus = skill_bonus + affinity_bonus

    return int(base_output * (1 + total_bonus))

# 示例：
# 建筑基础产出：1000/小时
# 英雄经营技能等级：5，系数：0.05
# 相性匹配加成：20%
# hero_bonus = 5 × 0.05 + 0.2 = 0.45
# 最终产出 = 1000 × 1.45 = 1450/小时
```

### 5.2 公会技能效果

**公式**：
```
技能效果 = 基础效果 × 技能等级
实际效果 = 技能效果 × (1 + 公会建筑加成)
```

**示例**：
```python
def calculate_guild_skill_effect(player, skill_id):
    skill = get_guild_skill(player.player_id, skill_id)
    skill_ref = get_guild_skill_ref(skill_id)

    # 基础效果
    base_effect = skill_ref.base_effect  # 如：2%攻击力/级
    skill_effect = base_effect * skill.level

    # 公会建筑加成
    guild = get_guild(player.guild_id)
    building_bonus = get_guild_building_bonus(guild.guild_id, "技能馆")

    return skill_effect * (1 + building_bonus)

# 示例：
# 技能：攻击强化，基础效果：2%/级
# 当前等级：5级
# 公会建筑加成：10%
# 实际效果 = 2% × 5 × 1.1 = 11%攻击力加成
```

## 六、任务相关公式

### 6.1 任务等级奖励系数

**公式**：
```
实际奖励 = 基础奖励 × min(等级系数, 2.0)
等级系数 = 1 + (玩家等级 - 解锁等级) × 0.05
```

**示例**：
```python
def calculate_quest_reward(player, quest_ref):
    base_reward = quest_ref.reward

    level_diff = player.level - quest_ref.unlock_level
    level_ratio = 1 + level_diff * 0.05
    level_ratio = min(level_ratio, 2.0)  # 最多2倍

    return {item: int(count * level_ratio) for item, count in base_reward.items()}

# 示例：
# 任务解锁等级：10级
# 基础奖励：银两×1000
# 玩家等级：15级
# 等级系数 = 1 + (15-10) × 0.05 = 1.25
# 实际奖励 = 1000 × 1.25 = 1250银两
```
