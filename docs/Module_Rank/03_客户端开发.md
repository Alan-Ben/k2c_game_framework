## 数据管理

### NPRankCommon

```csharp
public class NPRankCommon : _ANPBasicPlayerComponent
{
    // 各榜单数据
    private Dictionary<int, List<RankInfo>> _m_rankDic;

    // 我的排名信息
    private Dictionary<int, int> _m_myRankDic;

    /// <summary>
    /// 获取排行榜数据
    /// </summary>
    public List<RankInfo> getRankList(ERankType rankType)
    {
        if (_m_rankDic.TryGetValue((int)rankType, out var list))
            return list;
        return null;
    }

    /// <summary>
    /// 请求排行榜
    /// </summary>
    public void reqRankList(ERankType rankType, Action callback)
    {
        NPGSClientListener.sendRequest(
            NPGSWriter_031_RankOp.make_001_ReqRankFixedBaseList((int)rankType),
            new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_031_001_RetRankFixedBaseList>((msg) =>
            {
                _m_rankDic[(int)rankType] = msg.getRankList();
                _m_myRankDic[(int)rankType] = msg.getMyRank();
                callback?.Invoke();
            }));
    }

    /// <summary>
    /// 点赞
    /// </summary>
    public void reqLike(ERankType rankType, long targetPlayerId, Action callback)
    {
        NPGSClientListener.sendRequest(
            NPGSWriter_031_RankOp.make_002_ReqRankFixedLike((int)rankType, targetPlayerId),
            new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_031_002_RetRankFixedLike>((msg) =>
            {
                callback?.Invoke();
            }));
    }
}
```

## UI 窗口

### 排行榜界面

```csharp
public class RankWindow : BaseWindow
{
    private ERankType _currentRankType;

    public void setRankType(ERankType rankType)
    {
        _currentRankType = rankType;
        NPRankCommon.instance.reqRankList(rankType, () =>
        {
            refreshRankList();
        });
    }

    private void refreshRankList()
    {
        var rankList = NPRankCommon.instance.getRankList(_currentRankType);
        updateRankItems(rankList);
    }

    public void onClickLike(int rank)
    {
        var rankList = NPRankCommon.instance.getRankList(_currentRankType);
        var targetPlayerId = rankList[rank - 1].playerId;

        NPRankCommon.instance.reqLike(_currentRankType, targetPlayerId, () =>
        {
            showLikeEffect();
        });
    }
}
```

## 注意事项

1. 排行榜数据有缓存时间
2. 点赞有每日次数限制
3. 不同榜单类型需分别请求
