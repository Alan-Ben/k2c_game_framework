# ActivityTeamOp 模块 - 数据配表文档

## 模块概述

**模块编号**: p012
**模块名称**: ActivityTeamOp (组队活动操作)
**主要功能**: 提供活动组队相关功能，包括队伍创建、加入、退出、踢人、申请审批等

## 配置文件

### 关联配置表

| 配置表名称 | 用途 | 说明 |
|-----------|------|------|
| ActivityConfig | 活动基础配置 | 定义活动类型、时间等 |
| TeamActivityConfig | 组队活动配置 | 定义队伍人数上限、加入条件等 |
| CrossTeamConfig | 跨服队伍配置 | 跨服组队相关配置 |

## 数据结构

### 队伍信息 (CrossTeam_SetInfo_Join)

```csharp
// 加入条件配置
public class CrossTeam_SetInfo_Join
{
    public int minLevel;        // 最低等级要求
    public int maxLevel;        // 最高等级限制
    public long minPower;       // 最低战力要求
    // 其他条件...
}
```

### 队伍加入方式 (ENPCrossTeamJoinType)

| 枚举值 | 说明 |
|--------|------|
| FREE | 自由加入 |
| APPLY | 申请加入 |
| INVITE | 邀请加入 |

### 队伍数据结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| teamId | long | 队伍唯一ID |
| instanceId | long | 活动实例ID |
| teamName | String | 队伍名称 |
| teamDec | String | 队伍宣言 |
| joinType | ENPCrossTeamJoinType | 加入方式 |
| joinCond | CrossTeam_SetInfo_Join | 加入条件 |
| leaderCid | long | 队长CID |
| members | List | 队员列表 |

## 配置字段说明

### 队伍配置

| 字段名 | 类型 | 说明 |
|--------|------|------|
| maxMemberCount | int | 最大成员数量 |
| minMemberCount | int | 最小成员数量(开启条件) |
| autoDissolveTime | int | 自动解散时间(秒) |

## 配置加载流程

1. 服务器启动加载活动配置
2. 根据活动类型初始化队伍系统
3. 玩家进入活动时加载队伍数据
