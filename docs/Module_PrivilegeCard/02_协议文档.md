# 权益卡协议文档

## 协议模块编号: p002 (InitOp) / p021 (PlayerInfo)

---

## 一、客户端请求协议 (GC2GS)

### 1.1 初始化相关

#### GC2GS_002_027_ReqPrivilegeCardInit - 请求权益卡初始化
**功能说明**: 请求获取玩家所有权益卡数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| (无参数) | - | - |

---

### 1.2 奖励领取

#### GC2GS_021_004_ReqGainPrivilegeCardDailyReward - 领取每日奖励
**功能说明**: 领取权益卡每日奖励

| 字段名 | 类型 | 说明 |
|--------|------|------|
| cardType | EPrivilegeCardType | 权益卡类型 |

---

## 二、服务端响应协议 (GS2GC)

### 2.1 初始化响应

#### GS2GC_002_027_RetPrivilegeCardInit - 返回权益卡初始化数据
**功能说明**: 返回玩家所有权益卡数据

| 字段名 | 类型 | 说明 |
|--------|------|------|
| cardList | List&lt;PrivilegeCardObj_Info&gt; | 权益卡列表 |

---

### 2.2 操作响应

#### GS2GC_021_004_RetGainPrivilegeCardDailyReward - 领取每日奖励结果
**功能说明**: 返回领取每日奖励结果

| 字段名 | 类型 | 说明 |
|--------|------|------|
| cardType | EPrivilegeCardType | 权益卡类型 |
| rewardList | List&lt;RewardItem&gt; | 奖励列表 |

---

### 2.3 推送通知协议

#### GS2GC_021_054_OnPrivilegeCardChg - 权益卡变化推送
**功能说明**: 推送权益卡数据变化

| 字段名 | 类型 | 说明 |
|--------|------|------|
| card | PrivilegeCardObj_Info | 变化的权益卡信息 |

---

## 三、数据结构

### PrivilegeCardObj_Info - 权益卡信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| cardType | EPrivilegeCardType | 权益卡类型 |
| expireTimeS | int | 过期时间戳 |
| lastRewardTimeS | int | 上次领奖时间 |
| totalGainDays | int | 累计获得天数 |

---

## 四、协议调用流程

### 4.1 权益卡初始化流程
```
客户端                          服务端
   |                               |
   |--- ReqPrivilegeCardInit ----->|
   |                               | (查询玩家权益卡数据)
   |<-- RetPrivilegeCardInit ------|
   |                               |
```

### 4.2 领取每日奖励流程
```
客户端                          服务端
   |                               |
   |--- ReqGainPrivilegeCardDailyReward -->|
   |                               | (验证是否可领取)
   |                               | (发放奖励)
   |<-- RetGainPrivilegeCardDailyReward ---|
   |                               |
```

### 4.3 权益卡变化流程
```
服务端                           客户端
   |                               |
   | (玩家获得权益卡)               |
   |--- OnPrivilegeCardChg ------->|
   |                               | (更新本地数据)
   |                               |
```
