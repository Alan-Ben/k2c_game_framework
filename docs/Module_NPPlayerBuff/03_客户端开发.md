## 核心类说明

### NPPlayerBuffComponent

玩家Buff组件，管理玩家身上所有Buff。

```csharp
public class NPPlayerBuffComponent : NPComponentBase
{
    // Buff列表
    private List<NPPlayerBuffInfo> buffList;

    // 添加Buff
    public void AddBuff(NPPlayerBuffInfo buff);

    // 移除Buff
    public void RemoveBuff(int buffId);

    // 获取Buff
    public NPPlayerBuffInfo GetBuff(int buffId);

    // 计算总效果
    public long GetTotalEffect(int effectType);

    // 检查是否有Buff
    public bool HasBuff(int buffId);
}
```

### NPPlayerBuffInfo

单个Buff信息类。

```csharp
public class NPPlayerBuffInfo
{
    public int buffId;          // Buff ID
    public int buffType;        // Buff类型
    public long remainTime;     // 剩余时间
    public long effectValue;    // 效果值

    // 是否已过期
    public bool IsExpired();

    // 获取剩余时间描述
    public string GetRemainTimeDesc();
}
```

## 主要功能

### Buff管理

- 添加/移除Buff
- 更新Buff状态
- 处理Buff过期

### 效果计算

- 计算属性加成
- 计算资源产量加成
- 处理特殊效果

## 使用示例

### 获取攻击加成

```csharp
// 获取总攻击加成
long attackBonus = PlayerBuffComponent.Instance.GetTotalEffect(BuffType.ATTACK);
```

### 检查特定Buff

```csharp
if (PlayerBuffComponent.Instance.HasBuff(buffId))
{
    var buff = PlayerBuffComponent.Instance.GetBuff(buffId);
    Debug.Log($"Buff剩余时间: {buff.GetRemainTimeDesc()}");
}
```
