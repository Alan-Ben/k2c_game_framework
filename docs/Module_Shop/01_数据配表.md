# 商店模块数据配表文档

## 配表说明

商店模块相关的配置数据主要存储在以下配表中:

---

## 一、商店基础配表

### ShopRefObj - 商店配置
**文件**: `shop_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 商店配置ID |
| name | string | 商店名称 |
| type | int | 商店类型 |
| refresh_type | int | 刷新类型 |
| refresh_cost | object | 刷新消耗 |
| slot_count | int | 商品槽数量 |

**商店类型枚举**:
| 类型ID | 说明 |
|--------|------|
| 1 | 普通商店 |
| 2 | 竞技场商店 |
| 3 | 公会商店 |
| 4 | 活动商店 |
| 5 | 神秘商店 |

**刷新类型枚举**:
| 类型ID | 说明 |
|--------|------|
| 1 | 手动刷新 |
| 2 | 每日刷新 |
| 3 | 每周刷新 |
| 4 | 固定时间刷新 |

---

## 二、商品配表

### ShopItemRefObj - 商品配置
**文件**: `shop_item_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 商品ID |
| shop_id | long | 所属商店ID |
| item_id | long | 物品ID |
| item_count | long | 物品数量 |
| price | object | 价格 |
| discount | float | 折扣 |
| buy_limit | int | 购买限制 |
| unlock_condition | object | 解锁条件 |

---

## 三、礼包配表

### GiftPackRefObj - 礼包配置
**文件**: `gift_pack_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 礼包ID |
| name | string | 礼包名称 |
| type | int | 礼包类型 |
| price | object | 价格 |
| content | array | 礼包内容 |
| buy_limit | int | 购买限制 |
| show_time | object | 显示时间 |

---

## 四、限时礼包配表

### LimitGiftPackRefObj - 限时礼包配置
**文件**: `limit_gift_pack_ref.json`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | long | 礼包ID |
| name | string | 礼包名称 |
| trigger_condition | object | 触发条件 |
| duration | long | 持续时间（秒） |
| content | array | 礼包内容 |
| price | object | 价格 |

---

## 五、配表加载方式

```csharp
// 获取商店配置
ShopRefObj shopRef = GRefdataCoreMgr.instance.shopRefCore.getRef(shopId);

// 获取商品配置
ShopItemRefObj itemRef = GRefdataCoreMgr.instance.shopItemRefCore.getRef(itemId);

// 获取礼包配置
GiftPackRefObj giftRef = GRefdataCoreMgr.instance.giftPackRefCore.getRef(giftId);
```
