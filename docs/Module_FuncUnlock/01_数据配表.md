# FuncUnlock 功能解锁模块 - 数据配表文档

## 模块概述

**模块名称**: FuncUnlock (功能解锁)
**模块类型**: 客户端独立组件
**主要功能**: 管理游戏功能解锁条件和解锁状态

## 配置文件

### 配置表

| 配置表名称 | 用途 |
|-----------|------|
| FuncUnlockConfig | 功能解锁配置 |
| FuncConditionConfig | 解锁条件配置 |

## 数据结构

### 解锁信息 (FuncUnlockInfo)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| funcId | int | 功能ID |
| funcName | String | 功能名称 |
| unlockLevel | int | 解锁等级 |
| unlockCondition | Object | 解锁条件 |
| isUnlocked | boolean | 是否已解锁 |

## 功能类型

| 类型ID | 类型名 | 说明 |
|--------|--------|------|
| 1 | SYSTEM | 系统功能 |
| 2 | BUILDING | 建筑功能 |
| 3 | ACTIVITY | 活动功能 |
| 4 | SOCIAL | 社交功能 |
| 5 | SHOP | 商店功能 |
