## 服务端响应协议 (GS2GC)

### GS2GC_002_001_RetPlayerInfo

**说明**：返回玩家基础信息

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| playerId | long | 玩家ID |
| playerName | string | 玩家名称 |
| level | int | 等级 |
| exp | long | 经验值 |
| vipLevel | int | VIP等级 |
| createTime | long | 创建时间 |
| lastLoginTime | long | 最后登录时间 |

---

### GS2GC_002_003_RetCurrencyList

**说明**：返回货币列表

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| currencyList | array<CurrencyInfo> | 货币列表 |

---

### GS2GC_002_007_RetBagItemList

**说明**：返回背包物品列表

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemList | array<ItemInfo> | 物品列表 |

---

### GS2GC_002_012_RetHeroInit

**说明**：返回英雄初始化数据

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| heroList | array<HeroInfo> | 英雄列表 |
| formationList | array<long> | 阵容列表 |

---

### GS2GC_002_050_RetAchieveInit

**说明**：返回成就初始化数据

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| achieveList | array<Achieve_Info> | 成就列表 |
| achievePointList | array<Achieve_AchievePointInfo> | 成就点列表 |

---

### GS2GC_002_255_OnQuestCountInit

**说明**：返回任务计数初始化

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| questCountList | array<QuestCountInfo> | 任务计数列表 |

---

## 数据结构

### CurrencyInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| currencyType | int | 货币类型 |
| amount | long | 数量 |

### ItemInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemId | long | 物品ID |
| itemCfgId | int | 物品配置ID |
| count | int | 数量 |
| expireTime | long | 过期时间 |

### Achieve_Info

| 字段名 | 类型 | 说明 |
|-------|------|------|
| achieveId | long | 成就ID |
| progress | long | 进度 |
| curStep | int | 当前阶段 |

### Achieve_AchievePointInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| type | int | 成就类型 |
| count | long | 成就点数 |
| hadDrawMaxStep | long | 已领取最大阶段 |
