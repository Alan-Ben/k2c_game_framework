#### 客户端处理

```csharp
// 监听器处理
public class GSSubDealer_030_050_OnShopRefresh : _AGSSubDealerBase
{
    public override void deal(NPPlayer _player, GS2GC_030_050_OnShopRefresh _msg)
    {
        Shop_Info shopInfo = _msg.getShop();
        _player.shopComp.retOnShopRefresh(shopInfo);
    }

// 组件处理
public void retOnShopRefresh(Shop_Info _info)
{
    if (null == _info) return;

    NPPlayerShop shop = getShop(_info.getShopRefId());
    if (null == shop) return;

    shop.update(_info);
    setShopNextRefreshTimeMs(_info.getShopRefId(), _info.getNextRefreshTimeMs());
    _m_redDealer?.refrshRedTip(shop);
}
```

#### 客户端处理

```csharp
// 监听器处理
public class GSSubDealer_030_051_OnShopItemChg : _AGSSubDealerBase
{
    public override void deal(NPPlayer _player, GS2GC_030_051_OnShopItemChg _msg)
    {
        long shopId = _msg.getShopRefId();
        Shop_ItemInfo itemInfo = _msg.getShopItem();
        _player.shopComp.retOnShopItemChg(shopId, itemInfo);
    }
}

// 组件处理
public void retOnShopItemChg(long _shopId, Shop_ItemInfo _item)
{
    if (null == _item) return;

    NPPlayerShop shop = getShop(_shopId);
    if (null == shop) return;

    shop.updateItem(_item);
}

// 商品更新
public void updateItem(Shop_ItemInfo _item)
{
    NPPlayerShopItem temp = null;
    for (int i = 0; i < _m_shopItemList.Count; i++)
    {
        temp = _m_shopItemList[i];
        if (temp.instanceId == _item.getInstanceId())
        {
            temp.update(_item);
            break;
        }
    }
}
```

## 四、协议交互流程

### 4.1 商品购买完整流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Bag as 背包模块
    participant Currency as 货币模块

    C->>S: GC2GS_030_001_ReqBuyShopItem<br/>(shopRefId, instanceId, count)

    S->>S: 验证商店是否解锁
    S->>S: 验证商品是否存在
    S->>S: 验证购买次数限制

    S->>Currency: 检查货币是否足够
    Currency-->>S: 返回货币数量

    alt 货币不足
        S-->>C: 返回错误码: 货币不足
    else 货币足够
        S->>Currency: 扣除货币
        S->>Bag: 发放物品
        S->>DB: 更新购买记录
        S->>DB: 记录购买日志

        S-->>C: GS2GC_030_001_RetBuyShopItem<br/>(result=0, rewards)

        alt 达到购买上限
            S->>S: 标记商品售罄
            S-->>C: GS2GC_030_051_OnShopItemChg<br/>(shopRefId, itemInfo)
        end
    end
```

### 4.2 商店刷新完整流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant S as 服务端
    participant DB as 数据库
    participant Currency as 货币模块
    participant Random as 随机服务

    C->>S: GC2GS_030_003_ReqRefreshShop<br/>(shopRefId)

    S->>S: 检查刷新次数限制
    S->>S: 计算刷新费用

    alt 免费刷新
        S->>S: 检查免费次数
    else 付费刷新
        S->>Currency: 检查货币
        S->>Currency: 扣除货币
    end

    S->>Random: 随机生成新商品列表
    Random-->>S: 返回商品列表

    S->>DB: 更新商店数据
    S->>DB: 记录刷新日志

    S-->>C: GS2GC_030_050_OnShopRefresh<br/>(shopInfo)
```

### 4.3 自动刷新定时流程

```mermaid
sequenceDiagram
    participant Timer as 定时器
    participant S as 服务端
    participant DB as 数据库
    participant C as 客户端

    loop 每分钟检查
        Timer->>S: 检查需要刷新的商店
        S->>DB: 查询next_refresh_time <= 当前时间
        DB-->>S: 返回商店列表

        loop 遍历每个商店
            S->>S: 随机生成新商品
            S->>DB: 更新商店数据
            S-->>C: GS2GC_030_050_OnShopRefresh
        end
    end
```

| 30006 | CURRENCY_NOT_ENOUGH | 货币不足 | 扣除货币时 | "货币不足" |
