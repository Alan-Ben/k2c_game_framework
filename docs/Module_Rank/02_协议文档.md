# 排行榜系统 - 协议文档

## 协议编号

模块编号：p031 (RankOp)

## 客户端请求协议 (GC2GS)

### GC2GS_031_001_ReqRankFixedBaseList

**说明**：请求排行榜基础列表

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rankType | int | 榜单类型 |

**返回**：GS2GC_031_001_RetRankFixedBaseList

---

### GC2GS_031_002_ReqRankFixedLike

**说明**：请求点赞

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rankType | int | 榜单类型 |
| targetPlayerId | long | 目标玩家ID |

**返回**：GS2GC_031_002_RetRankFixedLike

---

### GC2GS_031_003_ReqRankFixedLikeScore

**说明**：请求点赞分数

---

### GC2GS_031_004_ReqRankFixedAKeyLike

**说明**：请求一键点赞

---

### GC2GS_031_005_ReqRankFixedInfoByRank

**说明**：请求按排名获取信息

---

### GC2GS_031_006_ReqRankFixedInfoByKey

**说明**：请求按键值获取信息

---

## 服务端响应协议 (GS2GC)

### GS2GC_031_001_RetRankFixedBaseList

**说明**：返回排行榜基础列表

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rankType | int | 榜单类型 |
| rankList | array | 排名列表 |
| myRank | int | 我的排名 |
| myScore | long | 我的分数 |

---

## 数据结构

### RankInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| rank | int | 排名 |
| playerId | long | 玩家ID |
| playerName | string | 玩家名称 |
| score | long | 分数 |
| likeCount | int | 点赞数 |
