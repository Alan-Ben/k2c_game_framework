## 三、协议调用流程

### 3.1 周卡初始化流程
```
客户端                          服务端
   |                               |
   |--- ReqWeekCardInit ---------->|
   |                               | (查询周卡数据)
   |<-- RetWeekCardInit -----------|
   |                               |
```

### 3.2 激活免费试用流程
```
客户端                          服务端
   |                               |
   |--- ReqWeekCardActiveFreeTrial -->|
   |                               | (验证是否可激活)
   |                               | (激活周卡)
   |<-- RetWeekCardActiveFreeTrial ---|
   |                               |
```

### 3.3 离线结算流程
```
服务端                           客户端
   |                               |
   | (玩家上线)                     |
   |--- 计算离线溢出CD -------------|
   |--- OnWeekCardChg ------------->|
   |--- PushRedDotChg ------------->|
   |                               |
```
