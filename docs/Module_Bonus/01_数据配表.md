# Bonus 奖励系统模块 - 数据配表文档

## 模块概述

**模块名称**: Bonus (奖励系统)
**模块类型**: 客户端独立组件
**主要功能**: 提供奖励展示、奖励计算、奖励合并等通用奖励处理功能

## 配置文件

### 配置表

| 配置表名称 | 用途 |
|-----------|------|
| BonusConfig | 奖励配置 |
| BonusTypeConfig | 奖励类型配置 |
| BonusMergeConfig | 奖励合并规则 |

## 数据结构

### 奖励信息节点 (BonusInfoNode)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| bonusId | int | 奖励ID |
| bonusType | int | 奖励类型 |
| resourceId | int | 资源ID |
| count | long | 数量 |
| quality | int | 品质 |

## 奖励类型

| 类型ID | 类型名 | 说明 |
|--------|--------|------|
| 1 | RESOURCE | 资源类奖励 |
| 2 | ITEM | 物品类奖励 |
| 3 | HERO | 英雄类奖励 |
| 4 | SKIN | 皮肤类奖励 |
| 5 | TITLE | 称号类奖励 |
