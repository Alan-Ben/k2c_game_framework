# 红点系统数据配表文档

## 配表说明

红点系统相关的配置数据主要存储在以下配表中:

---

## 一、红点类型枚举

### ERedDotType - 红点类型

| 枚举值 | 说明 |
|--------|------|
| NONE | 无 |

---

## 二、红点配置

### 红点配置说明

红点系统的配置主要包含以下内容：

| 配置项 | 说明 |
|--------|------|
| red_dot_id | 红点ID |
| red_dot_type | 红点类型 |
| expire_time_ms | 过期时间(毫秒时间戳) |
| priority | 红点优先级 |
| related_module | 关联模块 |

---

## 三、红点处理器配置

每种红点类型可以配置对应的处理器：

| 处理器类型 | 说明 |
|------------|------|
| 条件检测处理器 | 检测特定条件是否满足 |
| 状态检测处理器 | 检测特定状态是否变化 |
| 数量检测处理器 | 检测数量是否达到阈值 |

---

## 四、红点数据结构

### RedDotInfo - 红点信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| redDotType | ERedDotType | 红点类型 |
| expireTimeMs | long | 过期时间 |

### Common_RedDotInfo - 通用红点信息

| 字段名 | 类型 | 说明 |
|--------|------|------|
| type | ERedDotType | 红点类型 |
| expireTimeMs | long | 过期时间 |

---

## 五、配表加载方式

红点系统是内存系统，不需要从配置表加载数据。

红点状态由各模块的处理器动态计算得出。

---

## 六、红点管理

### 6.1 红点处理器注册

```java
// 注册红点处理器
private void regDealer(_ARedDotDealer _dealer)
{
    _m_dealerList[_dealer.getRedDotType().ordinal()] = _dealer;
}
```

### 6.2 红点刷新机制

红点状态由各业务模块触发刷新，而非定时轮询：

- 条件变化时触发
- 状态变化时触发
- 数量变化时触发
