# 客户端数据模块完整说明

## 一、模块概述

### 1.1 业务背景

客户端数据模块是 K2C 游戏的基础设施模块，负责管理客户端本地数据的存储、同步和查询。该模块支持多种数据类型的存储，包括游戏设置、引导进度、红点状态等，确保玩家在不同设备间的数据一致性。

### 1.2 目标用户

- **游戏玩家**：通过该模块保存个人设置和游戏进度
- **开发团队**：利用该模块实现数据跨设备同步
- **运营人员**：通过Web加密数据接口进行数据验证

### 1.3 核心价值

1. **数据持久化**：客户端数据安全存储到服务端
2. **跨设备同步**：玩家更换设备后可恢复数据
3. **版本控制**：防止数据覆盖和冲突
4. **安全传输**：Web加密数据接口保障数据安全

## 三、业务流程详解

### 3.1 客户端数据保存流程

```mermaid
flowchart TD
    A[客户端请求保存数据] --> B{检查数据类型}
    B -->|无效类型| C[返回类型错误]
    B -->|有效类型| D{检查数据键长度}
    D -->|超长| E[返回键长度错误]
    D -->|正常| F{检查数据大小}
    F -->|超限| G[返回数据过大]
    F -->|正常| H{检查数据格式}
    H -->|格式错误| I[返回格式错误]
    H -->|格式正确| J{查询现有数据}
    J -->|不存在| K[新增数据记录]
    J -->|存在| L{版本号检查}
    L -->|版本号过低| M[返回版本冲突]
    L -->|版本号正确| N[更新数据记录]
    K --> O[返回保存成功]
    N --> O
```

**详细步骤说明**：

1. **数据校验**
   - 检查数据类型有效性
   - 检查数据键长度（最大128字符）
   - 检查数据大小（最大配置限制）

2. **格式验证**
   - 验证JSON格式正确性
   - 检查必填字段

3. **版本控制**
   - 新数据直接插入
   - 已有数据检查版本号
   - 版本号必须递增

4. **数据存储**
   - 保存到数据库
   - 更新缓存

### 3.2 客户端数据查询流程

```mermaid
flowchart TD
    A[客户端请求查询数据] --> B{检查数据类型}
    B -->|无效类型| C[返回类型错误]
    B -->|有效类型| D{查询数据库}
    D --> E{数据是否存在}
    E -->|不存在| F[返回不存在]
    E -->|存在| G[返回数据信息]
```

**详细步骤说明**：

1. **参数验证**
   - 验证数据类型有效性
   - 验证数据键合法性

2. **数据查询**
   - 查询数据库记录
   - 返回数据值和版本号

### 3.3 Web加密数据流程

```mermaid
flowchart TD
    A[请求Web加密数据] --> B{验证加密键}
    B -->|无效| C[返回加密键无效]
    B -->|有效| D[生成加密原始数据]
    D --> E[使用密钥加密数据]
    E --> F[设置过期时间]
    F --> G[缓存加密结果]
    G --> H[返回加密数据]
```

**详细步骤说明**：

1. **密钥验证**
   - 验证加密键有效性

2. **数据生成**
   - 生成需要加密的原始数据
   - 包含玩家ID、时间戳等信息

3. **加密处理**
   - 使用AES加密算法
   - 生成加密数据字符串

4. **过期设置**
   - 设置加密数据过期时间
   - 缓存到Redis

### 3.4 数据同步流程

```mermaid
flowchart TD
    A[客户端数据变化] --> B{同步类型}
    B -->|实时同步| C[立即发送保存请求]
    B -->|延迟同步| D[加入待同步队列]
    C --> E[等待服务端响应]
    D --> F{触发同步条件}
    F -->|登出时| G[批量同步]
    F -->|定时同步| G
    F -->|手动同步| G
    G --> E
    E --> H{同步成功}
    H -->|成功| I[更新本地版本号]
    H -->|失败| J[重试同步]
```

## 四、关键规则

### 4.1 数据类型规则

| 类型ID | 类型名称 | 说明 |
|--------|----------|------|
| 1 | Settings | 客户端设置（音量、画面等） |
| 2 | Tutorial | 引导进度 |
| 3 | RedDot | 红点状态 |
| 4 | UIState | UI状态 |
| 5 | Cache | 缓存数据 |

### 4.2 同步类型规则

| 同步类型 | 类型值 | 说明 |
|----------|--------|------|
| 手动同步 | 0 | 手动触发同步 |
| 登录同步 | 1 | 登录时自动同步 |
| 登出同步 | 2 | 登出时自动同步 |
| 实时同步 | 3 | 数据变化立即同步 |

### 4.3 数据大小限制

1. **数据键**：最大128字符
2. **数据值**：最大64KB（可配置）
3. **单玩家总数据量**：最大1MB

### 4.4 版本号规则

1. **版本号生成**：使用时间戳或递增序列
2. **版本号验证**：新版本号必须大于现有版本号
3. **冲突处理**：版本冲突时拒绝更新
