# 宴会系统 - 协议文档

## 协议编号

模块编号：p019 (DinnerOp)

## 客户端请求协议 (GC2GS)

### GC2GS_019_001_ReqStartDinner

**说明**：请求开始宴会

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dinnerId | int | 宴会ID |

**返回**：GS2GC_019_001_RetStartDinner

---

### GC2GS_019_002_ReqStartDinnerByPermit

**说明**：请求使用许可开始宴会

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dinnerId | int | 宴会ID |
| permitId | int | 许可ID |

**返回**：GS2GC_019_002_RetStartDinnerByPermit

---

### GC2GS_019_003_ReqJoinedPlayerList

### GC2GS_019_005_ReqGetStartLogInfo

### GC2GS_019_006_ReqGetDinnerIdxList

### GC2GS_019_007_ReqGetDinnerInfo

### GC2GS_019_008_ReqJoinDinner

**说明**：请求加入宴会

| dinnerId | long | 宴会ID |

---

## 数据结构

### DinnerInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dinnerId | long | 宴会ID |
| hostPlayerId | long | 举办者ID |
| hostPlayerName | string | 举办者名称 |
| dinnerCfgId | int | 宴会配置ID |
| state | int | 状态 |
| startTime | long | 开始时间 |
| endTime | long | 结束时间 |
| joinerList | array | 参与者列表 |
| permitId | int | 许可ID |

### DinnerJoinerInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| playerId | long | 玩家ID |
| playerName | string | 玩家名称 |
| joinTime | long | 加入时间 |
| rewardTaken | bool | 是否已领取奖励 |

### DinnerInviteInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| inviteId | long | 邀请ID |
| dinnerId | long | 宴会ID |
| fromPlayerId | long | 邀请者ID |
| fromPlayerName | string | 邀请者名称 |
| expireTime | long | 过期时间 |
