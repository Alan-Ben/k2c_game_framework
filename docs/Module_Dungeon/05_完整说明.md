# 副本模块完整说明

## 一、模块概述

### 1.1 业务背景

副本模块是 K2C 游戏的核心 PVE（玩家对环境）系统，包含三种类型的副本：
- **午间副本**：每日定时开放，玩家挑战获取宝箱奖励
- **晚间副本**：全服玩家共同挑战世界Boss，伤害排行获取奖励
- **公会副本**：公会成员协作挑战怪物，获取公会资源和奖励

副本系统是玩家日常获取资源的重要途径，提供了多样的玩法体验。

### 1.2 目标用户

| 用户类型 | 特征描述 | 主要诉求 |
|----------|----------|----------|
| 日常玩家 | 每日稳定上线 | 快速获取日常资源 |
| 挑战玩家 | 追求高伤害排名 | 展示实力，获取排名奖励 |
| 公会成员 | 参与公会活动 | 公会贡献，协作挑战 |
| 收集玩家 | 收集稀有道具 | 获取副本专属奖励 |

## 三、业务流程详解

### 3.1 午间副本挑战流程

```mermaid
flowchart TD
    A[进入午间副本] --> B{检查开启时间}
    B -->|未开启| C[显示开启倒计时]
    B -->|已开启| D{检查今日次数}
    D -->|次数用完| E[显示购买选项]
    D -->|次数充足| F[显示副本信息]
    F --> G[点击攻击按钮]
    G --> H{检查体力}
    H -->|体力不足| I[显示体力获取途径]
    H -->|体力充足| J[选择攻击方式]
    J --> K{普通/借用}
    K -->|普通攻击| L[扣减体力]
    K -->|借用攻击| M{检查借用次数}
    M -->|次数用完| N[提示次数不足]
    M -->|次数充足| O[选择好友英雄]
    O --> L
    L --> P[执行攻击]
    P --> Q[计算奖励]
    Q --> R[显示攻击结果]
    R --> S{检查宝箱条件}
    S -->|条件满足| T[提示可领取宝箱]
    S -->|条件不满足| U[显示进度]
    T --> V[点击领取宝箱]
    V --> W[发放宝箱奖励]
    W --> X[显示奖励详情]
    U --> Y[返回副本界面]
    X --> Y
```

**详细步骤说明**：

1. **副本进入**
   - 检查玩家等级是否满足解锁条件
   - 显示副本信息：名称、推荐战力、奖励预览
   - 显示今日剩余次数

2. **攻击准备**
   - 检查体力是否充足
   - 选择攻击方式：普通攻击或借用好友英雄
   - 借用攻击有额外奖励加成

3. **攻击执行**
   - 扣减体力
   - 计算攻击奖励
   - 更新今日攻击次数

4. **宝箱领取**
   - 累计攻击次数达到条件解锁宝箱
   - 点击领取发放宝箱奖励

### 3.2 晚间副本挑战流程

```mermaid
flowchart TD
    A[进入晚间副本] --> B{检查开启时间}
    B -->|未开启| C[显示开启倒计时]
    B -->|已开启| D[获取Boss信息]
    D --> E{检查Boss状态}
    E -->|已死亡| F[显示击杀记录]
    E -->|存活| G[显示Boss血量]
    G --> H[点击攻击按钮]
    H --> I[计算伤害]
    I --> J[扣减Boss血量]
    J --> K{Boss是否死亡}
    K -->|是| L[记录击杀玩家]
    L --> M[发放击杀奖励]
    M --> N[全服广播击杀]
    K -->|否| O[更新伤害排行]
    N --> P[结算排行奖励]
    O --> Q[显示伤害结果]
    P --> Q
    Q --> R{继续攻击?}
    R -->|是| H
    R -->|否| S[返回主界面]
```

**关键机制说明**：

1. **Boss血量共享**
   - 全服玩家攻击同一Boss
   - 血量实时同步更新
   - 使用Redis原子操作保证数据一致性

2. **伤害计算**
   - 基于玩家攻击力计算基础伤害
   - 加入随机因素增加趣味性
   - 暴击判定提升爽快感

3. **击杀奖励**
   - 最后一击玩家获得额外奖励
   - 全服广播击杀信息
   - 根据伤害排名发放排行奖励

### 3.3 公会副本挑战流程

```mermaid
flowchart TD
    A[进入公会副本] --> B{检查副本状态}
    B -->|未开启| C{检查权限}
    C -->|无权限| D[提示权限不足]
    C -->|有权限| E[点击开启副本]
    E --> F[初始化怪物列表]
    F --> G[推送副本开启通知]
    B -->|已开启| H[显示怪物列表]
    G --> H
    H --> I[选择攻击目标]
    I --> J{怪物是否存活}
    J -->|已死亡| K[显示已击杀]
    J -->|存活| L[点击攻击]
    L --> M[计算伤害]
    M --> N[扣减怪物血量]
    N --> O{怪物是否死亡}
    O -->|是| P[发放击杀奖励]
    P --> Q[更新伤害排行]
    O -->|否| Q
    Q --> R{检查副本通关}
    R -->|未通关| S[显示伤害结果]
    R -->|已通关| T[发放通关奖励]
    T --> U[推送通关通知]
    S --> V{继续攻击?}
    V -->|是| I
    V -->|否| W[返回主界面]
```

**公会协作机制**：

1. **怪物标记**
   - 会长/官员可标记重点攻击目标
   - 帮助成员集中火力
   - 提高通关效率

2. **伤害排行**
   - 公会内部伤害排名
   - 激励成员积极参与
   - 便于奖励分配

3. **副本升级**
   - 消耗公会资金提升副本等级
   - 提高怪物难度和奖励
   - 长期成长目标

## 五、用户故事

### 5.1 午间副本用户故事

> **作为日常玩家**，我每天中午12点上线，先完成午间副本。我先用普通攻击打3次，获得了银两和经验书。然后我发现攻击次数达到5次可以领取一个宝箱，于是我又借用好友的英雄攻击了2次，不仅完成了宝箱条件，还获得了额外的奖励加成。领取宝箱后，我获得了大量金币和稀有材料，感觉非常满足。

### 5.2 晚间副本用户故事

> **作为追求排名的玩家**，我非常关注晚间副本的世界Boss活动。每晚8点Boss开启时，我都会第一时间参与。我的战力较高，每次攻击都能打出很高的伤害。昨晚我打了100多次，累计伤害达到了第一名，最终获得了排行第一的丰厚奖励。而且有一次我运气很好，最后一击击杀了Boss，还额外获得了击杀奖励！

### 5.3 公会副本用户故事

> **作为公会会长**，我负责管理公会的副本活动。我们公会的副本设置为每周一三五自动开启，这样成员们都知道什么时候有活动。我经常使用怪物标记功能，告诉成员优先攻击哪个怪物。我们的副本已经升到了5级，难度虽然高了，但奖励也更丰厚了。每次通关后，公会成员都很开心，大家的配合也越来越默契。
