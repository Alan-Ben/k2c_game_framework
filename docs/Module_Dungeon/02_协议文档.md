## 数据结构

### MiddayDungeonInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dungeonId | int | 副本ID |
| state | int | 状态 |
| boxList | array | 宝箱列表 |
| attackCount | int | 攻击次数 |
| endTime | long | 结束时间 |

### EveningDungeonInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dungeonId | int | 副本ID |
| state | int | 状态 |
| bossInfo | BossInfo | Boss信息 |
| rankList | array | 排行榜 |
| endTime | long | 结束时间 |

### GuildDungeonInfo

| 字段名 | 类型 | 说明 |
|-------|------|------|
| dungeonId | int | 副本ID |
| dungeonLvl | int | 副本等级 |
| monsterList | array | 怪物列表 |
| damageRank | array | 伤害排行 |
| isAutoStart | bool | 是否自动开始 |
