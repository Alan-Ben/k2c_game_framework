## 核心管理类

### GuildMarsHelpMgr

火星援助管理器，负责:
- 援助请求管理
- 援助处理逻辑
- 援助奖励发放

### GuildRallyMgr

集结管理器，负责:
- 集结创建和管理
- 集结成员管理
- 集结目标处理

## 业务逻辑

### 火星援助流程

1. 玩家发送援助请求
2. 推送给公会成员
3. 成员选择帮助
4. 发放帮助奖励
5. 更新援助状态

### 公会宝箱流程

1. 触发宝箱生成条件
2. 生成宝箱数据
3. 推送给公会成员
4. 成员领取奖励
5. 更新领取状态

### 集结流程

1. 玩家创建集结
2. 推送集结邀请
3. 成员加入集结
4. 集结时间到达
5. 开始集体行动

## 离线处理

### OfflineDealer_GuildMarsHelpBeAutoDealed

处理玩家离线时援助被自动处理的情况。

### OfflineDealer_GuildMarsHelpSuc

处理玩家离线时援助成功的情况。
