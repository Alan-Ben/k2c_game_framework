# 招募系统 - 协议文档

## 说明

招募系统主要通过 CommOp (p007) 和 InitOp (p002) 进行协议通信。

## 相关协议

### 初始化协议

#### GS2GC_002_041_RetRecuritInfo

**说明**：返回招募初始化信息

---

### 招募操作

#### GC2GS_007_028_ReqRecruit

**说明**：请求招募

**请求参数**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| recruitId | int | 招募ID |
| count | int | 招募次数(1或10) |

**返回**：GS2GC_007_028_RetRecruit

**响应字段**：

| 字段名 | 类型 | 说明 |
|-------|------|------|
| recruitId | int | 招募ID |
| resultList | array | 结果列表 |
| guaranteeCount | int | 当前保底计数 |

---

### 招募记录

#### GS2GC_007_073_OnRecuritRecordAdd

**说明**：通知招募记录添加

---

### 招募商店

#### GC2GS_007_XXX_ReqRecruitShopRefresh

**说明**：请求刷新招募商店

---

## 数据结构

### RecruitResult

| 字段名 | 类型 | 说明 |
|-------|------|------|
| itemId | int | 物品ID |
| itemType | int | 物品类型 |
| itemCount | int | 数量 |
| rarity | int | 稀有度 |
| isNew | bool | 是否新获得 |

### RecruitRecord

| 字段名 | 类型 | 说明 |
|-------|------|------|
| recordId | long | 记录ID |
| recruitId | int | 招募ID |
| resultList | array | 结果列表 |
| recruitTime | long | 招募时间 |
