# 协议客户端测试生成 Skill

## 适用场景
- 为新协议生成 Client 侧测试方法
- 为指定协议号区间批量补测试代码
- 为已完成服务端实现的协议补联调用例

## 先做的事
1. 先读取对应 `.alpro` 协议定义，确认真实参数结构。
2. 搜索 `Client/src/MGClient/Cmd/Cmds` 下的现有测试类，复用现有组织方式。
3. 如协议包含复杂对象参数，再到 `ServerProtocol/src/Common/` 查对象定义。

## 执行步骤
1. 根据协议包、协议号范围定位请求协议和响应协议。
2. 按项目现有命名生成测试类或测试方法。
3. 为每个协议生成可直接调用的发送逻辑、默认测试参数、结果日志。
4. 对成功和失败响应都给出基础处理。

## 关键规则
- 参数必须严格以 `.alpro` 定义为准
- 复杂对象参数必须先构造对象，不要擅自拆成错误的基础类型
- 导入统一用 `import`，不要写全限定类名
- 方法名应反映真实协议功能
- 注释使用中文，说明测试用途和关键参数

## 输出要求
- 生成可直接放入 `Client` 工程的测试代码
- 默认测试数据要合理，但允许调用方覆盖
- 需要时补充通用辅助方法，例如登录、数据准备、结果校验

## 校验清单
- 协议参数与 `.alpro` 完全一致
- 复杂对象构造参数正确
- import 完整且干净
- 测试方法命名与协议语义一致
- 响应处理覆盖基本成功/失败路径
