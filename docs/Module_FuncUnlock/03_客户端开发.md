## 核心类说明

### FuncUnlockInfo

功能解锁信息类。

```csharp
public class FuncUnlockInfo
{
    public int funcId;           // 功能ID
    public string funcName;      // 功能名称
    public int unlockLevel;      // 解锁等级
    public bool isUnlocked;      // 是否已解锁

    // 检查是否解锁
    public bool CheckUnlock();

    // 获取解锁描述
    public string GetUnlockDesc();
}
```

## 主要功能

### 解锁检查

检查特定功能是否已解锁。

### 解锁提示

显示功能解锁提示和引导。

### 条件判断

判断是否满足解锁条件。

## 使用示例

### 检查功能解锁

```csharp
// 检查功能是否解锁
if (FuncUnlockManager.Instance.IsFuncUnlocked(FuncType.SHOP))
{
    // 显示商店入口
    ShowShopButton();
}
else
{
    // 显示解锁条件
    ShowUnlockCondition(FuncType.SHOP);
}
```

### 监听解锁事件

```csharp
// 注册解锁事件
FuncUnlockManager.Instance.OnFuncUnlocked += (funcId) => {
    Debug.Log($"功能 {funcId} 已解锁");
    UpdateUI();
};
```
