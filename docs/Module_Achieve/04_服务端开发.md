## 核心逻辑

### 更新成就进度

```java
public void updateProgress(long playerId, long achieveId, long addValue) {
    PlayerAchieve achieve = achieveDao.selectByPlayerAndId(playerId, achieveId);
    if (achieve == null) {
        return;
    }

    AchieveConfig config = achieveConfigDao.getById(achieveId);
    if (config == null) {
        return;
    }

    // 更新进度
    long newProgress = achieve.getProgress() + addValue;
    achieve.setProgress(newProgress);

    // 检查是否进入下一阶段
    int newStep = calculateStep(config, newProgress);
    if (newStep > achieve.getCurStep()) {
        achieve.setCurStep(newStep);
        // 推送红点
        pushRedDot(playerId, achieveId);
    }

    achieveDao.updateById(achieve);

    // 推送通知
    pushAchieveChg(playerId, achieve);
}
```

### 领取成就奖励

```java
public void takeAchieveReward(long playerId, long achieveId, int step) {
    PlayerAchieve achieve = achieveDao.selectByPlayerAndId(playerId, achieveId);
    if (achieve == null || achieve.getCurStep() < step) {
        throw new BusinessException(ErrorCode.ACHIEVE_STEP_NOT_REACHED);
    }

    if (achieve.getStepRewardTaken().contains(step)) {
        throw new BusinessException(ErrorCode.REWARD_ALREADY_TAKEN);
    }

    AchieveStepConfig stepConfig = achieveStepConfigDao.getByAchieveAndStep(achieveId, step);

    // 发放奖励
    itemService.giveItems(playerId, stepConfig.getRewardList());

    // 记录领取
    achieve.getStepRewardTaken().add(step);
    achieveDao.updateById(achieve);
}
```

## 注意事项

1. 成就进度更新需要触发器机制
2. 阶段奖励需验证是否达到
3. 成就点数用于兑换系统
