## 数据管理

### SevenDayLoginComponent

```csharp
public class SevenDayLoginComponent : _ANPBasicPlayerComponent
{
    // 登录天数
    private int _m_loginDay;

    // 已领取奖励列表
    private List<int> _m_rewardTakenList;

    // 目标进度列表
    private List<SevenDayGoalInfo> _m_goalList;

    /// <summary>
    /// 请求领取奖励
    /// </summary>
    public void reqTakeReward(int day, Action callback)
    {
        NPGSClientListener.sendRequest(
            NPGSWriter_021_PlayerInfoOp.make_XXX_ReqTakeSevenDayReward(day),
            new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_021_XXX_RetTakeSevenDayReward>((msg) =>
            {
                _m_rewardTakenList.Add(day);
                callback?.Invoke();
            }));
    }

    /// <summary>
    /// 是否已领取
    /// </summary>
    public bool isRewardTaken(int day)
    {
        return _m_rewardTakenList.Contains(day);
    }

    /// <summary>
    /// 是否可领取
    /// </summary>
    public bool canTakeReward(int day)
    {
        return _m_loginDay >= day && !isRewardTaken(day);
    }
}
```

## UI 窗口

### 七日登录界面

```csharp
public class SevenDayLoginWindow : BaseWindow
{
    // 刷新界面
    public void refreshUI()
    {
        var component = SevenDayLoginComponent.instance;
        for (int day = 1; day <= 7; day++)
        {
            bool canTake = component.canTakeReward(day);
            bool taken = component.isRewardTaken(day);
            // 更新UI状态
            updateDayItem(day, canTake, taken);
        }
    }

    // 领取奖励
    public void onClickTakeReward(int day)
    {
        SevenDayLoginComponent.instance.reqTakeReward(day, () =>
        {
            refreshUI();
            showRewardEffect();
        });
    }
}
```

## 注意事项

1. 登录天数由服务端控制
2. 奖励需要手动领取
3. 七日目标有额外奖励
