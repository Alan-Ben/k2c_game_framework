## 四、请求方法

### 4.1 初始化请求

```csharp
// 请求阶段目标初始化
NPGSClientListener.sendRequestByLog(
    new GC2GS_002_062_ReqStageGoalInit(),
    new CommonRequestCallbackProtocolDealer<GS2GC_002_062_RetStageGoalInit>((msg) =>
    {
        // 处理初始化数据
        _processInitData(msg);
    })
);
```

### 4.2 领取奖励请求

```csharp
// 领取首达奖励
public void reqDrawFirstReachReward(long bigStepId, Action<bool> callback)
{
    NPGSClientListener.sendRequestByLog(
        new GC2GS_007_015_ReqDrawStageGoalFirstReachReward(bigStepId),
        new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_007_015_RetDrawStageGoalFirstReachReward>((msg) =>
        {
            callback?.Invoke(true);
        }, (errCode) =>
        {
            callback?.Invoke(false);
        })
    );
}

// 领取任务奖励
public void reqTakeTaskReward(long taskId, Action<bool> callback)
{
    NPGSClientListener.sendRequestByLog(
        new GC2GS_007_025_ReqTakeStageGoalTaskReward(taskId),
        new CommonErrCodeRequestCallbackProtocolDealer<GS2GC_007_025_RetTakeStageGoalTaskReward>((msg) =>
        {
            callback?.Invoke(true);
        })
    );
}
```
