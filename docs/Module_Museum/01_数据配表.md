# 博物馆系统 - 数据配表

## 概述

博物馆系统 (MuseumOp, p035) 是游戏中的收藏玩法，玩家可以收集和展示各类藏品。

## 配表文件

### 1. 博物馆配置 (Museum)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| museum_id | int | 博物馆ID |
| museum_name | string | 博物馆名称 |
| max_slot | int | 最大展位 |

### 2. 藏品配置 (MuseumItem)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| item_id | int | 藏品ID |
| item_name | string | 藏品名称 |
| item_type | int | 藏品类型 |
| rarity | int | 稀有度 |
| max_level | int | 最大等级 |

### 3. 藏品升级配置 (MuseumItemUpgrade)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| item_id | int | 藏品ID |
| level | int | 等级 |
| cost_list | array | 升级消耗 |
| attr_add | json | 属性加成 |

## 配表路径

- 客户端配置：`game_client/Assets/Scripts/ResScripts/NPSO/GSO/Museum/`
- 服务端配置：`game_server/Config/museum/`
