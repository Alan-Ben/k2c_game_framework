# 副本模块协议文档

## 协议模块编号

模块编号：p024 (DungeonOp) / p037 (GuildDungeonOp)

协议主序号：`24` / `37`

---

## 一、协议架构总览

```mermaid
graph TB
    subgraph 客户端请求 GC2GS
        A1[午间副本请求<br/>024_001~006]
        A2[晚间副本请求<br/>024_011~015]
        A3[公会副本请求<br/>037_001~012]
    end

    subgraph 服务端响应 GS2GC
        B1[午间副本响应<br/>024_001~006]
        B2[晚间副本响应<br/>024_011~015]
        B3[公会副本响应<br/>037_001~012]
    end

    subgraph 服务端推送 GS2GC
        C1[午间副本推送<br/>024_051~052]
        C2[晚间副本推送<br/>024_061~062]
        C3[公会副本推送<br/>037_050~056]
    end

    A1 --> B1
    A2 --> B2
    A3 --> B3

    B1 -.-> C1
    B2 -.-> C2
    B3 -.-> C3
```

### 2.1 午间副本协议

#### GC2GS_024_001_ReqMiddayDungeonAttack - 请求午间副本攻击

**功能说明**: 请求玩家对午间副本进行攻击，获取攻击奖励

**协议编号**: 主序号 24, 子序号 1

| 序号 | 字段名 | 类型 | 说明 | 示例 |
|------|--------|------|------|------|
| 1 | dungeonId | int | 副本ID | 1 |

**服务端处理流程**:

```mermaid
flowchart TD
    A[接收请求] --> B{验证副本开启状态}
    B -->|未开启| C[返回错误: DUNGEON_NOT_OPEN]
    B -->|已开启| D{检查今日攻击次数}
    D -->|次数用完| E[返回错误: ATTACK_COUNT_EXCEEDED]
    D -->|次数充足| F{检查体力}
    F -->|体力不足| G[返回错误: ENERGY_NOT_ENOUGH]
    F -->|体力充足| H[扣减体力]
    H --> I[执行攻击计算奖励]
    I --> J[更新攻击次数]
    J --> K[发放奖励]
    K --> L[更新宝箱进度]
    L --> M[返回攻击结果]
    M --> N[推送副本信息变化]
```

**响应**: `GS2GC_024_001_RetMiddayDungeonAttack`

## 八、协议版本管理

### 8.1 版本兼容策略

```mermaid
flowchart TD
    A[协议变更] --> B{变更类型}
    B -->|新增字段| C[向后兼容<br/>老版本忽略新字段]
    B -->|删除字段| D[需要版本号检查]
    B -->|修改字段类型| E[需要协议升级]

    C --> F[递增子版本号]
    D --> G[新增协议替代]
    E --> H[新增主版本号]

    F --> I[发布更新]
    G --> I
    H --> I
```

### 8.2 协议版本号规则

| 版本类型 | 格式 | 说明 | 示例 |
|----------|------|------|------|
| 主版本 | v{major} | 协议结构重大变更 | v2 |
| 子版本 | v{major}.{minor} | 新增协议或字段 | v1.5 |
| 补丁版本 | v{major}.{minor}.{patch} | Bug修复 | v1.5.1 |

```mermaid
sequenceDiagram
```

```java
/**
 * 协议参数校验
 */
public class DungeonProtocolValidator {

    /**
     * 校验副本ID
     */
    public static boolean validateDungeonId(int dungeonId) {
        return dungeonId > 0 && dungeonId < 10000;
    }

    /**
     * 校验Boss ID
     */
    public static boolean validateBossId(int bossId) {
        return bossId > 0 && bossId < 100000;
    }

    /**
     * 校验公会ID
     */
    public static boolean validateGuildId(long guildId) {
        return guildId > 0;
    }

    /**
     * 校验玩家ID
     */
    public static boolean validatePlayerId(long playerId) {
        return playerId > 0;
    }

    /**
     * 校验怪物ID列表
     */
    public static boolean validateMonsterIdList(List<Integer> monsterIdList) {
        if (monsterIdList == null || monsterIdList.isEmpty()) return false;
        if (monsterIdList.size() > 10) return false;
        for (int monsterId : monsterIdList) {
            if (monsterId <= 0) return false;
        }
        return true;
    }
}
```
