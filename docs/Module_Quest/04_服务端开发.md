# 任务模块服务端开发文档

## 一、模块架构

### 1.1 模块概述

任务模块（Quest Module）负责管理游戏中的各类任务，包括：
- 主线任务进度管理
- 日常任务系统
- 系统任务（成就、目标等）
- 活跃度系统
- 任务目标追踪

### 1.2 模块编号

协议模块编号: `p028`

## 四、核心逻辑流程

### 4.1 开始任务流程

```
客户端                          服务端
   |                               |
   |--- ReqStartQuest ------------>|
   |                               | 1. 验证任务配置是否存在
   |                               | 2. 验证前置任务是否完成
   |                               | 3. 创建任务数据
   |                               | 4. 初始化任务目标
   |<-- RetStartQuest -------------|
   |<-- OnQuestAdd ----------------| (推送任务新增)
   |                               |
```

### 4.2 完成任务流程

```
客户端                          服务端
   |                               |
   |--- ReqFinishQuest ----------->|
   |                               | 1. 验证任务是否存在
   |                               | 2. 验证任务目标是否完成
   |                               | 3. 发放任务奖励
   |                               | 4. 更新任务状态
   |                               | 5. 解锁后续任务
   |<-- RetFinishQuest ------------|
   |<-- OnQuestFinish -------------| (推送任务完成)
   |                               |
```

- 玩家数据服务 (PlayerDataService)
- 资源服务 (ResourceService)
- 配置数据服务 (RefdataService)
- 推送服务 (PushService)
- 事件服务 (EventService)
