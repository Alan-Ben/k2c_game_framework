## 核心逻辑

### 执行招募

```java
public List<RecruitResult> recruit(long playerId, int recruitId, int count) {
    // 1. 获取招募配置
    RecruitConfig config = recruitConfigDao.getById(recruitId);

    // 2. 检查次数限制
    if (count != 1 && count != 10) {
        throw new BusinessException(ErrorCode.INVALID_RECRUIT_COUNT);
    }

    // 3. 扣除消耗
    List<ItemInfo> costList = calculateCost(config, count);
    itemService.consumeItems(playerId, costList);

    // 4. 执行招募
    PlayerRecruit playerRecruit = recruitDao.getByPlayerAndId(playerId, recruitId);
    List<RecruitResult> results = new ArrayList<>();

    for (int i = 0; i < count; i++) {
        RecruitResult result = doSingleRecruit(playerId, config, playerRecruit);
        results.add(result);
    }

    // 5. 更新招募数据
    playerRecruit.setTotalCount(playerRecruit.getTotalCount() + count);
    recruitDao.updateById(playerRecruit);

    // 6. 保存记录
    saveRecruitRecord(playerId, recruitId, results);

    return results;
}

private RecruitResult doSingleRecruit(long playerId, RecruitConfig config, PlayerRecruit playerRecruit) {
    // 检查保底
    boolean guarantee = false;
    if (config.getGuaranteeCount() > 0 &&
        playerRecruit.getGuaranteeCount() >= config.getGuaranteeCount() - 1) {
        guarantee = true;
        playerRecruit.setGuaranteeCount(0);
    } else {
        playerRecruit.setGuaranteeCount(playerRecruit.getGuaranteeCount() + 1);
    }

    // 随机抽取
    int itemId = randomFromPool(config.getItemList(), guarantee);

    // 发放物品
    itemService.giveItem(playerId, itemId, 1);

    return new RecruitResult(itemId, 1, getItemRarity(itemId));
}
```

## 注意事项

1. 保底计数需要正确处理
2. 概率权重配置需验证
3. 招募记录需要保存
