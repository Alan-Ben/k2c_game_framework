## 三、协议调用流程

### 3.1 英雄升级流程
```
客户端                          服务端
   |                               |
   |--- ReqHeroUpgrade ----------->|
   |                               | (验证资源、升级处理)
   |<-- RetHeroUpgrade ------------|
   |<-- OnHeroLevelChg ------------| (推送等级变化)
   |                               |
```

### 3.2 英雄穿戴装备流程
```
客户端                          服务端
   |                               |
   |--- ReqHeroWearEquip --------->|
   |                               | (验证装备、穿戴处理)
   |<-- RetHeroWearEquip ----------|
   |<-- OnEquipBaseChg ------------| (推送装备变化)
   |                               |
```
