## 数据存储

使用 Redis 排序集合 (Sorted Set) 存储排行榜数据。

### Redis Key 设计

```
rank:{rankType}          # 排行榜数据
rank:like:{playerId}     # 玩家点赞记录
```

## 核心逻辑

### 获取排行榜

```java
public List<RankInfo> getRankList(int rankType) {
    String key = "rank:" + rankType;

    // 从缓存获取
    Set<ZSetOperations.TypedTuple<String>> set =
        redisTemplate.opsForZSet().reverseRangeWithScores(key, 0, 99);

    List<RankInfo> rankList = new ArrayList<>();
    int rank = 1;
    for (ZSetOperations.TypedTuple<String> tuple : set) {
        Long playerId = Long.parseLong(tuple.getValue());
        Long score = tuple.getScore().longValue();

        // 获取玩家信息
        PlayerBase player = playerDao.selectById(playerId);

        RankInfo info = new RankInfo();
        info.setRank(rank++);
        info.setPlayerId(playerId);
        info.setPlayerName(player.getPlayerName());
        info.setScore(score);
        rankList.add(info);
    }

    return rankList;
}
```

### 更新排名

```java
public void updateRank(int rankType, long playerId, long score) {
    String key = "rank:" + rankType;
    redisTemplate.opsForZSet().add(key, String.valueOf(playerId), score);
}
```

## 定时任务

### 刷新排行榜

```java
@Scheduled(cron = "0 0 * * * ?") // 每小时刷新
public void refreshRankList() {
    for (ERankType type : ERankType.values()) {
        // 重新计算排名
        recalculateRank(type);
    }
}
```

## 注意事项

1. 排行榜使用 Redis 缓存提高性能
2. 点赞有每日次数限制
3. 排名更新需要原子操作
