# Java 注释生成 Skill

## 适用场景
- 为新建或已有 Java 类补充类注释、方法注释、成员变量注释
- 清理无信息量注释，并按项目风格补齐真正有价值的说明
- 重点说明复杂业务逻辑、状态流转、缓存/懒加载、数据库操作、网络通信时机

## 执行步骤
1. 先读取目标类及其相邻调用代码，确认类职责、关键字段、主要流程。
2. 参考同模块已有注释风格，优先保持现有项目写法一致。
3. 只为有业务价值的内容补注释，不重复代码表面含义。
4. 涉及组件、BO、ALProcess、消息分发时，补充其在整体架构中的作用。

## 注释规范
- 类注释使用 `/** ... */`
- 方法注释使用 `/** ... */`
- 成员变量注释使用简洁的 `//`，放在声明上一行
- 注释使用中文
- 复杂方法可用编号列步骤说明执行流程
- 方法注释尽量包含 `@param` 和 `@return`

## 编写原则
- 优先描述业务语义，不写“给变量赋值”这类废话
- 对复杂逻辑说明数据流和状态变化
- 明确指出缓存、懒加载、异步处理、线程安全等关键约束
- 涉及数据库和协议收发时，标明触发时机和影响范围

## 注意事项
- 默认不改业务逻辑，只补注释
- 如现有注释已经准确，不要机械重写
- 若信息不足，先从调用链和同类实现补上下文再动手
