# 伴侣系统 - 数据配表

## 概述

伴侣系统 (ConsortOp, p015) 是游戏中的核心社交养成玩法，玩家可以培养伴侣的好感度、亲密度，解锁皮肤和光环。

## 配表文件

### 1. 伴侣配置 (Consort)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| consort_id | long | 伴侣ID |
| consort_name | string | 伴侣名称 |
| rarity | int | 稀有度 |
| init_intimacy | int | 初始亲密度 |
| max_intimacy | int | 最大亲密度 |

### 2. 伴侣皮肤配置 (ConsortSkin)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| skin_id | int | 皮肤ID |
| consort_id | long | 伴侣ID |
| unlock_condition | json | 解锁条件 |
| effect_list | array | 特效列表 |

### 3. 伴侣光环配置 (ConsortHalo)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| halo_id | int | 光环ID |
| halo_name | string | 光环名称 |
| max_level | int | 最大等级 |
| buff_list | array | Buff列表 |

### 4. 商务技能配置 (BusinessSkill)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| skill_id | int | 技能ID |
| skill_name | string | 技能名称 |
| skill_type | int | 技能类型 |
| effect_value | int | 效果值 |

### 5. 祝福技能配置 (BlessSkill)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| skill_id | int | 技能ID |
| skill_name | string | 技能名称 |
| max_level | int | 最大等级 |
| effect_list | array | 效果列表 |

## 伴侣状态枚举

```csharp
public enum EConsortState
{
    LOCKED = 0,     // 未解锁
    UNLOCKED = 1,   // 已解锁
    ACTIVE = 2      // 激活中
}
```
